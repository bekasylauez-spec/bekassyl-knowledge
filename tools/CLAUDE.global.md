# Bekassyl — барлық жобаға ортақ ережелер (BEKA-1 / BEKA-2)

Толық мәтіні: Obsidian `D:\РАБОЧКА\Bekassyl` (01_Общие правила, 14_Мои правила, 16_КМ чертежи) және ортақ memory `D:\РАБОЧКА\.claude\memory` (MEMORY.md индексі). Бұл жерде — тек ең маңыздысы, ереже қай папкада ашылса да жүктелсін деп.

## Жұмыс тәртібі
- Жауап қазақша. Тапсырма толық біткенде соңында «Бәрі бітті» + не жасалды, тексеріс нәтижесі.
- Кез келген жұмыс алдында Obsidian-ды оқы: `01_Общие правила`, тақырып папкасы (02_Фундамент … 09_Таблицы, 16_КМ чертежи), `14_Мои правила`, `15_Проекты/<объект>`, ондағы аналог (PDF/суреттерімен). Қай жазбаны қолданғаныңды қысқа айт.
- Пайдаланушы айтқанның бәрі — жалпы ереже: бірден Obsidian-ға және memory-ге жаз, сызылғанның бәріне қолдан.
- Жұмысты өзім соңына дейін жасаймын (AutoCAD/Revit/ЛИРА скриптпен), тек нағыз шешім керек болса сұраймын. Оформлениені асықпай, пайдаланушымен парақ-парақ бірге.
- Нәтиже (PDF, DWG) — тек жоба папкасына, ондағы файлдардай таза атпен; Temp/scratchpad-тан жіберме.
- Пайдаланушыда ашық DWG керек болса — өзім сақтап жабамын (COM), өз AutoCAD данамда ашамын; пайдаланушының AutoCAD-ына SendCommand жоқ; оның процесін өлтірме. Автоматтан соң FILEDIA 1, CMDDIA 1, SECURELOAD 1 қайтар.
- Пайдаланушы қолмен түзеткенді өшірме — стилін көшір.
- Яндекс Браузерді жаппа: computer-use алдында оны allowlist-ке қос, оған баспа. Мүмкін болса файл деңгейінде жұмыс істе.

## Оформление (КЖ/КМ, AutoCAD СПДС)
- Стиль, листтер реті/нөмірі, графика — аналогтан. Аналог объектілерін (выноска, размер, кесте, узел) клондап өзгерт, өз стиліңді ойлап таппа. Узел/деталь пайдаланушы DWG-сіне дәл (пішін, өлшем, ұзындық).
- Выноска, размер, отметка, разрез — тек СПДС объектілері. Шрифт ISOCPEUR, бір размер стилі.
- Мәтін биіктігі: выноска = размер мәтіні = 2.5 мм; атаулар 3.0–3.5 мм. Бір парақ — бір масштаб (барлық аннотация сол масштабта).
- Лист ориентациясы ғимарат пішініне сай: тік созылған план → книжный, көлденең → альбомный.
- Выноска: полка стрелкаға қарсы жақта; стрелка элементтің қырына (ортасына/штрихына емес); полка элементтен 300–600; әр выноска өз элементінің қасында, қысқа қиғаш сызықпен; сызбаны, осьті, колоннаны, басқа выносканы кеспейді. Узел (SPDSNOTEKNOT) полкасы шеңберден АЛЫСҚА қарай.
- Размер мәтіні сызықта стандарт саңылаумен; жылжытсаң — тек сызық бойымен. Қысқа размер мәтіні сызықтың сыртқы жағына, шетіне жақын. Тізбекте шаг «200х11=2200». Размерлер бір-біріне түспейді.
- Отметкалар қабаттаспайды; көрші отметкалардың әр жұбы арасында размер. Отметканы элемент бойынша тексер (колонна/қабырға үсті = ригель табаны), «схемада бар» — жеткіліксіз.
- Сызық қалыңдығы: негізгі контур 0.30, арматура 0.40, штрих/размер/жіңішке 0.05. Бетон штрихы ANSI36, масштаб 20, әр қабырғаға жеке штрих.
- Отверстие — бір диагональ (сол-төменнен оң-жоғарыға), X емес. Разрез белгісі размер тізбегінен тыс.
- Кесте рамкадан шықпасын (жол қосқан соң табанын тексер); «лист N» сілтемелері марка↔парақ кестесінен.
- PDF тек Layout-тан; пайдаланушының viewport-тарын ауыстырма.

## Арматура (КЖ)
- Екі стержень/аймақ бір орынға түспейді (тек көрсетілген нахлёст). Доп. арматура тек плита бар жерде (атриум/отверстие үстінен өтпейді), әр бөлікке жеке аймақ, шаг, ұзындық.

## Тексеріс (көрсетпес бұрын)
- Қатенің бір нүктесін емес, бүкіл түрін барлық парақтан түзет; тексеріске жаңа чек қос.
- AutoCAD geomdump + oc.py (оқылмаған объект = қате), нәтиже TOTAL 0; әр парақты бөліп (ширек, 190 dpi) жақындатып қара. Қасиетке емес, геометрияға сен; «дұрыс па?» десе — қайта тексер.

## КМ
- Модельді/3D көрсетпес бұрын km-model-checker (q20_audit C1…C9) — тек ALL PASS. Қателер тізімі: `D:\Бекасыл КЖ КМ\_Стандарт_КЖ\КМ_ҚАТЕЛЕР_ПРОМПТ.md`, ережелер `ЕРЕЖЕЛЕР.md`; жаңа қате → үшеуіне де қос.
- Спецификация: ұзындық чертежден (ЛИРА емес), кронштейн колоннадан бөлек, балка арасы — беттер арасы; бетонға тиетін әр тірекке пластина + анкер, шыны/жабын ауданы м²; кестеде формулалар (сан емес); кесте сызықтары: тақырып/бағандар 0.30, топ ішінде 0.05.
- КМ выноска (09.11): маркалы элементке тек марка (сечение жазылмайды); сечение тек маркасыз бөлшекке («-t8 / С245»). Сызық полканың жақын ұшына, полка стрелкадан ары; өз элементінің қасында, ештеңені кеспейді.

## Модельдер және субагенттер (оптимизация, 04.11)
- Негізгі сессия — Opus: тапсырманы түсіну, жоспар, шешім, оформление, пайдаланушыға көрсетер алдындағы соңғы тексеріс тек Opus-та.
- Бөлуге болатынды субагентке бер (бір хабарламада параллель): `obsidian-reader` (haiku) — Obsidian ережелері/аналог; `file-scout` (haiku) — файл іздеу; `script-worker` (sonnet) — нақты спек бойынша скрипт; `drawing-checker` (sonnet) — тәуелсіз тексеріс; `spec-calculator` (sonnet) — спецификация/есеп. Басқасы — әдепкі sonnet.
- Тапсырма беру: мақсат, кіріс/шығыс жолдары, қолданылатын ережелер, «дайын» критерийі — толық. Субагент шешім қабылдамайды; белгісіз болса сұрақ қайтарады.
- Субагент нәтижесіне соқыр сенбе: файлды/санды өзім тексеремін, содан кейін ғана көрсетемін. Сапа маңызды тексерісте `model: opus` берсе болады.
- 2–3 tool шақыруы жететін жұмысты өзім істеймін (агентке бермеймін).
