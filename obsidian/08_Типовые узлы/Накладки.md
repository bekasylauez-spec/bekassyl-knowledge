# Накладки

Ключевое уточнение: одна основная вертикальная арматура при накладочном соединении получает **2 накладки — с двух сторон**.

Поэтому 8 основных стержней → **16 накладок**.

На обычном стержне накладки располагаются с противоположных сторон, 180°. В угловом стержне колонны — **90°**, обе внутрь колонны.

Соединения выполняются вразбежку.

Для разных элементов граница нахлёст/накладка различается согласно нашим правилам:
- колонна: в общем случае Ø≤20 нахлест, Ø>20 накладка; но при смешанной схеме, где группа работает с накладками, все стержни этой схемы могут соединяться накладками, каждый по своему Ø;
- стена/пилон: Ø≤18 нахлест, Ø20+ накладка;
- ригель: длинные основные/дополнительные стержни соединяем накладками.
