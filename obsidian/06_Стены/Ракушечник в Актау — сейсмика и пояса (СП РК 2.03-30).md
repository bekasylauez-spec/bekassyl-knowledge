# Ракушечник в Актау — сейсмика и пояса (СП РК 2.03-30-2017)

## Сейсмичность Актау (Прил. Б)
| Карта | Актау |
|---|---|
| ОСЗ-2475 (классы отв. I–III) | 6 баллов |
| ОСЗ-22475 (класс IV) | 6 баллов |
| agR(475) / agR(2475) | 0,025g / 0,042g |

## Логика
1. **п. 1.1** — СП применяется при расчётной сейсмичности площадки **7, 8, 9, 10** баллов.
2. **Табл. 6.2** — сейсмичность площадки: грунт IA/IБ/II при зоне 6 → **6**; грунт **III** → **7**.
3. **Табл. 6.1** — тип III: пески рыхлые; пески водонасыщенные; глинистые IL>0,5; глинистые IL≤0,5 при e>0,9 (e>0,7 для супесей); vs,30<270 м/с. Прим. г): нет данных о IL/влажности и УГВ выше 5 м → тип III. Прим. в): прогноз подъёма УГВ → тип по замоченному состоянию.
4. Итог: тип грунта по ИГИ I или II → 6 баллов → СП 2.03-30 не применяется → антисейсмический пояс не обязателен (остаётся конструктивный армопояс по нормам кладки). Тип III → 7 баллов → все требования п. 9.9.

## Если 7 баллов — ограничения (п. 9.9, 9.1)
- **9.9.4** — камни из природных материалов (**ракушечник**, известняк, туф, песчаник) — только по отдельным нормативным документам, разработанным в развитие СП. Прямого допуска в СП нет → главный риск на экспертизе.
- 9.9.1 — перевязка однорядная цепная; при 7 баллах допускается многорядная, тычковый ряд не реже чем через 3 ложковых.
- 9.9.2 — облегчённая кладка с утеплителем внутри запрещена.
- 9.9.3 — раствор смешанный цементный марки ≥ М50.
- 9.9.7, 9.9.9, 9.9.10 — Rnt ≥ 120 кПа (1,2 кгс/см²) по испытаниям; если не получить — кладку для несущих стен не допускается; контрольные испытания обязательны.
- 9.9.11 — антисейсмические пояса в уровне всех перекрытий по всем несущим стенам (не нужны при монолитном перекрытии, заделанном по контуру, опирание ≥ 250 мм).
- 9.9.12 — верхний пояс связан с кладкой выпусками.
- 9.9.13 — пояс на всю ширину стены (при стене ≥510 — меньше до 150 мм), h ≥ 150 мм, бетон ≥ B12,5, продольная арматура ≥ 4Ø10 (7–8 баллов).
- 9.9.14 — сетки в сопряжениях стен As ≥ 1 см², L ≥ 1,5 м, шаг 700 мм по высоте.
- 9.9.17 — сердечники ≥ B15, связаны с поясами.
- 9.9.19 — высота этажа ≤ 5,0 м, h_эт / t ≤ 12 (комплексная конструкция ≤ 6,0 м).
- 9.9.20 — желательна внутренняя продольная стена; стены лестничной клетки на всю ширину.
- Табл. 9.4 — расстояние между поперечными стенами ≤ 12 м (комплексная ≤ 15 м).
- Табл. 9.5 — простенок ≥ 0,77 м (угловой +0,25); проём ≤ 3,5 м; простенок/проём ≥ 0,33; карниз из камня ≤ 0,2 м.
- 9.9.24 — площадки заделка ≥ 250 мм; консольные ступени запрещены.
- 9.9.25 — балкон ≤ 1,5 м; 9.9.26 — парапет > 400 мм армировать.
- 9.9.27–28 — перемычки заделка ≥ 350 мм (≤1,5 м — 250 мм); брусковые сборные перемычки запрещены.
- 9.9.30 — направление раскладки сборных плит не менять в пределах отсека.
- Табл. 9.1 — длина/ширина отсека ≤ 80 м (не ЖБ системы).
- Табл. 9.2 п. 5 — каменная кладка: ≤ 16 м (4 этажа); комплексная — 21 м (6 эт.).

## Не проверено
- Есть ли более новая редакция/изменения СП после 2019 г.
- Действующий отдельный документ по ракушечнику (п. 9.9.4).
- Требования для 6 баллов по СП РК EN 1996 / НП — отдельно.
