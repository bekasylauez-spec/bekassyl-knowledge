# 01. Модель — шаблон, параметрлер, атаулар, фильтрлер (BI Group)

Жазылған: 17.11.2026. Дерек: S03 моделінің API дампы (`out\d01…d07`, `a04_conventions.txt`), S05-пен салыстырылды. Аясы: тек BI жобалары (`00_ОҚЫ_АЛДЫМЕН`).

## 1. Шаблон және файл

- Шаблон BI: жоба параметрі `BI_версия_шаблона = 3,51`. Барлық тип, семейство, кесте, фильтр, вид шаблоны — шаблондікі; жаңасын ойлап таппаймын, барын көшіріп атын өзгертемін.
- Файл workshared. Рабочий наборлар: `Рабочий набор1` (бетон: стена, плита, фундамент), `Общие слои и сетки`, және **әр орындаушыға өз аты жазылған набор** (S03-те 19 набор) — арматура орындаушының наборында.
- Деңгейлер: `-01 Подвал`, `01 Этаж` … `17 Этаж`, `100 Кровля`, `101 Будка`; типі `(уровень)стрелка_проектная_вверх_имя_уровня`.
- Жоба параметрлері: `Округление нахлеста = 10` (мм), `BI_абсолютная_отметка_нуля`, `BI_секция`, `BI_общая_масса_арматуры`.
- Браузер: видтер `01_Стены / 02_Плиты / 03_Фундаменты / 04_Каркасы / 05_Колонны / 06_Балки / 07_Лестницы`; парақтар `00_По конструкциям / 02_Фундамент / 03_Каркас / 04_Стены / 07_Плиты …`; кестелер де сондай. Браузер сүзгісі параметрге қарайды — параметр толтырылмаған вид/парақ көрінбейді (4-бөлім).

## 3. Марка жүйесі

- **Конструкция маркасы** хосттың стандарт «Марка» параметрінде: `СЖм-1` (стена жесткости), `СШм-1` (стена шахты), `Пм-6`, `Фм-1`, `Бм-1`, `ЛМм-1` (марш), `ЛПм-1` (площадка), `ПРПм-1` (парапет). Бір маркаға барлық қабаттағы стена кіреді (СЖм-1 = 18 стена элементі).
- **Арматурада** сол марка `BI_марка_конструкции` параметрінде (хосттан автоматты түспейді — қолмен/скриптпен жазылады). Барлық кесте мен фильтр осы параметрге сүйенеді.
- Хост **сборкаға** (Assembly) салынған: тип аттары `Стена 10`, `Плита 91`, `Фундамент 6`, `Бм-1`; хостта `BI_главный_элемент = Да`, `BI_этаж`. Сборкалар `1СА-конструкция_(сборка)` және `3ВМ(сборка)` кестелері үшін (бетон көлемі).
- Қайталанатын арматура **группа моделіне** жиналады: `Каркас Кр-1` (121 дана), `ЛМм-2. общ арм`, плита арматурасы қабаттарға группамен көшірілген.
- `BI_этаж` — қабат нөмірі (−1, 1 … 17): стена кестелері «поэтажно» соған қарай бөлінеді.

## 5. Арматура типтері

Әр диаметрге төрт тип: кәдімгі, `каркас`, `пм`, `каркас пм`.

| Қосымша | Тип параметрі | Мағынасы |
|---|---|---|
| (жоқ) | `BI_тип_элемента_КЖ = 1`, `BI_в_погонных_метрах = Нет` | дана стержень: кестеде `L=… / саны` |
| `пм` | `BI_в_погонных_метрах = Да` | **погонный метр**: кестеде `п.м. / метраж`, нахлёст автоматты қосылады (негізгі тор, ұзын көлденең стержень) |
| `каркас` | `BI_тип_элемента_КЖ = 2`, `BI_фильтр_арматуры = Каркас` | изделие (каркас) ішіндегі стержень; `BI_марка_изделия` (Кр-2, Ф1) толтырылады |
| `каркас пм` | екеуі де | каркас ішіндегі погонный стержень |

## 6. Формалар, префикстер, позиция

| Форма | `RAS_префикс` | `BI_примечание` | Не | Отгиб |
|---|---|---|---|---|
| `(форма)1` | — | — | түзу стержень | — |
| `(форма)21` | **Ск** | пшка | П-тәрізді (скоба): A, B, C | — |
| `(форма)хомут` | **Х** | хомут | тұйық хомут: A, B, C=100 | «Стандартный - 135 градусов» |
| `(форма)шпилька S` | **Ш** | — | стена шпилькасы (S-тәрізді) | «Стандартный сейсмический - 180 градусов» |
| `(форма)шпилька` | **Ш** | шпилька | плита шпилькасы | 180° |
| `(форма)98_лягушка` | **Ф** | — | фиксатор («лягушка») | «Парапет_Анкеровка_90°» |
| `(форма)11` | **Г** | гшка | Г-тәрізді | — |
| `(форма)15` | **Г** | v-образный_ф15 | V-тәрізді (лестница, приямок) | — |
| `(форма)26_угол_больше_90…` | — | z-об_+90 | Z-тәрізді | — |

- Префикс пен ескерту — **форманың өз параметрі** (тек оқуға), стерженьде қолмен жазылмайды. Марка мәтіні = `RAS_префикс` + `BI_позиция` → `Ск24`, `Х3`, `Ш1`; түзу стержень — тек нөмір (`12`, `26`).
- Өлшемдер ведомость деталей үшін: `BI_A`, `BI_B`, `BI_C`, `BI_H1`, `BI_H2`, `BI_α`, `BI_арматура_длина_по_прямой`, `BI_арматура_гнутая` (Да/Нет автоматты).
- `BI_позиция` — **марка ішінде** нөмірленеді (әр СЖм, Пм өз 1, 2, 3 …). Изделие ішіндегі позиция — әріппен (`а`, `б`, `в`, `г`, `ж`, `з`).
- Плитада негізгі тор бір позиция (`2`), доп. стерженьдер Ø мен ұзындық бойынша әрқайсысы бөлек позиция.

| | `Доп` | қосымша (тік те, көлденең де) |
| | `Попереч` | хомут, шпилька |

## 8. Вид фильтрлері

- Арматура: `Арм_Верт`, `Арм_Гор`, `Арм_Доп`, `Арм_Попереч`, `Арм_Каркас`, `Арм_осн`, `Арм_Низ_X_(НизГор)`, `Арм_Низ_Y_(НизВерт)`, `Арм_Верх_X_(ВерхГор)`, `Арм_Верх_Y(ВерхВерт)`, `Арм_ДопНиз_X`, `Арм_ДопНиз_Y`, `Арм_ДопВерх_X`, `Арм_ДопВерх_Y` — бәрі `BI_фильтр Equals "<мән>"`. `Арм_Хомуты и шпилька` — «Форма» атауында «хомут» не «шпилька». `Арм_Каркас` — `BI_фильтр_арматуры = Каркас` НЕМЕСЕ `BI_фильтр = Каркас`.
- **Әр маркаға үш фильтр:** `#<Марка>_Армирование` (`BI_марка_конструкции ≠ <Марка>` → жасыру), `#<Марка>_Разрезы` (басқа марканың қималарын жасыру), `#<Марка> Выпуск` (басқа марканың выпускін жасыру). S03-те 99 марка × 3.
- Видтер: `А_Виды_…` (топ, мақсат, атау бойынша), `Разрезы_Армирование`, `Разрезы_Опалубка`, `Разрез Стены`, `Выпуски_Разрезы`, `УБРАТЬ ВСЕ РАЗРЕЗЫ`. Модель: `М_(ФНК)_ГрупМод_(Подготовка)`, `М_(ПР)_КмнтТип_(капитель)` …
- Қолданылуы: фильтр «көрінбейтін» етіп қойылады (жасыру); көрші стенаның арматурасын қимада қалдыру керек болса — «полутон» (halftone).
- Шаблон фильтрді, масштабты, детализацияны **басқармайды** — олар әр видте бөлек.
