# BI Group — КЖ (Revit) ережелері. Осыдан баста

Жазылған: 17.11.2026.
Источник: пайдаланушы 16.11.2026 — «Менде Revit 2026-да файл ашық тұр, онда армирование бар. Толық оқып үйреніп шық: основной армирование қалай жасалған, доп қалай, стенаның оформлениесін қара. Сосын ережелерін BI group деп жеке Obsidian-ға және GitHub-қа жаса. Бұл тәсілдер BI-дің проектеріне арналған ережелер».

## 1. Қолданылу аясы

- **Тек BI Group жобаларына.** Басқа объектілерге бұрынғы ережелер қолданылады (`01`–`18` папкалар, `ЕРЕЖЕЛЕР.md`).
- Жоба BI-дікі екенін білу: пайдаланушы айтады; не модельде `BI_версия_шаблона`, `BI_марка_конструкции`, `BI_фильтр` параметрлері және `(основная_надпись) : Форма 3` штампы бар.
- BI жобасында **модельдеу тәсілі мен оформление — осы папкадан**. Жұмыс тәртібі (алдымен оқу, паспорт, тексеріс, файлдарды таза ұстау, пайдаланушы Revit-іне тимеу) — жалпы ережелерден (`~/.claude/CLAUDE.md`).
- Қайшылық реті: пайдаланушының осы чаттағы сөзі → осы папка → жалпы ережелер. Айырмашылықтар тізімі: `07`-файл, 1-бөлім.
- Мұнда жазылғанның бәрі — үлгі модельден **оқылған факт**. Диаметр, шаг, отметка — әр жобаның өз есебінен; ереже — *қалай модельденеді және қалай көрсетіледі*.

## 4. Ең маңызды он ереже (қысқаша)

1. **Бәрі жеке `Rebar` жиыны.** «Армирование по площади / по траектории», сетка қолданылмайды. Раскладка — «Число с интервалом» (не «Один»), зависимость — өшірулі.
2. **Әр стерженьде төрт параметр міндетті:** `BI_марка_конструкции` (СЖм-1, Пм-6, Фм-1), `BI_позиция`, `BI_фильтр` (Верт / Гор / Доп / Попереч / ДопНиз_X …), `BI_этаж`.
3. **Негізгі арматура тұтас модельденеді:** плитаның шетінен шетіне дейін бір стержень (28,86 м болса да), типі `… пм` («в погонных метрах»). Нахлёст модельде сызылмайды — оны кесте қосады: стык саны × `k·d` (10 мм-ге дөңгелектеп).
4. **Стенаның тік арматурасы қабат сайын бөлек:** ұзындық = қабат биіктігі + нахлёст; стыктар 50 % вразбежку; ұзындықтар «Узлы стыковки» парағының кестесінен (бетон класына қарай: B25 ≈ 61d, B30 ≈ 51d).
5. **Доп. арматура — бөлек стерженьдер, бөлек `BI_фильтр`:** плитада `ДопНиз_X`, `ДопНиз_Y`, `ДопВерх_X`, `ДопВерх_Y` (әрқайсысы бөлек парақ), стенада `Доп`.
6. **Бір парақ — бір топ арматура.** Видтегі фильтрлер қалғанын жасырады (`Арм_Верт`, `Арм_Гор`, `Арм_Доп`, `Арм_Хомуты и шпилька`, `#СЖм-1_Армирование`). Шаблон фильтрлерді басқармайды — олар әр видте қолмен.
7. **Диаметр түспен ажыратылады** (арматура подкатегориясы `Ø12`, `Ø14` …): Ø12 қою жасыл, Ø14 ашық жасыл, Ø16 көк, Ø18 қызғылт сары, Ø20 күлгін-қызыл, Ø22 қою күлгін, Ø25 қызыл.
8. **Позиция «MRA поз.» арқылы қойылады:** шаг тізбегі `200х12=2400` түрінде + полкадағы позиция нөмірі. Гнутый бөлшек маркасы префикспен: `Ск` (П-шка), `Х` (хомут), `Ш` (шпилька), `Ф` (фиксатор).
9. **Стена парақтары:** опалубка → тік + көлденең схема (бір парақта екі развертка, 1:100) → доп схема → қималар 1:25 → спецификация поэтажно → ведомость деталей → ВРС. Формат А1-ге дейін.
10. **Кестелер шаблондікі:** `(Группа)_<Марка>_1СА / 2СА / 3ВМ / 4ВД / 5ВРС`, сүзгі `BI_марка_конструкции = <Марка>`. Қолмен кесте сызылмайды.
