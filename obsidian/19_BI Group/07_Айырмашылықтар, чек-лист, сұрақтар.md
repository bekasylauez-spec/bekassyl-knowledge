# 07. Айырмашылықтар, чек-лист, сұрақтар (BI Group)

Жазылған: 17.11.2026. Аясы: тек BI жобалары.

## 1. BI тәсілі ↔ өз ережелеріміз

Екі баған да дұрыс — әрқайсысы өз жобасында. BI жобасында сол баған қолданылады; араластырмаймын.

| Тақырып | Өз ережеміз (жалпы) | BI жобасында |
|---|---|---|
| Парақ форматы | А3, сыймаса А2; А1 жоқ | стена развёрткасы мен қималары **А1** (S03: 98 парақ А1), плита схемасы А3, қалғаны А2 — *расталды 17.11.2026* |
| Шрифт | ISOCPEUR 2,5 мм, атау 3,0–3,5 | ISOCPEUR 2,5 мм **курсив**, ені 0,9; атау 3,5 курсив — *расталды 17.11.2026* |
| Нахлёст | 71d / 61d (кесте) | бетон класына қарай «Узлы стыковки» кестесі: B25 ≈ 61d, B30 ≈ 51d; разбежка аралығы ≈ 0,3·l — *расталды 17.11.2026* |
| Негізгі тор | тұтас, шеттен шетке | тұтас стержень, типі `пм`; нахлёст модельде жоқ, кестеде есептеледі |
| Доп. арматура | әр бөлікке жеке аймақ; ойықтан өтпейді | сол сияқты + төрт топқа (`ДопНиз/Верх_X/Y`) бөлініп, **төрт бөлек парақта** |
| Позиция белгісі | СПДС выноска, полка стрелкаға қарсы | Revit маркасы полкамен (7 / 12 / 15 мм) + **MRA `поз.`**; гнутый бөлшекте префикс `Ск`, `Х`, `Ш`, `Ф`, `Г` |
| Шаг тізбегі | `200х11=2200` | бірдей: `200х12=2400` (MRA автоматты не размер префиксі) |
| Диаметрді ажырату | выноска мәтінімен | **түспен** (арматура подкатегориясы) |
| Бір парақ — бір масштаб | иә | жоқ: план 1:100 + қима 1:50 (Фм) не легенда 1:20 (плита) бір парақта |
| Қима (плита) | нақты қима | шартты қима — қолмен сызылған **легенда** |
| Отверстие | бір диагональ | бірдей (`Обозначение_проема_прямоугольный`) |
| Обрамление отверстия | сызылады | 3D-де сызылмайды: типтік узел парағы + «пустой» семейство → «Спецификация на усиление отверстий» |
| Спецификация | шаблонның СА / ВМ / ВД / ВРС кестелері | бірдей (сол шаблон) |
| Ведомость деталей | барлық гнутый позиция эскизімен | бірдей (`4ВД`, сүзгі `BI_арматура_гнутая`) |
| Бетон штрихы | ANSI36, масштаб 20 | `(цветовая_область)бетон` / материал штрихы (`BI_бетон_разрез_вверх_1,5мм`) |
| Стена қималары | — | әр қабатқа белгі, қайталанатыны «по N»; көлденең қима 1:25 |
| Примечание | парақта мәтін | парақ параметрі `BI_примечание_расширенное` (штамп өзі шығарады) |

**17.11.2026:** пайдаланушы «BI жобасында» бағанын толық, сол күйінде қабылдады («Иә, үлгідегідей», «полный қарап қалай бар солай қабылдап сақта ок») — 3-бөлім.

## 2. BI жобасында жұмыс чек-листі

**Бастамас бұрын**
1. `std-pull.ps1` → осы папканың `00`-файлы → жұмысқа сай файл (`02` / `03` / `04` / `05` / `06`).
2. Шаблон: BI КЖ шаблоны (нұсқасын пайдаланушыдан растау — 3-бөлім, 9-сұрақ). Жаңа тип/семейство жасамаймын — шаблондағыны көшіремін.
3. Бетон класы әр конструкцияға белгілі ме (тип атында `B30`) — нахлёст кестесі соған байланысты.

**Модель**
4. Хост типі атау үлгісімен; «Марка» = конструкция маркасы; хост сборкада; `BI_этаж`, `BI_главный_элемент`.
5. Арматура типі: тұтас негізгі — `… пм`; дана — қосымшасыз; изделие ішіндегі — `… каркас`.
6. Раскладка «Число с интервалом»; форма шаблондікі (`(форма)1`, `21`, `хомут`, `шпилька S` …).
7. Әр стерженьде: `BI_марка_конструкции`, `BI_позиция`, `BI_фильтр`, `BI_этаж`. Тексеру скрипті: бос параметрлі стержень саны = 0 (хомут/шпилькада `BI_фильтр = Попереч`).
8. Стена тік арматурасы: L = қабат + нахлёст (кестеден), 50 % разбежка; көлденең: 50 / 200×n / 200 / 100×3 / 50; шетінде Ск.
9. Позициялар: бір позиция = бір Ø + бір өлшем; нөмірлеу спецификация ретімен.

**Видтер мен парақтар**
10. Вид шаблон видінен көшіріледі; `BI_группирование`, `BI_назначение_вида`, `BI_комментарии_к_виду`, `BI_марка_конструкции` толтырылады.
11. Фильтрлер: бір видте бір топ; өз маркасының `#<Марка>_Армирование` фильтрі — жасыру күйінде (қимада көршіге — полутон).
12. Аннотация тек шаблон типтерімен: MRA `поз.`, марка `Позиция_7` / `Позиция/Шаг_12`, размер `BI_основной_2,5мм_округление_до_5мм`, отметка `BI_стрелка_проектная_вверх`, мәтін `BI_основной_текст_2,5_к`.
13. Парақ: штамп `Форма 3`; `BI_штамп_имя_листа_пользовательское`, `BI_штамп_раздел_проекта = КЖ`; примечание `BI_примечание_расширенное`-ге.
14. Кестелер: маркаға көшіру (`1СА/2СА`, `3ВМ`, `4ВД`, `5ВРС`), сүзгідегі марканы ауыстыру.

**Көрсетпес бұрын**
15. Кесте массасы ↔ модель: `пм` жолында метраж модельден артық (нахлёст) — айырма стык санына сай ма.
16. Парақтағы MRA тізбектерінің қосындысы конструкция өлшеміне тең бе.
17. «см. л. КЖ-…» сілтемелері толық па; марка жазылуы біркелкі ме.
18. Ведомость деталей-де бір позиция бірнеше өлшеммен шықпай ма.
19. Әр парақты PDF-ке шығарып, бөліп жақындатып қарау (жалпы тексеріс ережесі).

## 3. Пайдаланушы шешімдері (17.11.2026)

Пайдаланушы екі жауап берді:
1. «BI жобасында А1, курсив, B25/B30 нахлёст кестесін үлгідегідей қолданайын ба?» — **«Иә, үлгідегідей»**.
2. Қалған сұрақтарға — **«полный қарап қалай бар солай қабылдап сақта ок»**: үлгі тәсілдері толық, сол күйінде қабылданады.

Яғни BI жобасында үлгі (Омар S03 / S05) қалай жасалса — солай жасаймын; жалпы ережелерімізбен «түзетпеймін». Бұл тек BI жобаларына: басқа объектіде А3 / А2, курсивсіз мәтін, 71d / 61d және қалған жалпы ережелер өзгермейді.

| № | Сұрақ | Шешім |
|---|---|---|
| 1 | А1 формат | **Үлгідегідей.** Стена развёрткасы мен қималары А1; плита схемасы А3; қалғаны А2 |
| 2 | Курсив | **Үлгідегідей.** ISOCPEUR 2,5 мм курсив, ені 0,9; шаблон типтері өзгермейді |
| 3 | Нахлёст кестесі | **Үлгідегідей.** «Узлы стыковки» B25 / B30 кестелері (`02`-файл, 3-бөлім), бетон класына қарай |
| 4 | Плита қорғаныс қабаты (легендада `20*` / `35*`, модельде 40 / 30) | **Үлгідегідей.** Стержень деңгейі үлгі модельдегідей (ось: асты 35 және 45, үсті 45 және 55); шартты қима легендасы шаблоннан өзгеріссіз көшіріледі |
| 5 | Доп. стержень деңгейі | **Үлгідегідей** — шартты деңгейде (`03`-файл, 2.2-бөлім), негізгі тор қабатына дәл келтірілмейді |
| 6 | Отверстие обрамлениесі | **Үлгідегідей** — 3D-де сызылмайды: типтік узел парағы + «пустой» семейство → «Спецификация на усиление отверстий» |
| 7 | Стенаның тік және көлденең схемасы | **Үлгідегідей** — бір А1 парақта қатар; үлкен стенада екі бөлек парақ (`04`-файл, 1-бөлім) |
| 8 | Позиция нөмірлеу | **Үлгідегідей** — марка ішінде, спецификация ретімен, гнутый бөлшекке префикс `Ск / Х / Ш / Ф / Г` (`01`-файл, 6-бөлім) |
| 10 | Плита шпилькаларының `BI_фильтр`-і | Үлгінің өзінде екі нұсқа бар (S03 — бос, S05 — `Попереч`); екеуінде де вид `Арм_Хомуты и шпилька` фильтрімен көрсетіледі. `Попереч` қоямын (S05-тегідей, стенамен біркелкі) — екі нұсқаның біреуін таңдау менің шешімім |

**Тәсіл деп қабылданбағаны — үлгінің анық қателері (4-бөлім):** бос сілтемелер, жазу қателері, жоқ ГОСТ нөмірі, бір позицияның бірнеше өлшеммен шығуы, тазаланбаған көшірме видтер. Бұлар тәсіл емес, орындау қатесі, сондықтан көшірмеймін. Оларды да сол күйі қалдыру керек болса — пайдаланушы айтады.

## 4. Үлгідегі қателер (ереже емес — қайталамаймын)

- Бір позиция бірнеше өлшеммен: СЖм-1 ведомость деталей — `Ск9` (4 түрі), `Ск13` (3), `Ск26` (4), `Ск4`, `Ск10`, `Ск18`, `Ск28`.
- Бос сілтемелер «см. л. КЖ- » (опалубка парақтарында «Схему расположения монолитных стен см. л. КЖ- »).
- Атау қателері: «Стена жескости», «Схема расположение элементов», «Схема армирование», «Фрагмент6.», «горизонатльного»; марка жазылуы аралас (`Пм6` / `Пм-6`, `Пм1` / `Пм-1`); «Плита покрытия Пм-1 на отм. −0.100» (перекрытия).
- «Вязальной проволокой Ø 1,6 мм (ГОСТ 2333-8)» — мұндай ГОСТ жоқ (вязальная проволока — ГОСТ 3282-74).
- «Узлы стыковки» B25: Ø18 нахлёст тік кестеде 1100, көлденең кестеде 1110.
- ВРС-те «А240 (ГОСТ 34028-2016)», ал тип параметрінде А240 — СТ РК 2591-2014.
- Примечаниеде «Шаг горизонтальной арматуры … см. на л. раскладки горизонтальной арматуры» — альбомда мұндай бөлек парақ жоқ (шаг көлденең схеманың өзінде).
- Плита легендасының сандары (`20*`, `35*`) модельге дәл сай емес — бірақ пайдаланушы шешімімен үлгідегідей қалдырылады (3-бөлім, 4).
- `BI_фильтр`: S03-те плита шпилькаларында бос; S05-те 397 стерженьге фильтр атауы (`Арм_Хомуты и шпилька`) мән ретінде жазылған.
- Жоғарғы қабат плиталарында хосттың «Марка»-сы бос (тек Пм-1, Пм-2-де толтырылған); 49 стенада «Марка» бос.
- «копия 1 / копия 2» атаулы видтер (62) мен кестелер (26) тазаланбаған.
- 70 шақты жиында «зависимость» қосулы қалған (қалған 51 мыңы өшірулі).

## 5. Бұл талдауда не қамтылмады

- Лестница (ЛМм, ЛПм), парапет, балка, колонна парақтары — тек тізім деңгейінде қаралды (үлгі стеновая жүйе; сұрақ 11).
- Кесте формулалары (нахлёст есебі) — өріс атауларынан және нәтижеден тексерілді, формула мәтіні API-де жоқ.
- Общие данные мәтіні — жобаға тән (климат, грунт, нормалар), ереже ретінде алынбады.
