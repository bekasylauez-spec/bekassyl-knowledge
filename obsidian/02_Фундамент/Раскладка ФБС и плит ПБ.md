# Раскладка ФБС (сборный ленточный) и плит ПБ

Утверждено пользователем 05.11.2026 (Ақтау қыз, ул. Мереке 14/16, TUNAY STROY).

## ФБС
- Размеры блоков — только заводской стандарт (прайс завода в папке проекта). Ақтау: ТОО «КИС-Актау» (полный перечень), ФБС 24/12/9.4.6-т (2380/1180/880 × 400 × 580), шов 20 → модуль 2400/1200/900, высота ряда 600.
- Ряды чередуются: 1-й ряд — сквозные горизонтальные стены (углы/тавры), 2-й ряд — сквозные вертикальные. Перевязка вертикальных швов соседних рядов ≥ 300 мм (норма 0,4h = 240) — проверять скриптом.
- Доборы (остаток не кратен блокам) — **монолитные вставки** (бетон В15), ≥ 200 мм, ставить у торца/узла; под колоннами — монолит В20 400×400 на всю высоту рядов (выпуски колонн).
- Остаток ≤ 40 мм — уходит в швы, монолит не нужен.
- Стена, где план шире 400 (напр. 800), — два ряда блоков 400 рядом, швы со смещением.
- Отметки берутся из разреза КЖ: подошва −1.700…−1.400, 1-й ряд −1.400…−0.800, 2-й ряд −0.800…−0.200, пояс 200 до 0.000; грунт/котлован с листа котлована.

## Плиты ПБ (над 1-м этажом)
- Пролёт по короткому направлению между несущими стенами; длина = пролёт по осям − 20 (ПБ 54 для 5400, ПБ 20 для 2100), опирание ≥ 120 (факт 140–190).
- Ширины 1.5/1.2/1.0 м: минимум штук, остаток ≤ 100 мм — в швы/зазоры у стены.
- Где под плитой нет стены (колонны в коридоре) — монолитный участок Му-1.
- Стены под плитами — штриховой линией (HIDDEN), марка П1… на плите, по плите диагональ.

## Оформление
- Листы — копия рамки СПДС соседнего листа (3.1) + блок штампа «крпкер» + MTEXT имени/номера; копирование СПДС только в полном AutoCAD (accoreconsole не копирует proxy).
- План — копия планa осей с размерами из DWG пользователя; марки блоков 2.5 мм (1/2/3) внутри блока; монолит ANSI36 20.
- Спецификация: Поз./Обозначение/Наименование/Кол./Масса/Примечание (185 мм); текст не должен выходить за ячейку.

Скрипты: scratchpad сессии 4c62aff2 `gen.py` (раскладка + проверка перевязки), `gen_lsp.py` + `fjob_core.lsp` (LISP для своего acad.exe: `acad.exe /nologo /b scr`, в scr `_.OPEN` — с файлом в аргументе скрипт не стартует).

## Подошва под ФБС (Фм-1), 05.11.2026
- Монолитная подошва 800×300 (−1.700…−1.400), В25, подбетонка 100 В7.5; под двойной стеной ФБС (800) подошва 1200.
- Листы по аналогу старого альбома (лист 4 опалубка + лист 5 спецификация): объекты аналога переносить WBLOCK из исходного DWG → INSERT «*» в рабочий файл; SPDS-разрезы переставлять piecewise-переносом по осям старый→новый план, лишние (на стенах, которых нет) удалять.
- Арматура считать для обоих рядов (верх+низ по 5 Ø14 ш.200) — в старом аналоге посчитан один ряд. Ск1 по 5 шт. в каждом углу/тавре.
- Разрез 1-1 М1:20 не влезает справа от плана 1:100 на А3 → ставить на лист спецификации.

## Фундаментный пояс ФП-1 (поверх ФБС), 05.11.2026
- Пользователь: 4 стержня Ø12, хомут шаг 300. Принято: 400×200 (−0.200…0.000), В25, 4Ø12 А500С (2 верх + 2 низ), хомут Х2 Ø8 А240 ш.300 (Ø хомута не задан — взят как Х1 подошвы), Г1 Ø12 по 4 шт. в углах/тавровых узлах, нахлёст Ø12 860.
- Листы: схема пояса (план из 3.5 без подошвы) + сечение 1-1 М1:10 справа; спецификация/ведомость деталей/ведомость стали отдельным листом.
- Пользователь убрал двойную стену 800 по оси 6 C–D (3.7, контур 3.5) → пояс везде 400; 3.8 и подошва 1200 на 3.5 ещё со старой стеной — согласовать.
