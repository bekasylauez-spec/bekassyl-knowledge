# Коэффициент поведения q — что это и какой брать по НТП

**Пост #335, 11.10.2026 · видео 7:52 · YouTube: https://youtu.be/Q9BLgor7PYY** (просмотрено по субтитрам)

## Идея
Пример из норм: грунт II, ag = 0,44g → упругий спектр, площадка **1,1g**, а здание считают на **0,37g (q=3)** или **0,22g (q=5)**. Здание может повредиться, но не обрушиться; энергия гасится в пластических шарнирах (концы балок, низ колонн и стен). q = сила на упругое здание / расчётная сила (НТП РК 08-01.1-2017, 4.2.5). Расчётный спектр = упругий / q, но **не ниже 0,2·ag** (граница на длинных периодах).

## Класс пластичности
- **DCL**: q = 1,5 для любой системы, но на площадках **7–10 баллов не допускается** (табл. 2.3 НТП 08-01.3) → на практике **DCM**.
- Большой q работает только при выполнении всех правил DCM: сильная колонна–слабая балка, частые хомуты в крит. зонах, ограничение сжатия νd.
- Класс пластичности **один на всё здание**.

## Тип системы — по доле горизонтальной нагрузки
| Система | Кто берёт горизонталь |
|---|---|
| Рамная | рамы > 65 % |
| Двойная (рамная) | рамы > 50 %, стены 35–50 % |
| Двойная, эквивалентная стеновой | стены > 50 %, вертикаль в основном рамы |
| Стеновая | стены > 65 % горизонтали + большая часть вертикали |

## Таблица 2.1 (DCM, регулярные и умеренно нерегулярные)
| Система | q |
|---|---|
| Рамы, двойные рамные | **3,9** |
| Стены несвязанные | **4,2** |
| Стены связанные / двойные экв. стеновым | **4,5** |
| Стены ≥ 90 % сейсмики и каркас ≥ 25 % | **5,0** |
| Перекрёстно-стеновая (стены вдоль/поперёк шаг ≤ 6 м, опирание по контуру) | **5,0** |
| Одна глухая стена в направлении | **3,3** |
| Несколько стен на одной оси | **3,6** |
| Крутильно-податливая | **2,0** |
| Перевёрнутый маятник (≥ ½ массы в верхней трети) | **1,5** |

## Связанные стены
Критерий: ΣMw,c (с перемычками) ≤ **0,75**·ΣMw,unc (без перемычек) → нужны **два расчёта** с одной силой наверху. Пример прил. А: две стены по 1,5 м, проём 3 м: 15 000 → **2 120 кН·м** (−86 %) → связанные; простенки по 7 м: 11 690 (−22 %, < 25 %) → не связаны.

## Разные q по X и Y — можно
Тип системы определяют отдельно в каждом направлении (кроме крутильно-податливой — там нельзя делить).

## Паркинг (подземный)
- Стен по периметру много → двойная экв. стеновой **4,5** (или **5,0** если стены ≥ 90 %, каркас ≥ 25 %).
- Стен мало, колонны с ригелями → рамная **3,9**.
- Безригельный (колонны + плоские плиты) — наши нормы по монолиту **не рассматривают**.
- Для паркинга регулярность в плане можно не оценивать, коэффициент случайного кручения = 2.

## Порядок
1) кто берёт горизонталь по X и по Y → 2) для стен: два расчёта, связаны ли → 3) q из табл. 2.1 → 4) выполнить **все** правила DCM.
