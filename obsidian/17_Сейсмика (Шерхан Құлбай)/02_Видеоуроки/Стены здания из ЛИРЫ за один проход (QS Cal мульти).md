# Все стены здания из ЛИРЫ за один проход — QS Cal «Здание — изгибные стены»

**Пост #375, 15.10.2026 · видео 21:39 · https://youtu.be/dsp9_Km8Gyw**

## Что нужно из ЛИРЫ (3 вещи)
1. **Текстовый файл задачи** (Файл → Создать текстовый файл; папка — Настройки → Каталоги → Текстовые файлы).
2. **Усилия от РСН в стержневых аналогах** стен: выделить все вертикальные стержни-аналоги (рамкой + фрагментация), Анализ → Документация → Стандартные таблицы → Результаты → «Усилия от РСН» → Excel.
3. **T1** — Стандартные таблицы → Периоды колебаний (пример 0,818 → 0,82 с).
Пример: 13 эт. + подвал, 60 стен, 657 аналогов. Вручную — сейсмика: q=4,5, грунт II, T1, коэффициент к V = 1,5.

## Результат
Расчёт всех стен ~13 мин. **Мозаика** по этажам и по проверке (νd, краевая зона, конструктивные, арматура). Клик → карточка стены → открыть в калькуляторе «Изгибная стена» по шагам.

## Функции плана
- **Т- и Г-узлы** находит по геометрии; у пересечения краевая зона ≥ **3bw** (п. 5.7.2.9).
- Г/Т/П-сечения считаются **одним составным элементом** (п. 5.6.4) — группировка.
- **Короткий простенок** (l < 4bw) — «как колонна» (п. 5.3.4): предел νd по колонной формуле 0,65·γ (12 эт. → 0,718); армирование — из ЛИРЫ. Пример 350×650: 0,689 < 0,718 — проходит.
- **Шахта лифта** (5 стен по 200): «найти кандидатов по геометрии» → одно сечение, косой изгиб, ячейки 50 мм; стена, не проходившая одна (0,58), в шахте проходит. Сверка с **ETABS**: нижние этажи −6…+4 %, верхние — калькулятор строже до 10 %. Отличия ETABS: краевые зоны по каждой стене отдельно; мин. армирование 0,25 % (у нас **0,5 %** в краевых элементах); V усиливает по DCH-формуле.

## Одна стена 300×6900 по шагам (подвал + 12 эт., H=39,6 м, hcr = 6,6 м)
- νd = 0,261 (подвал 0,271) при пределе 0,512.
- μφ: T1=0,82 > TC=0,64 → 2·4,5−1 = 8 × 1,5 (класс B) = **12**.
- lc: xu = 3292, расчёт 2983 → принято **3250** (округление до 50 мм, книзу не уменьшается).
- Вертикальная: послойный анализ, εcu = 0,0035, два вложенных цикла половинного деления (xu → N, As → M), 14 итераций → 6523 мм² (мин. 0,5 % lc = 4875) → **34Ø16 = 6836 мм²**; 12-й этаж 18Ø12.
- Горизонтальная: V×1,5 (п. 5.5.2), подкос 45°, z = 0,9d = 6165; мин. 300 мм²/м (п. 5.7.2.14); 5834 кН < 12 000 кН (бетон) → 2Ø18 шаг 200.
- α·ωwd = 0,383 ≥ 0,338 → хомуты Ø12 шаг 100; над крит. зоной — половина (п. 5.7.3.3).
- Отчёт: PDF «для экспертизы», DXF чертежи стен для AutoCAD, сборник.
