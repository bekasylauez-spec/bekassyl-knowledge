# Telegram-бот: модель грунта для ЛИРЫ по отчёту изысканий (SLD)

**Пост #413, 17.10.2026 · видео 2:39 · https://youtu.be/zYhWAZc4SUk · Бот: https://t.me/qs_soil_model_bot** (по подписке)

- Отправляешь отчёт об изысканиях (сводная ведомость, паспорта проб, схема выработок, разрезы DWG) → бот возвращает **SLD для ЛИРА-САПР** + сводку по ИГЭ.
- По каждому ИГЭ: E, ρ, c, φ — у **каждой цифры источник** (раздел, строка таблицы, напр. «раздел 5, строка 15, водонасыщенное»). Кнопки: средние или максимальные значения.
- ИГЭ ниже УГВ — отдельный материал с флагом **«Вода»**; насыпной и почвенный слой сняты.
- Отдельный список **спорных мест отчёта** (пример: разрез 19 нарисован зеркально подписям скважин; у двух скважин нет знаков на плане — восстановлены по разрезу).
- Контроль: SLD читается обратно — 10 материалов, 138 скважин, 616 слоёв; расстояния по разрезам 97/97.
- Пример: **138 скважин, 9 ИГЭ** — вручную в ЛИРЕ долго и с ошибками.
- «Модель из бота — исходные данные, а не готовое решение»: значения проверять.
