# Изгибная стена DCM по Еврокоду 8 и сверка с ЛИРОЙ

**Пост #343, 12.10.2026 · видео 7:32 · https://youtu.be/zztt-Plwa48**

## Шаги расчёта
1. **νd = NEd/(Ac·fcd)** — для DCM ≤ **0,4** (по НТП — 0,4·γ, растёт с этажностью; 12 эт. → 0,512).
2. **μφ** — коэффициент пластичности по кривизне: μφ = 2q0 − 1 (если T1 ≥ TC), иначе по 2-й формуле; для арматуры класса B × **1,5** (10,6 → 15,9).
3. **lc** граничной зоны: из xu, бетон сверх εcu2 = 0,0035 — обжимать хомутами; но **не меньше max(0,15·lw; 1,5·bw)**.
4. Вертикальная арматура краёв — по **точному равновесию M–N** (послойно).
5. Горизонтальная — на V: для изгибных DCM V × **1,5**; ферменная аналогия, бетон на сдвиг не учитывают, отдельно проверка раздавливания подкоса.
6. **α·ωwd** ≥ требуемого (от μφ, νd, ρv) и ≥ **0,08**.
