# Спектр упругих реакций по НТП РК 08-01.1-2017

**Пост #380, 15.10.2026 · видео 5:00 · https://youtu.be/J2YYqCObMI0**

## Что такое спектр
Маятники разной высоты на одной трясущейся платформе: максимальное ускорение каждого = точка спектра. Знаешь период здания → по спектру видишь ускорение.

## Три участка (ф. 4.2–4.4)
1. от ag растёт до **2,5·ag**;
2. **площадка** TB…TC — максимум;
3. после TC падает ~ 1/T.

Ширину площадки задаёт **грунт (табл. 4.1)**: TC = **0,44 / 0,64 / 0,96 с** для грунтов I / II / III. Мягче грунт → шире площадка → больше ускорение у гибких зданий.

**Отличие от EC8:** в EC8 четыре участка (после TD ~ 1/T²), коэффициент грунта S и грунты A–E.

## Демпфирование ≠ 5 %
η по ф. (4.5)–(4.8): до 1 с η = ρ, дальше уменьшается по степенному закону. При **2 %: ρ = 1,338** → спектр выше на треть.

## Спектр перемещений
SDe = Se·(T/2π)² — главный график для **сейсмоизоляции**. Строят с двумя демпфированиями: здание 5 %, изолятор ξeff 15–25 %; начиная с **0,8·Teff** спектр берут по демпфированию изолятора.

## Проверка QS Cal на примерах норм
- Пример 2: грунт III, 0,48g, 5 % → площадка 1,2g, при T=2 с **0,576** (как табл. 4.3).
- Пример 3: 2 % → площадка 1,605g (в нормах 1,606 — округление ρ), при T=2 с **0,740** (как табл. 4.4).
- Изоляция: грунт I, 0,5g, изолятор 15 %, Teff=2 с → η=0,673, ускорение 0,185g вместо 0,275g, смещение изолятора **184 мм**.
