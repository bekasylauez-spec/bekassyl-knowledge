# Модальный анализ — сколько форм брать и почему кручение бывает первой формой

**Пост #435, 18.10.2026 · видео 5:10 · https://youtu.be/wOAOy0iRV3U**

## Число форм — п. 6.3.2.4 НТП РК 08-01.2-2021
- Σ эффективных масс ≥ **90 %** **или** все формы с массой > **5 %** — в **каждом** направлении.
- Не получается → берут формы до определённого периода (доля T1 и ½ начала площадки — формулировку уточнить по тексту п. 6.3.2.4).
- EC8 (4.3.3.3.1(5)): число форм ≥ 3√n (n — этажей) и период последней ≤ 0,20 с.
- Пример: 9 этажей, план 24×24, стены по фасадам: T1=0,59 (Y), T2=0,54 (X), T3=0,39 (кручение); 1-я и 2-я — по 85 %, пять форм дают 94 %.

## Сочетание форм — п. 6.6.1
Tk+1 > 0,9·Tk (близкие) → **CQC**, иначе **SRSS**.

## Порядок форм решает жёсткость на кручение
Жёсткость на кручение = Σ жёсткостей стен/колонн × **плечо²** до центра. Стены по фасадам — большое плечо, ядро в центре — маленькое.

| Кручение — | Вывод |
|---|---|
| **третья** форма (Tθ < обоих сдвиговых) | условие регулярности 3.2.1.1 б) выполнено |
| **вторая** (между ними) | в лучшем случае **умеренно нерегулярная** |
| **первая** (больше обоих) | **крутильно-податливая**: q = **2,0**, ρ = **2,5**; «таких схем следует избегать» |

Те же стены перенесли в ядро → Tθ выросло 0,39 → 0,57, кручение стало 2-й формой.
Ядро в углу → формы смешанные; max/среднее перемещение края перекрытия: ≤ **10 %** регулярное, ≤ **25 %** умеренно нерегулярное.
Пример прил. Г: жёсткая заделка — кручение 2-я форма (0,617 с) → «чрезмерно нерегулярное»; с податливостью грунта — 3-я форма → регулярное. **Регулярность проверяют с учётом основания.**

## Как увести кручение на 3-ю форму
Стены ближе к периметру, равномерные массы/жёсткости, без больших масс на краях, ограничить вытянутость плана.
