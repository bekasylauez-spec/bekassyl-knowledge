# Почему колонна разрушается без хомутов

**Пост #393, 16.10.2026, видео 1:10 (3D).**

Колонна сильнее всего гнётся **у концов**. Редкие хомуты → бетон разрушается, стержни выгибаются.

## НТП РК 08-01.3-2021 (рамы DCM)
| Что | Значение | Пункт |
|---|---|---|
| Крит. зоны | у **обоих** концов: lcr = max(1,5hc; lcl/6; 0,45 м) | 4.5.3.2.3, 4.5.3.2.4 |
| Шаг хомутов | s ≤ min(b0/2; 150 мм; 8dbL) | 4.5.3.2.13 |
| Первый хомут | ≤ 50 мм от конца | 4.5.3.2.13 |
| **Вся длина критическая** | короткая колонна lc/hc < 3; первый этаж с кладкой; кладка с одной стороны | 4.5.3.2.5 |
| Кладка не на всю высоту | особый случай | п. 8.2, рис. 4.15 |

## Пример
Колонна 400×400, этаж в свету 2,5 м → max(600; 417; 450) = **lcr = 600 мм**.
