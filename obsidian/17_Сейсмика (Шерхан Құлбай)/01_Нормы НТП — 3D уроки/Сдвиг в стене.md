# Сдвиг разрушает стену резко — стена должна сначала гнуться

**Пост #348, 13.10.2026, видео 0:46 (3D).**

Сдвиг — хрупкое разрушение без предупреждения → по НТП стена должна сначала **гнуться** (иерархия прочностей).

## НТП РК 08-01.3-2021
- Поперечную силу из расчёта **увеличивают**: изгибная стена ×**1,5**, сдвиговая — по формуле (5.3) — п. 5.5.2
- Косые трещины держит **сетка** (вертикальные + горизонтальные стержни) — п. 5.8.2.3
- **Скольжение по шву бетонирования** (над перекрытием/фундаментом) проверяют отдельно; анкеровку стержней через шов увеличивают на **50 %** — п. 5.8.2.13
- В стенах с проёмами сильнее всего нагружены **простенки**; сдвиг проверяют в сечении через проём — п. 5.6.6
