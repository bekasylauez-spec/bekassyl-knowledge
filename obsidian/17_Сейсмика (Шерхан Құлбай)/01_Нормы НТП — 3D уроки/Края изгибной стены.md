# Как армировать края изгибной стены

**Пост #333, 11.10.2026, видео 1:04 (3D).**

При землетрясении край то растянут, то сжат. Без частых хомутов сжатый бетон разрушается, стержни выгибаются наружу. **Держат край хомуты.**

## Правила НТП РК 08-01.3-2021
| Что | Формула / значение | Пункт |
|---|---|---|
| Критическая зона по высоте | hcr = max(lw; hw/6) | 5.7.2.1 |
| Длина края (граничной зоны) | lc ≥ max(0,15·lw; 1,5·bw) | 5.7.2.7 |
| Стержни края | Ø ≥ 12 мм | 5.7.2.12 |
| Шаг хомутов в крит. зоне | s ≤ min(b0/2; 150 мм; 8·dbL) | 5.7.2.13, ф. (4.19) |
| Концы хомутов | 135°, заведены внутрь на 10·dbw | 6.1.2 |
| Выше крит. зоны | s ≤ min(b0; 250 мм; 16·dbL) | 5.7.3.4 |

## Мой чек-лист
- [ ] hcr по каждой стене отмечен на развёртке
- [ ] lc не меньше 0,15lw и 1,5bw (у пересечений стен — не меньше 3bw, п. 5.7.2.9)
- [ ] хомуты 135° с хвостом 10d
