# Сетки стенки: сколько их и сколько арматуры

**Пост #341, 12.10.2026, видео 0:52 (3D).**

## НТП РК 08-01.3-2021
| Требование | Значение | Пункт |
|---|---|---|
| Сетки | две — у каждой грани, шпильки шаг ≤ 500 мм | 5.7.2.17 |
| Вертикальная | ρv ≥ 0,002 | 5.7.2.14 |
| Горизонтальная | ρh ≥ max(0,001; 0,25·ρv) | 5.7.2.14 |
| Диаметр | 8 мм … bw/8 | 5.7.2.15 |
| Сдвиговые стены | ρ ≥ 0,003 в каждом направлении, шаг ≤ 300 мм | 5.8.2.4, 5.8.2.10 |
| По высоте | меняют диаметр, **шаг оставляют** | 5.7.2.18 |
| Лишняя вертикальная арматура | **вредит**: стена ломается от сдвига, хрупко | 5.7.2.19 |

## Пример
Стена 250 мм, Ø10 шаг 200 с двух сторон → ρ = 2·78,5/(250·200) = **0,0031** — проходит и для изгибной, и для сдвиговой.
