# Спектр упругих реакций — калькулятор

**Открыть:** https://qs-cal.netlify.app/spectrum/spectrum

Упругий спектр по НТП РК 08-01.1-2017 / 08-01.6-2022, в т.ч. для **сейсмоизоляции**. Встроенная верификация (НТП 08-01.6, прил. В): IА/IБ, 0,5g, ξ=5 %, T=2 с → Se = 0,275g, SDe = 273,6 мм; ξeff = 15 % → η = 0,673, ddc = 184 мм.

## Поля (слева)
| Поле | По умолчанию |
|---|---|
| Тип грунта: IА/IБ (TB 0,15, TC 0,44) · II (0,20/0,64) · III (0,25/0,96) | II |
| ag, g | 0,5 |
| g, м/с² | 9,81 |
| ξ суперструктуры, % | 5 |
| ξeff изолятора, % | 15 |
| Teff изолятора, с | 2,0 |
| Шаг спектра, с | 0,01 |
| Tmax, с | 7,0 |
Кнопка **CALCULATE**.

## Результат
4 графика: спектр при ξ, при ξeff, **совмещённый** (до 0,8·Teff по ξ, далее по ξeff), **спектр перемещений**. Таблица T / Se,g / η — кнопка **Copy table** → вставка в ЛИРУ/ETABS.

## Приём
Чтобы получить спектр просто для другого демпфирования (напр. 2 %), впиши его в поле ξeff и сравнивай два графика.
