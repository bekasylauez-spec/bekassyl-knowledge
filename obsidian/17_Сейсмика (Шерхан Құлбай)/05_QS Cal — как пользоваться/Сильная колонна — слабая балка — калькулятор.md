# Сильная колонна — слабая балка — калькулятор

**Открыть:** https://qs-cal.netlify.app/scb/step_1_ishodnye_dannye.html

**5 шагов:** 1 Данные → 2 Арматура балок → 3 Моменты балок → 4 Моменты колонн → 5 Арматура колонн. Кнопки «📑 Сборник расчётов», «💾 Сохранить в сборник».

## Шаг 1 — Данные
- **Конфигурация:** название рамы, пролётов n, этажей m, **поперечные балки в узлах есть/нет** (п. 4.4.4.1.3 — влияет на ширину полки), длины пролётов L1…, высоты этажей H1…, названия осей.
- **Сечения по этажам:** колонны (h вдоль каркаса, b поперёк, см; **NEd min, т** — минимальная N сейсм. сочетания из ЛИРЫ), балки (bw, h, **hf плиты**, см). Кнопки «⇕ … ко всем этажам», «🔄 Обновить схему».
- **Бетон** балок и колонн отдельно (C12/15…C50/60), **арматура** балок/колонн продольная и поперечная (S240…S600).
- Коэффициенты αcc, γc (для сейсмики по НТП 1,3), γs (1,0); **класс пластичности арматуры A/B/C**; q (табл. 2.1), грунт, T1, Tc.
- Защитные слои до **центра** арматуры: балки низ/верх, колонны.
- Схема здания справа (кнопка «📸 Сохранить схему для PDF»).

## Дальше (из видео)
Шаг 2 — клик по ячейке: число стержней и Ø верх/низ балки + арматура плиты в полке (ширину полки считает сам); проверки балки (мин. армирование, верх/низ, Ø через узел) и **автокорректировка**. Шаг 3 — MRb по фактической арматуре (тавр с полкой). Шаг 4 — ΣMRb × 1,3 (можно изменить), распределение между колоннами по жёсткости. Шаг 5 — автоподбор симметричной арматуры колонн; > 4 % — увеличивать сечение.
