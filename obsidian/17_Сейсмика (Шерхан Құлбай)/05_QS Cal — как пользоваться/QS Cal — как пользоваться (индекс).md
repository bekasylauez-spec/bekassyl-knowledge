# QS Cal — как пользоваться (индекс)

**Открыть:** https://qs-cal.netlify.app/

Изучено 19.10.2026 изнутри (аккаунт пользователя, вход выполнен во встроенном браузере Claude; в шапке «⏳ 60 дн. осталось» — срок бесплатного доступа).

## Общие правила работы
- **Вход обязателен.** Без входа карточка открывает окно «Регистрация». Сайт в режиме QS_FREE_MODE (без оплаты), но с авторизацией (Firebase).
- Ввод **данных сохраняется в браузере** (localStorage) — у каждого браузера свой; файлы стены/проекта можно скачать и загрузить (💾 / 📂, `.qswb` у «Здания»).
- **Сборник (Блок 1)** — копилка расчётов: «💾 Сохранить в сборник/Блок» → оттуда «Печать в PDF».
- PDF: «Полный / для экспертизы» и «Краткий / конструктору».
- **Импорт из ЛИРЫ** (стены, перемычки): `Файл задачи .txt` (один раз на блок — геометрия хранится в браузере) + `Усилия .xlsx` (Стандартные таблицы → «Усилия от РСН» по стержневым аналогам: ЭЛЕМ/СЕЧ/№ РСН/N,т/MY/QZ). **Знак N: сжатие = «+»** (ЛИРА «−» конвертируется сам). Берутся MY и QZ; из двух сечений — max по модулю.
- Нагрузки часто вводятся в **тоннах** (т, т·м, тс) — переводит сам (×9,806).
- Красная подсветка поля = нарушено ограничение норм; подсказка рядом показывает предел (напр. «≤ 0,75d = 378 мм»).
- Режим «Здание» помечен **«ТЕСТ, НЕ ДЛЯ ПОДПИСИ»** — результаты проверять.
