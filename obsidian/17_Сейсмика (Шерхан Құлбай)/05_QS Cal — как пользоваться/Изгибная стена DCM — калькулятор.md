# Изгибная стена DCM (одна стена, многоэтажная) — калькулятор

**Открыть:** https://qs-cal.netlify.app/wall-multi/ishodnye-dannye.html

EC8 + НТП РК 08-01.3-2021. **10 шагов** (меню слева): 1 Исходные данные → 2 Нормализованные силы → 3 Коэффициент пластичности → 4 Длина ограниченной зоны → 5 Подбор продольной (краевая) → 6 Подбор горизонтальной → 7 Условие α·ωwd → 8 Конструктивные требования → 9 Армирование → 10 Итоговая проверка. Плюс «📁 Сборник (Блок 1)» и «Печать в PDF».

## Шаг 1 — две вкладки
**АРМИРОВАНИЕ ПО ЭТАЖАМ (геометрия и усилия):**
- Наименование (ось/марка, напр. СМ-1); nэтажей (11), подвалов, техэтажей сверху, защитный слой c (50), hw (авто), hcr (авто), отм. низа 1-го этажа.
- Таблица по этажам: ОТМ., hst, № КЭ, bw, lw, **Бетон** (общий или свой класс этажа), усилия при Mmax / Nmax / Qmax, «Все РСН».
- Кнопки: **📄 Файл задачи .txt** (один раз на блок), **📁 Усилия .xlsx** (на каждую стену) → № КЭ, hst, ОТМ, bw, lw и сочетания заполнятся сами. Без .txt — ручной режим: впиши hst и № КЭ, тогда .xlsx применит усилия по ним.
- Подбор перебирает **каждую пару M–N** (продольная) и **Q–N** (горизонтальная) из всех РСН × сечений.

**ОБЩИЕ ПАРАМЕТРЫ:** бетон (C20/25…C40/50, αcc, γc), арматура продольная/поперечная/горизонтальная (S240…S600), γs, **класс арматуры B/C**, q (табл. 2.1), грунт I/II/III, **T1**, Tc (табл. 4.2), схема сечения (bw, lw, lc).

Кнопки: **РАССЧИТАТЬ**, 💾 Скачать файл стены, 📂 Загрузить стену из файла.

## Порядок из видеоурока
q = 4…4,5, грунт, T1 из ЛИРЫ → рассчитать → на шаге 5 задать max шаг краевых стержней и угловые Ø → калькулятор подбирает → шаг 6: коэффициент к V **1,5** (для сверки с ЛИРОЙ ставили 1) → шаг 7 хомуты (задать мин. Ø) → шаг 9 схемы для чертежа → PDF.
