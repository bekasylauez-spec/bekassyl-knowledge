# Продавливание EN 1992-1-1 — калькулятор

**Открыть:** https://qs-cal.netlify.app/punching/index.html

Выбор схемы: **с плитой** (`punching-en2/`: средняя/крайняя/угловая колонна, капитель есть/нет) · **с фундаментом** (`punching-en2-foundation/`: учёт отпора грунта VEd,red) · со стеной — в разработке.

## 4 шага: Данные → Расчёт (формулы, разделы 2.1 u₀, 2.2 u₁, 2.3 поперечная арм., 2.4 uout) → Проверки и итог → Армирование (план раскладки шпилек, разрез, PDF «конструктору» / «полный»)

## Поля шага 1 (по умолчанию)
| Поле | Значение |
|---|---|
| Тип узла | средняя (β = 1,15) / крайняя (1,4) / угловая (1,5) |
| Капитель | Есть / Нет |
| Нагрузка на колонну | 200 **т** |
| Толщина капители+плиты / плиты | 550 / 250 мм |
| Защитный слой c | 30 |
| Колонна b × h | 500 × 500 |
| Капитель Lh₁, Lh₂ | 1000 (подсказка ≥ 2h) |
| Бетон | C25/30 (C12/15…C50/60) |
| Поперечная арматура | S240 / B400 / B500 / B600 |
| αcc, γc, γs | 1 / 1,3 / 1,15 |
| Арматура плиты ⌀ / шаг | 16 / 200 |
| Шпильки ⌀ | авто или 6…25 |
| Шаг s_r (радиальный) | ≤ 0,75d (подсказка) |
| Шаг s_t (по кругу) | 1,5d |
| 1-й ряд a | max(0,3d; 50) |
| Зона армирования r | r_out − 1,5d, число рядов |
| Зерно d_g, угол α, β | 20 мм, 90°, 1,15 |
Справа сразу рисуются вид сверху (u₁ на 2d) и разрез.

## Как читать итог
Сначала **по грани колонны (u₀)** — если не проходит, арматура не поможет → капитель/колонна/бетон. Красная строка «без поперечной арматуры» — причина ставить шпильки, не ошибка. Итог показывает несущую способность узла в тоннах (без арматуры / с арматурой / по грани).
