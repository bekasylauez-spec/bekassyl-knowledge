# Сдвиговая стена DCM — калькулятор

**Открыть:** https://qs-cal.netlify.app/wall-sdvig/ishodnye-dannye-sdvigovaya.html

Сам проверяет тип: «hw/lw = 4500/3000 = 1,50 ≤ 2,0 — Сдвиговая стена ✓».

## Шаги
1 Исходные → 2 Конструктивные требования → 3 Нормализованная сила νdw → 4 μφ → 5 Длина периферийного элемента lc → 6 Подбор продольной (периф.) → 7 Поперечное армирование ωwd → 8 Горизонтальная арматура → 9 Армирование → 10 Итоговая проверка.

## Ввод
- Общие: Ned (**т**), VEd (кН), n этажей, hw, hc (высота в чистоте), c, отм.0.
- Таблица по этажам: ОТМ., hst, № КЭ, bw, lw, бетон, Ned т, MEd кН·м, VEd кН, hc, источник. Пустая ячейка = значение из формы; hw = Σhst.
- **📁 Усилия .xlsx (ЛИРА)** — лист «Стержни», колонки ЭЛЕМ/N/MY/QZ. Берётся max |N| сжатия; MEd = max|MY|·9,81; VEd = max|QZ|·9,81. **MEd — информативно** (в DCM-сдвиговой не участвует, ε = q).
- Материалы отдельных этажей — своя продольная/поперечная сталь, «↺ Общие».
- Общие параметры: бетон, αcc, γc, стали, γs, класс B/C, q (табл. 5.1 EN 1998-1), грунт, T1, Tc.
Кнопки: РАССЧИТАТЬ, сохранить/загрузить стену.
