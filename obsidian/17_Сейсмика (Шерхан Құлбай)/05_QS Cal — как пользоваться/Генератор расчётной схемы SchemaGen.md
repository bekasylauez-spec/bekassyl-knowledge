# Генератор расчётной схемы Q.S. SchemaGen (DXF → ЛИРА-САПР 2024)

**Открыть:** https://qs-cal.netlify.app/qs-schemagen/index.html

Препроцессор для **ЛИРА-САПР 2024**: из архитектурного DXF строит КЭ-схему (пластины стен и плит, проёмы, перегородки) → DXF + TXT для ЛИРЫ. «Мои задания» — история.

## Системы (генерация доступна для всех)
Стеновой каркас · Рамный каркас · Рамно-связевой · Паркинг (каркас, плита или отдельные подошвы с балками).

## Режим 1 · из DWG (стеновой)
- **План:** «Один план» или «Поэтажные планы»; только **.dxf до 50 МБ**. Есть **«Скачать шаблон Q.S.»** с правильными слоями.
- **Слои (регистр важен, можно несколько через запятую):**
  | Слой | По умолчанию |
  |---|---|
  | Оси | S-GRID |
  | Монолитные стены | A-WALL |
  | Контур плиты | A-FLOR |
  | Перегородки (опц.) | — (осевые линии или узкие контуры) |
  | Двери / окна | A-DOOR / A-WIND (ширина из чертежа) |
  | Проёмы в плите (лестницы, лифты) | A-OPNG |
  | Подписи высот проёмов | TEXT «h=2200», «h=2200 (1100)» = верх 2200, подоконник 1100 |
  | Штриховка монолита | опц. — проёмы как разрывы штриховки |
- Автопоиск проёмов плиты по диагоналям — **выключен** по умолчанию (ложные срабатывания).
- Проёмы по умолчанию: двери h 2100, низ окна 900, h окна 1500.
- **Этажность:** таблица (название, Zниз, h, тип: Подвал/Этаж/Типовой/Технический/Кровля); Zниз вручную только у 1-го, дальше авто; «Добавить типовых этажей». Пример по умолчанию: подвал −4,6 (4,5 м), 1 эт. 3,75, типовые 3,3, техэтаж 2,5 → 23,95 м.
- **СГЕНЕРИРОВАТЬ СХЕМУ** → ход: очередь → чтение DXF → стены и проёмы → общая сетка → этажи → перегородки → запись DXF. Просмотр: план/изометрия, слои стены/сетка/проёмы.

> Связь с моей работой: можно попробовать вместо ручного построения модели в ЛИРЕ (см. память «LIRA модель по аналогу»). Для своего DXF — переименовать слои под поля или вписать свои имена.
