# Сваи, крановые нагрузки, сейсмоизолятор — калькуляторы

**Открыть:** https://qs-cal.netlify.app/#calc

## Набивная / буровая свая (с уширением и без) — `svai-buronabivnye/index.html`
СП РК 5.01-103-2013, пп. 4.4.1.11, 4.4.2.6, 4.4.2.7, 4.4.2.9. Шаги: Исходные → Статический → **Сейсмический** → Отчёт → Сборник.
- d ствола, D уширения (0 = нет), H погружения, hк котлована (0 = нет), L = H + hк (авто), устройство скважины (табл. 5, γcR), ядро скважины.
- Слои сверху вниз: грунт, IL (только глинистые), φ (для **любого** грунта — нужен для песков и для hd при сейсмике ф. 11.3), e, γ (**ниже УГВ — взвешенный γsb = (γs−γw)/(1+e)**, сам не считает!), h, влажность (пески), → zср, fi.
- Глубину острия задаёт L, а не сумма слоёв (лишние слои отбрасываются, последний усекается, недостающее — продолжение последнего слоя).
- Справочно: просадочность и водонасыщение (Sr, γs, wp, wL, Ilw).

## Забивная / вдавливаемая свая — `svai-zabivnye/index.html`
СП РК 5.01-103-2013, пп. 4.4.1.11, 4.4.2.1, 4.4.2.2. Сечение квадратное/круглое, b, l, hр ростверка, способ погружения (табл. 3), свая-стойка (R = 20 000 кПа). Слои: грунт, влажность, IL, h, γ, E (справочно, для осадки п. 4.6 — вне калькулятора).
**Сейсмика:** флажок, 7–10 баллов (табл. 11.1), повторяемость 1/2/3 (×0,85/1,0/1,15); тогда несущая способность и N ≤ F/γk — по **Feq** (ф. 11.1).

## Крановые нагрузки — `crane-loads/index.html`
СП РК EN 1991-3 / EN 1993-6. Тип крана опорный/подвесной; Qh, Qc, QcT, Fk1, Fk2; n колёс, n1 на нитке, mw ведущих, Lк пролёт, a база, nr ниток; vh, vкр; класс HC1–HC4; φ1, φ5, φ7 подбираются по норме; SB буфера; γG,sup, γQ, ψ, μ (0,2/0,5), g. Шаги: Исходные → Расчёт → Результат.

## Сейсмоизолятор — траектория — `seismoisolyator/isolator-test.html`
Загрузить два CSV: X (мм, Rx кН) и Y (мм, Ry кН) → ПОСТРОИТЬ — анимация траектории перемещения изолятора.
