# Здание — все изгибные стены (мульти) — калькулятор

**Открыть:** https://qs-cal.netlify.app/wall-building/zdanie.html

Режим помечен **«ТЕСТ, НЕ ДЛЯ ПОДПИСИ»**.

## 01 · Файлы модели
1. **Текстовый файл задачи ЛИРА (.txt)** — элементы, жёсткости, узлы, стержневые аналоги стен и перемычек.
2. **Усилия от РСН (.xlsx)** — «Усилия в стержневых аналогах» (ЭЛЕМ / СЕЧ / Номер РСН / N,т / MY / QZ).
3. **АР-план (.dxf/.dwg)** — необязательно, только для схемы каркаса и чертежей (стена ставится между гранями АР); смещение АР X/Y, мм.
4. **Файл проекта (.qswb)** — скачать/загрузить; данные автосохраняются в браузере.

## 02 · Общие данные (один раз на здание)
nэтажей (из файла), подвалов, техэтажей, отм.0, c; бетон (+ «Класс бетона по этажам ▸»), αcc, γc; арматура продольная/поперечная/горизонтальная, γs, класс B/C; q, грунт, T1, Tc.
**Стартовое армирование:** полевая вертикальная Ø в зоне А (критическая) и В (выше), шаг вертикальной, шаг хомутов sA, sB, у плит sпл; коэффициент к поперечной силе ε (1,5). Ø краевой и горизонтальной — авто-подбор, lc — всегда по расчёту.

## 03 · Рассчитать все стены
~13 мин на 60 стен. Дальше — мозаика по этажам/проверкам, функции плана (Т/Г-узлы, группировка шахт «найти кандидатов по геометрии», «армируется как колонна» для простенков l < 4bw), выгрузка: сборник, PDF, DXF чертежей стен, схема каркаса.

## Подготовка в ЛИРЕ (из видео)
Файл → Создать текстовый файл; выделить все вертикальные стержневые аналоги → Анализ → Документация → Стандартные таблицы → Результаты → «Усилия от РСН» → Excel; T1 — там же «Периоды колебаний».
