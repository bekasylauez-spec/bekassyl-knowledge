## Решения Bekassyl (06.11)
- Колонны по осям 22 и 33 (у деформационных швов) — **не входят** в Блок 3 (соседние блоки). В Блоке 3 — 60 колонн, оси 23–32.
- Прямоугольники 1200×800 / 1500×800 / 1000×800 между осями В–Д (22 шт) — **не колонны** (опоры оборудования), в Км не входят.
- Основная арматура Ø28 A500С (правило 06.11), хомуты/шпильки Ø10.

## Как сделано
- Лист колонны = импорт листа «Колонна Км-1» шаблона `Шаблон для Кж.dwg` (302 объекта) + генератор `gen3.py` (на базе Галакси `gen_km.py`), своя копия AutoCAD со слушателем K3LISTEN (папка `%TEMP%\acadjob_k3`, плагин rz.cs с файлами k3_*).
- Уровни: −1.200 (верх фундамента) → −0.050 (фундаментная балка 900) → +7.000 (ригель 900). Хомуты: участок −1.150…−1.000 шаг 75×2; основной этаж 50 | 100×16 | 200×6 | 150×3 | 200×6 | 100×16 | 50 (остаток 50 + 2×200 → 150×3 внутри зоны 200).
- Стык один: над −0.050 накладками Н2 (Ø28, L280), углы +600, средние +1200; выпуски из Фм — пунктир (в спецификации колонны нет).
- Отметки СПДС: базовая метка шаблона хранит «-2.000», остальные считаются от неё → после перемещения заменить текст (levelval) на −1,200 / −0,050 / +7,000.
- Таблицы шаблона: после правки ячеек AutoCAD теряет соседние формулы → все формулы массы спецификации переустанавливаются одной операцией (`tfix.py`), ведомость стали: Ø10 = хомуты + сетки.
- ЛИРА COM `AllTables` даёт только таблицы ввода (31 = «Блоки»), «Арматура в стержнях» оттуда не взять.
