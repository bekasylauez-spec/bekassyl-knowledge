## 0. ПЕРЕД ПОКАЗОМ КАЖДОГО ЛИСТА (обязательно, Bekassyl 31.10: «неге қателерді қайталап отырсың», «мен саған айтқанның барлығы ереже»)
Источник пунктов — [[01_Общие правила/Чек-лист проверки КЖ — Схема каркаса]] (номера), [[01_Общие правила/Оформление КЖ в AutoCAD — СПДС (утверждённые правила)]], [[02_Фундамент/Фундаментная плита]], [[02_Фундамент/Оформление листов Фм по аналогу (Онкоцентр 3.x)]], [[09_Таблицы/Анкеровки из обсуждения]].
- [ ] **Сначала автоматическая проверка: `chk.sh` → TOTAL 0, нет «НЕ ПРОЧИТАНО»; `tiles.py` — все половины всех листов просмотрены** ([[01_Общие правила/Проверка листа перед показом — автоматическая (oc.py)]]). Найденная ошибка → вся её категория на всех листах + новая проверка в oc.py.
- [ ] №21 Один масштаб на лист: геометрия и все СПДС/размеры/тексты в масштабе листа; узлы другого масштаба — отдельным листом; «М 1:xx» не писать.
- [ ] №28/30 Ряды размеров: первый ряд в 1000 от наружного контура, следующие через 1000; кружки осей за последним рядом.
- [ ] №31 Выносные линии касаются элемента.
- [ ] №32/13 Ничего не накладывается: oc.py = 0 (текст/текст, линия/текст), затем PDF-фрагменты крупно.
- [ ] №35 Мелкий размер: текст на стороне текстов цепочки, рядом со своим размером, с выноской; не продолжением линии.
- [ ] №14 Разрез: отметки всех уровней, между каждыми соседними отметками — размер; близкие отметки не накладываются (нижняя вниз / на другую сторону).
- [ ] №20 Всё внутри рамки, не на штампе/таблицах/примечаниях; листы вплотную.
- [ ] Выноски: полка против стрелки, стрелка на грань элемента, 300–600 от элемента, к центру схемы; под элементом 400+400.
- [ ] Штриховка бетона ANSI36 20, 0.05 мм; контуры 0.30 мм; подбетонка показана.
- [ ] Заголовки: одна строка, подчёркнуто, слой 0, Standard, 3 мм, по центру.
- [ ] Примечания — над штампом; спецификация на схемах.
- [ ] Фм: основная Ø по толщине (300–400 → Ø14), одна поз.1, край 50; доп. между основными, зоны ≥4 ячеек; анкеровка по таблице (Ø12 600, Ø14 700, Ø16 800, Ø18 850, Ø20 950, Ø22 1050, Ø25 1200, Ø28 1300, Ø32 1500); Ск1 H−80, ноги Ø14 800; Ф1 Ø12 полки 300 ш.400х400.
- [ ] Нумерация листов по аналогу (2.x, 3.x …).
- [ ] Ориентация листа по форме здания: план вытянут вертикально → книжный лист, горизонтально → альбомный (Bekassyl 31.10).
- [ ] По полному разбору аналога ([[11_Аналоги и фото/Онкоцентр КЖ — графика и размеры (полный разбор)]], 31.10):
  - кружок оси Ø7 мм на бумаге;
  - текст 2,5 мм (размеры, выноски, отметки, позиции), цифры знака разреза 3,5 мм;
  - арматура 0,4 мм;
  - контур плиты на листах армирования тонкий, на опалубочном толстый.
- [ ] Каждая колонна привязана к осям **своей** цепочкой у колонны (в обе стороны); стены — привязка толщины к оси.
- [ ] Короткий размер: текст на полке наружу цепочки (600, 450, 50…).
- [ ] Выноска позиции: «поз» над полкой, «ш.200» под полкой, засечка на стержне, веер ножек на несколько стержней. Марка элемента — стрелка на элементе.
- [ ] Разрез армирования: бетон не штрихуется (только подбетонка), стержни 0,4, поперечные — точки с шагом, обрыв зигзагом, за обрывом стрелка «1 / ш.200».
- [ ] Доп. листы Фм: ряды осей только слева и снизу. Зона — первый и последний стержень + соединительная линия с полкой. Длина стержня — размер над стержнем от оси. «200xN» у торцов. «200» между зонами.
