# Стены / диафрагмы

## Current Rules

- Распознавать стены и диафрагмы по модели и расчётным данным; формировать вертикальную/горизонтальную арматуру, проёмы, стыки и спецификации по расчёту.
- Для стены/пилона: Ø≤18 — нахлёст, Ø20+ — накладка, если не задано более позднее правило для конкретного проекта. См. [[07_Anchorage_Laps]].
- Не применять численные параметры из фундаментной плиты к стенам без явно подтверждённой области применения.
