## Решения
- Все уровни (как Блок 2), Ø28 A500С основная, доп. Ø28 по ЛИРА, боковые Ø12 при h>700, хомуты Х1 A240 Ø10/Ø12, шаг 100/200 аналога, сгущение по Asw.
- Унификация ±300 по максимуму группы (правило Блока 2): 78 → 59 марок.
- **Bekassyl 06.11: «унификация жаса азайт ригелді»** → правило БДМ Блок 1: одинаковые b×h, одинаковое число пролётов, каждый пролёт и ширина опоры ±600, уровень любой → одна марка (лист по самому длинному, армирование по огибающей ЛИРА всех, пролёты сопоставляются грань-в-грань); марки на нескольких уровнях — отметки стопкой (шаг 600). Итог: **51 марка, 126 шт, 97 листов (6.5–6.101)**. Марки пронумерованы по уровню (±0.000 → +12.750), затем сечению.
- Высокие ригели (h ≥ 1000) — разрез справа от фасада, части ≤19 м (последняя ≤11 м); прочие — части ≤21.5 м, обрыв у опоры.
- Листы: 6.1 схема ±0.000; 6.2 +4.500 + фрагменты лестницы +1.700/+3.500/+5.200; 6.3 +7.000 + фрагменты +9.950/+12.750 (1:200); 6.4 «Ведомость ригелей»; 6.5–6.101 Рм-1…51.
