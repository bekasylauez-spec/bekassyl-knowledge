# Пилоны

В доступном резюме зафиксированы следующие решения:

- Выпуски из фундамента совпадают с вертикальной арматурой пилона по количеству, диаметру и координатам: [[02_Фундамент/Выпуски из фундамента]].
- Фундаментные хомуты, описанные для колонных выпусков, для пилонов не применяются.
- Соединения: Ø≤18 — нахлёст; Ø20 и больше — накладки: [[08_Типовые узлы/Накладки]].

## Не восстановлено из доступного источника

Схемы армирования, защитные слои, шаги, граничные зоны и оформление.
