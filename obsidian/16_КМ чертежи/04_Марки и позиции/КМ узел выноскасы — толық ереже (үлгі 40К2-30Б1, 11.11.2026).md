## 1. Выносканың түрі (СПДС выноскасынан аумайды)

```
      -t16          ← 1-жол, полка үстінде
   ───────────      ← полка: жіңішке, мәтіннің бүкіл еніне
      С245    \     ← 2-жол, полка астында
               \    ← сол жіңішке сызық полка ұшынан үзілмей шығады
                ➤   ← жіңішке ашық стрелка, бөлшектің қырына тиеді
```

| Не | Мәні |
|---|---|
| Семейство | `БК_типовая_аннотация_текст_с_выноской` (`Семейства\`), дана параметрлері «Текст верх», «Текст низ», «Ширина полки» |
| Тип стрелкамен | `БК_выноска_стрелка`, стрелка `БК_стрелка_открытая_3,5мм_20°` (ашық, жіңішке) |
| Тип стрелкасыз | семейство атымен аттас негізгі тип — тек «Болты …» жазуына |
| Шрифт | ISOCPEUR, курсив, 2,5 мм (размер мәтінімен бірдей) |
| Полка ені (қағаз, мм) | `max(8; ең ұзын жолдың таңба саны × 1,6 + 3)` — мәтіннен әр жаққа ≈1,5 мм. Параметрге `ен / 304.8` беріледі, масштабқа көбейтілмейді |
| Сызық қалыңдығы | полка, сызық, стрелка — бәрі бірдей жіңішке (перо 1) |
| Сынық нүктесі | полканың стрелкаға қараған ұшынан стрелка бағытымен 1 мм (қағазда). Яғни сызық полка ұшынан бірден түзу кетеді, көзге сынық көрінбейді |
| Бір нысан | мәтін + полка + сызық бірге жылжиды; стрелка ұшы бөлек ұстағыш |

Мәтінді асты сызылған TextNote-пен, тегпен не кәдімгі аннотациямен жасауға **болмайды**: асты сызығы шрифт қалыңдығында және тек 1-жол енінде шығады, сынық орнында қалып қояды. Үшеуін де пайдаланушы қабылдамаған.

## 2. Не жазылады

| Элемент | 1-жол | 2-жол | Стрелка |
|---|---|---|---|
| Маркасы бар элемент (колонна, балка, прогон, связь…) | марка: `К1`, `Б1`, `П1` | бос | бар |
| Пластина, қабырға, накладка, фасонка | `-t16` | `С245` | бар |
| Уголок кесіндісі | `L 100x7` | `С245` | бар |
| Болттар тобы | `Болты М24` | бос | **жоқ** — сызық болттың ортасында бітеді |

- Маркалы элементке сечение **жазылмайды** (К1 жанында «40К2» жоқ). Сечение тек маркасыз бөлшекке.
- Қалыңдық әр бөлшектің өзінен алынады (`-t8`, `-t16`), «бәріне бірдей» жазылмайды.
- Бір мәтін — бір выноска: екі жазу бір полкаға қосылмайды («-t8 -t10» деген полка болмайды).
- Мәтінде пластина өлшемі (ені × ұзындығы) жазылмайды — ол размер тізбегінде.

## 3. Қай бөлшекке, неше рет

1. **Әр көріністе** (Узел, 1-1, 2-2, 3-3) сол көріністе көрінетін әр бөлшек түріне бір выноска. Үлгіде: Узел — 10, Разрез 1-1 — 9, 2-2 — 5, 3-3 — 7.
2. Бір көріністе бірдей екі бөлшек (мыс. екі қабырға -t16) қатар тұрса — бір жазудан **екі сызық** шығаруға болады; алыс тұрса — әрқайсысына бөлек.
3. Әр бөлшек парақта кемінде бір рет аталуы керек; көрінбейтін (жасырын) бөлшекке выноска қойылмайды.
4. Болттар: әр диаметрге әр көріністе бір «Болты М..».

## 4. Стрелка ұшы қайда тиеді

- Бөлшектің **қырына** (контур сызығына). Ортасына, бояуына, шов белгісіне, ось сызығына емес.
- Қиғаш/көлбеу жиегі бар пластинада — сол бос жиекке (үлгі: кронштейн -t8 қиғаш жиегі).
- Жұқа пластина қимасында (кесілген -t16) — оның көрініп тұрған ұшына не ұзын қырына.
- Маркалы элемент: колоннаға — сыртқы полка қырына; балкаға — полка қырына обрывқа жақын; прогонға — полка қырына.
- Стрелка ұшы басқа бөлшектің сызығымен түйіскен нүктеге қойылмайды (қай бөлшек екені түсініксіз болады).

## 5. Полка мен сызықтың орны

- Полка әрдайым **көлденең**. Мәтін бұрылмайды.
- Сызық полканың **стрелкаға жақын ұшынан** шығады; полка стрелкадан **ары** қарай созылады (бөлшек сол жақта → полка оңға; бөлшек оң жақта → полка солға).
- Сызық — бір қысқа **қиғаш** кесінді, шамамен 30–60°. Таза көлденең не тік сызық болмайды (размер не контурмен шатасады). Сызықта екінші сынық жоқ.
- Жазу өз бөлшегінің **қасында**: стрелка ұшынан полка ортасына дейін қағазда 10–35 мм (үлгіде 1:10-да модельдің 100–350 мм-і). Бүкіл көріністі кесіп өтетін ұзын сызық — қате (В113 9-узел: «-t8» сызығы бүкіл узелден өткен).
- Жазу мүмкіндігінше контурдан **тыс** тұрады. Сыртта орын жоқ болса ғана бөлшектің ішіндегі бос бояу үстіне қойылады (үлгі: колонна ішіндегі «-t16 / С245», «Болты М24»), бірақ болт, шов белгісі, размер үстіне емес.
- Көріністің төрт жағына бөліп тарат: сол жақтағы бөлшектің жазуы солда, оңдағынікі оңда. Сызықтар бір-бірін қиып өтпейді.

## 6. Неге тимейді (саңылаулар, қағазда)

| Жұп | Ең аз саңылау |
|---|---|
| Жазу ↔ басқа жазу (мәтін қорабы) | 2 мм |
| Жазу ↔ размер мәтіні / размер сызығы | 2 мм |
| Жазу ↔ разрез белгісі (штрих, стрелка, нөмір) | 3 мм |
| Жазу ↔ узел шеңбері, тақырып | 3 мм |
| Жазу ↔ көріністің подрезка шеті | ішінде, шетінен ≥ 2 мм |
| Сызық ↔ басқа выноска сызығы | қиылыспайды |
| Сызық ↔ размер тізбегі, разрез белгісі | қиылыспайды |
| Сызық ↔ бөлшектер | өз бөлшегіне жеткенше мүмкіндігінше аз бөлшек үстінен өтеді |

Размер тізбектері алдымен қойылады (контурдан ≥ 10 мм, араларында ≥ 8 мм), выноскалар содан кейін, қалған бос орынға.

## 7. Жасау тәртібі (Revit API)

```csharp
const double MM = 1 / 304.8;
// c — полка ортасы, end — стрелка ұшы: екеуі де көрініс жазықтығындағы модель координатасы (1:10-да қағаздың 1 мм = 10 мм)
double w = Math.Max(8, lines.Max(x => x.Length) * 1.6 + 3);                 // полка ені, қағаз мм
var sym = doc.Create.NewFamilyInstance(c, lines[0].StartsWith("Болты") ? ldPlain : ldArrow, view) as AnnotationSymbol;
sym.LookupParameter("Текст верх").Set(lines[0]);
sym.LookupParameter("Текст низ").Set(lines.Count > 1 ? lines[1] : "");
sym.LookupParameter("Ширина полки").Set(w * MM);                            // масштабқа көбейтілмейді
sym.addLeader(); doc.Regenerate();
var l = sym.GetLeaders()[0]; l.End = end;
XYZ R = view.RightDirection; double wm = w * MM * view.Scale;
XYZ se = c + R * ((end - c).DotProduct(R) > 0 ? wm / 2 : -wm / 2);          // полканың стрелкаға қараған ұшы
l.Elbow = se + (end - se).Normalize() * (1.0 * MM * view.Scale);            // сынық сол ұштан 1 мм
```

- `BKLeaderShelf` қосымшасы орнатылған болса, сынықты әр өзгерістен кейін өзі қояды; жоқ болса — әр қойған/жылжытқан соң соңғы екі жолды қайтала.
- Орындарды автоматты «оңға 20 мм» деп қойма. Тәртіп: (1) әр бөлшекке стрелка ұшын таңда (§4); (2) көріністегі бос тіктөртбұрыштарды тап (контур, размер, разрез белгісі, бұрын қойылған жазулар алынып тасталған); (3) жазуды ең жақын бос орынға қой; (4) қабаттасуды есептеп тексер; (5) суретпен қара. Үлгі: `uz_38_tidy_leaders.cs` — әр жазудың орны жеке берілген.
- DWG альбомында дәл осы ереже СПДС позициялық выноскасымен (екі жол, полка, стрелка) орындалады: полка бағыты `shelf.x ≥ arrow.x → 0, әйтпесе π`.

## 8. Тексеріс (көрсетпес бұрын, әр параққа)

Есеппен:
1. Әр выносканың мәтін қорабы (полка ені × 2 жол биіктігі ≈ 7 мм) басқа выноска қорабымен, размер мәтінімен, разрез белгісімен қиылыспайды → 0.
2. Әр выноска сызығы басқа выноска сызығымен, размер сызығымен қиылыспайды → 0.
3. Сынық полканың жақын ұшынан 1 мм (±0,05) жерде; стрелка ұшы полканың сол жағында тұр (полка стрелкадан ары).
4. Стрелка ұшы өз бөлшегінің қырынан ≤ 0,3 мм; ұзындығы (ұш → полка ортасы) 10–35 мм.
5. Паспорттағы әр бөлшек кемінде бір выноскада бар; «Болты» типі стрелкасыз, қалғаны стрелкамен; маркалы элементте 2-жол бос.

Көзбен: парақ PNG ≥ 4000 px, төрт ширекке бөліп, үлгі парақтың қасына қойып қара. Бір-біріне түскен әріп («-t8t10t16», «БолтыПр1М16») бірден көрінеді.
