## Где лежит
`D:\РАБОЧКА\База_КМ\` — начинать с `00_ОҚЫ_АЛДЫМЕН.md`.

- `03_Логика\` — сводная таблица объектов, типы каркасов и дерево выбора аналога, состав альбома КМ.
- `02_Узлы\` — каталог узлов по темам (базы, фундаменты и анкерные группы, опирание ригелей/ферм, монтажные стыки, фермы и балки переменного сечения, связи, прогоны, фахверк, подкрановые, лестницы/площадки, общие данные).
- `01_Объекты\<объект>\` — паспорт объекта + листы PNG/PDF + текст листов из DWG.

## Правило применения
- База даёт **инженерную логику и состав узлов**, а не стиль. Марки, выноски, листы, штампы — только по правилам Bekassyl ([[Узлы из аналога — привести к своим сечениям]], [[КМ выноска ережесі (09.11)]], [[Стиль альбома КМ — по лестнице ЛК (Қарасу)]]).
- Перед новым объектом КМ: `00_ОҚЫ_АЛДЫМЕН.md` → `03_Логика\02_Типы_каркасов…` (выбор аналога) → паспорт аналога → каталог узлов по теме → оригинальные листы.
- Паспорт — указатель, а не замена чертежа: ответственные размеры (анкеры, болты, толщины) сверять с листом (`листы\`, `pdf\`). В аналогах много противоречий между листами — они перечислены в разделе 8 каждого паспорта, не копировать.

## Как сделано (чтобы повторить для новых аналогов)
DWG → копия в `D:\_claude_work\km_base` → accoreconsole DXFOUT → ezdxf (текст, блоки, СПДС proxy) → рамки листов в модели → `-PLOT` Window в PDF → PNG (лист + 4 четверти) → чтение субагентами по шаблону паспорта (узловые листы — обязательно по четвертям, второй проход) → сборка частей → каталоги. Скрипты: `D:\РАБОЧКА\База_КМ\tools\`.
