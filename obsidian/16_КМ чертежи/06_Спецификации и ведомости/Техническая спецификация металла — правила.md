# Техническая спецификация металла — правила

Источник: работа по КМ БЦ Байтурсынова (13–17.10.2026) и ЖК Қарасу (18.10.2026), замечания Bekassyl.

## Форма
- ACAD-таблица стиля «Спецификация_АС»: Вид профиля ГОСТ | Марка металла | Обозначение и размер | № | массы по группам элементов (5–6 колонок) | Общая масса | Примечание.
- Группы строк: профили (ГОСТ 30245-2003), трубы (ГОСТ 10704-91), прокат листовой (ГОСТ 19903-2015); после каждой группы «Всего профиля / Итог», в конце «Всего масса металла».
- Шрифт ячеек — ISOCPEUR (стиль «Isocpeur»), высота 187,5 (М 1:75). Без жирных/других шрифтов в шапке.
- Добавленные строки обязаны повторять стиль соседних: выравнивание, высота текста, толщина линий сетки (последняя строка группы — жирная нижняя линия). Высота строк 600.

## Формулы
- В ячейках — формулы, показывающие вывод: профиль `=(кг/м*длина_м*0.001)`, пластина `=(t*7.85*0.001*(площадь_м2*шт))`.
- Итоги — Sum только по колонкам, где есть данные (пустая сумма даёт ####).
- После записи — EvaluateFields; проверять дампом таблицы.

## Что считать
- Длины — по чертежу (или по осям расчётной схемы, если она построена по чертежу — оговорить в примечании).
- Закладные детали (раздел КЖ) — строкой с пометкой «Зд-1 (КЖ)» (как в альбомах лестниц).
- Пластины: оголовки, фасонки, заглушки — отдельными толщинами.
- Базы не добавлять, если стойки привариваются к закладным (правило 18.10.2026).

## Сводка в основную спецификацию (19.10.2026)
- Металл отдельного сооружения (лестница + её ограждение) вносится в основную таблицу отдельной колонкой («Лестница»), строками по видам проката. Если такого вида проката в основной таблице нет, добавляется новая группа: двутавры, уголки и т.п.
- Группа из одной позиции — две строки (позиция + пустая), чтобы текст «Сталь С245, ГОСТ…» помещался; затем «Всего профиля / Итог».
- Цвета: строки «Всего профиля / Итог» — синие (5), «Итог» проката — пурпурные (6), «Всего масса металла» — чёрная.
- «Всего масса металла» по колонке = сумма всех «Всего профиля» групп.

## Техника (AutoCAD-таблицы с формулами)
- В существующую таблицу с формулами строки через API не вставлять: часть формул пропадает. Любая запись в таблицу после создания ломает поле первой формулы.
- Надёжно: собрать таблицу заново целиком — тексты, объединения, поворот, цвета, формулы и форматы в одной транзакции — и больше её не править (перемещать можно).
- Если сумма по строке собрана только из ячеек-формул, она теряет формат %lu2%pr2 (показывает 0.835250). Писать `=(Sum(E4:J4)+0)`.

## Проверка
- Масса ед. × кол-во = итог; сумма колонок = общая масса.
- Распечатать лист и проверить, что текст не переносится и не вылезает из ячеек.
