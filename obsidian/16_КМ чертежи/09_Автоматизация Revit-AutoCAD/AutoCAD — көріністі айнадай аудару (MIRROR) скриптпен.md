# AutoCAD — көріністі айнадай аудару (MIRROR) скриптпен

Жазылған: 17.11.2026, БЦ Лестница (екі вариант). Қолданылатын жері: чертежді (план, разрез, СПДС белгілерімен) айнадай аудару керек болғанда — DWG, КМ де, КЖ де.

## Жұмыс істейтін тәсіл
1. Өз AutoCAD данам (`acad.exe "<dwg>" /b script` → NETLOAD → команда), пайдаланушының AutoCAD-ына тимеймін. MIRROR командасы `ed.Command("_.MIRROR", SelectionSet.FromObjectIds(ids), "", p1, p2, "_Y")` арқылы — бұл үшін команда контексі керек (listener емес). MIRRTEXT 0, OSMODE 0.
2. Әр көрініс бөлек аударылады: көрініс терезесіне толық кіретін объектілер handle тізімімен таңдалады (SPDSFORMAT рамкасы кірмейді), осі — көрініс габаритінің ортасы. Сонда көрініс парақта өз орнында қалады, көршісіне шықпайды.
3. Көрініс атауы (MTEXT) бөлек: схема контурының ортасына қойылады.
4. Handle сақталады — «дейін / кейін» салыстыруды handle бойынша жасауға болады.

Мәтін, размер, штрих, отметка, узел белгісі, ось, разрез белгісі оқылатын күйде, дұрыс аударылады.

## MIRROR дәл аудармайтын нәрселер (кейін түзетіледі)
| Не | Не болады | Түзету |
|---|---|---|
| Выноскасыз, тік мәтінді СПДС жазуы («Л» рама шетінде, «Б1», «Пр1») | Мәтін сызықтың бұрынғы жағында қалып, элементтің үстіне түседі | FirstLine ↔ SecondLine ауыстыру (`noteflipv`) |
| Сыртқа шығарылған, выноскалы размер мәтіні («540», «370») | AutoCAD жаңа «әдепкі» жаққа қояды — осьтің, басқа размердің үстіне | TextPosition-ды бастапқының айна орнына қою |
| Тік размер мәтіндері | Оқылатын (сол) жағында қалады, яғни айна орнынан ~3,8 мм ығысады | Көрші выноскамен қабаттасса — выносканы жылжыту |
| Выноскасыз көлденең жазу | Сызық бойымен шамамен бір мәтін еніне жылжиды | Зиянсыз |
| Тік кесу сызықты СПДС разрез белгісі (3-3, 4-4, Р4, Р5) | Сан стрелканың үстінен астына түседі (≈3 мм төмен) — размер тізбегіне, засечкаға тиеді | Белгіні 300-ге жоғары жылжыту не көлденеңінен 100-ге ығыстыру; выноска сызығын кеспейтінін суреттен қарау |
| Кесте формулаларының қосындысы | Дөңгелектенбеген мәндерден есептеледі — көрсетілген сандардың қосындысынан 0,01-ге алшақ шығуы мүмкін | Формуланы `round(…*100)/100` түрінде жазу |

## Тексеріс
- Аударылған СПДС жазуының «жарылған» (explode) мәтін қорабы сенімсіз (мәтін еніне ығысқан) — жазуды суреттен тексер. Размер мәтінінің қорабы сенімді.
- Абсолют емес, **регрессия**: `ovl.py` — мәтін қорабы ↔ сызық / мәтін / ішкі рамка, handle жұбы бойынша, «бастапқы ↔ вариант». Тек ЖАҢА жұптар маңызды.
- `mdiff.py` — бастапқы көріністі суретке шығарып, көлденең аударып, вариантпен салыстырады (размер мәтіндері жасырылады): айна орнында тұрмаған әр жазу көрінеді.
- Өзгермеуі тиіс парақтар: PDF беттерін бастапқымен пиксельдік салыстыру (0 болуы керек).
- Содан кейін ғана ширектеп қарау (drawing-checker).

## Кесте тұзағы
`Table.GenerateLayout()` ұяшыққа формула қойғаннан кейін басқа ұяшықтың формуласын өшіріп тастады (18П жолының жалпы массасы бос қалды). Шақырма: формулаларды қой → `db.EvaluateFields()` → `_.UPDATEFIELD _ALL`. Тәуелді ұяшықтардың мәні тек UPDATEFIELD-тен кейін дұрыс.
