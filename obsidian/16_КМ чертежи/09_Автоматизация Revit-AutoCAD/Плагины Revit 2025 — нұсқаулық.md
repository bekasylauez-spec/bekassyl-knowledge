## 1. ModPlus — КЖ/КМ үшін ең пайдалысы

Revit-те «ModPlus» қойындысы ашылады. Әр команданың «?» белгісі modplus.org-тағы анықтамаға апарады. Кейбір функциялар ақылы: оларды сынақ мерзімімен немесе жазылыммен қолданасыз, ал тегіндері ешнәрсесіз ашылады.

### Конструкции (армирование)
- **Армирование стен.** Деңгейдегі қабырғаларды талдайды: бұрыштық, торцевой және крестовый қиылысуларды, проемдарды табады. Топтарға бөліп, әр топқа арматура ережесін береді. Тек қабырғаларды, тек қиылысуларды немесе тек проемдарды армирлеуге болады. Бос шаблонда да жұмыс істейді.
  *Қалай қолдану:* деңгейдегі қабырғаларды таңдау → «Анализ» → топтар → әр топқа диаметр, қадам, қорғаныс қабаты → «Армировать».
- **Армирование плит / колонн / балок.** Сол логика (талдау → топтау → армирлеу). Колонналарда фундамент плитасымен түйісу және спираль бар.
- **Арматура как тело.** Арматураны «Показать неперекрытой» (кез келген видте) немесе «Показать как тело» (тек 3D) күйіне ауыстырады.
- **Разделение арматуры.** Ұзын түзу стерждерді ұзындығы бойынша бөліп, нахлестка/стык қояды (ұзын стерждерді нормативтік стерженьдерге бөлу үшін).
- **Утилиты работы с арматурой.** Арматурамен жұмыс істеуге арналған көмекші құралдар жинағы.

### Сталь (КМ)
- **Вес пластин.** Пластиналардың массасын есептеп, параметрге жазады. Спецификацияда масса бағанын толтыруға ыңғайлы.

### Листы / Виды / Оформление
- **Дубликатор листов**, **Копировать листы в документы**, **Нумератор листов**: альбом листтерін көшіру және қайта нөмірлеу.
- **Дубликатор видов**, **Фильтры видов** (фильтрлерді шаблондар арасында көшіру), **Обрезка вида**, **Копировать обрезку вида**, **Секущий диапазон** (слайдермен).
- **Выравнивание видов**: видтерді листтер бойынша бір орынға қояды.
- **Раскраска элементов**: шарт бойынша түстеу. Бұл КМ_<марка> фильтрлерінің аналогы.

### Аннотации
- **Размеры вдоль линии**, **Размеры на плане** / **Наружные размеры на плане**: осьтер мен қабырғаларға автоматты размер қояды.
- **Аннотирование сечений**: сечениелерге размер, отметка және марка қояды.
- **Высотные отметки**: разрез пен фасадқа отметкаларды тез қояды.
- **Объединить размеры / Разбить размеры**, **Смещение размеров** (размер мәтіндері қабаттасқанда).

### Тексеру және модель
- **Элементы без марок**, **Отзеркаленные семейства**, **Менеджер предупреждений**, **Сравнение моделей**, **Очистка модели**.
- **Разделить по высоте**: қабырға мен колонналарды деңгейлер бойынша бөледі (каркас модельдеуде керек).
- **Соединение элементов**: қабырға мен балка примыканиесін, соединение мен вырезаниені басқарады.

### Экспорт / параметрлер
- **Экспорт листов**: PDF/DWG-ге шығарады, формат листтен автоматты анықталады.
- **Экспорт в Excel / Импорт из Excel**.
- **Параметры**, **Параметризация**, **Нумерация**, **Сумма параметров**, **Поиск и замена**.

## 2. pyRevit — тегін, ашық кодты «швейцар пышағы»

«pyRevit» қойындысының панельдері мыналар.

**Analysis**
- **ColorSplasher**: параметр мәні бойынша түстеп, легенда немесе фильтр жасайды.
- **Sum**: таңдалған элементтердің параметрін қосады (көлем, ұзындық).
- **Inspect → Diagnose Invisibility**: «элемент неге көрінбейді?» сұрағына жауап береді. Бізде раскостар көрінбей қалған жағдай болған.

**Drawing Set**
- **Sheets**: Batch Sheet Maker (листтерді тізіммен жасау), Rename Selected Sheets, Copy Sheets to Open Documents, Pin All Viewports.
- **Views**: Add Views to Sheets, Duplicate Selected Views, Rename Selected Views, Toggle Grid Bubbles by Direction, Query View Sheet Placement (листке қойылмаған видтер).
- **Revision**: ревизиялар мен облачкаларды басқарады.
- **Schedules**: Export Schedules To CSV, Create Schedule from CSV.
- **Print Sheets**: листтерді тізім ретімен басады.

**Modify**
- **Match Properties / Compare Properties**: екі элементтің қасиеттерін салыстырады немесе көшіреді.
- **Overkill**: қабаттасқан сызықтарды өшіреді (AutoCAD-тағы OVERKILL сияқты).
- **ReNumber**: таңдау ретімен нөмірлейді (марка, позиция).
- **ReValue**: параметр мәтінін шаблонмен өзгертеді.
- **Edit → Replace_Fonts**: шрифтті ауыстырады (ISOCPEUR).
- **Edit → Export View As Image**: 600 dpi PNG.
- **Edit → XLS Export/Import**.
- **Patterns → Batch Import PAT Files**: AutoCAD штриховкаларын импорттайды.

**Project**
- **Preflight Checks**: модельді тексереді.
- **Wipe**: тазалау құралдары (Unused Filters, Unused View Templates, Empty Tags).
- **Family**: Load Families (папкадан көп семейство жүктейді), Save Families.
- **Links → ListDWGs, Reload Links**.

**Selection**
- **Pick**: тек белгілі бір категорияны таңдайды.
- **Select → Select All Objects Of Selected Type**, **Find And Select Entities Without Tags/Dimensions**.
- **Memory (MWrite/MRead)**: таңдауды есте сақтайды.

**Toggles**
- **SectionBox**: секущий параллелепипедті таңдалған элементке қояды.
- **ViewRange**: секущий диапазонды 3D-де көрсетеді.
- **Sync Views**: ашық видтерді синхрондайды.
- **Override 2D**: 2D элементтерді қызылмен белгілейді.

**pyRevit (баптаулар)**
- **Settings**: тіл, жүктелу тәсілі.
- **Extensions**: қосымша кеңейтімдер (мысалы, EF-Tools, pyChilizer).
- **Search**: pyRevit командаларын атымен іздейді.
- **Python Shell**.

> Кеңес: кез келген pyRevit батырмасын **Shift+Click** арқылы бассаңыз, оның баптау режимі ашылады. **Alt+Click** скрипт файлын көрсетеді.

## 3. RevitLookup — модельдің «ішін» көру

Ол «Надстройки» (Add-Ins) қойындысында, RevitLookup тізімінде тұр.
- **Snoop Selection**: таңдалған элементтің барлық API қасиеттерін, параметрлерін, геометриясын және байланыстарын көрсетеді.
- **Snoop Active View / Snoop Document / Snoop Database**: виды, құжатты немесе бүкіл базаны ашады.
- **Snoop Point / Edge / Face / Subelement / Linked element**: геометрияны нүктелеп таңдап қарайды.
- **Search Elements**: Id немесе UniqueId бойынша іздейді.
- **Event Monitor**: Revit оқиғаларын бақылайды.

*Не үшін керек:* «параметр қайда жазылған?», «бұл қай семейство, қай тип?», «отметка неге басқа?» деген сұрақтарға жауап табу. Менің автоматты плагиндерімді (RBLive, km*.cs) жазуда да керек, мысалы BuiltInParameter атауын табу үшін.

## 4. DiRoots (DiRootsOne + ProSheets)

Тегін бөлігі:
- **SheetGen**: көп лист жасайды, шаблоннан вид қояды, тізімді Excel-мен алмасады.
- **ParaManager**: параметрлерді жасайды/өзгертеді, Excel мен shared parameters арқылы.
- **OneFilter**: ережелер бойынша сүзеді және түстейді.
- **ReOrdering**: префикс/суффикспен қайта нөмірлейді.
- **FamilyReviser**: семействоларды атын өзгертеді, worksets.
- **ViewManager**: видтер мен шаблондарды басқарады.

**ProSheets** листтерді PDF/DWG/IFC-ке пакетпен шығарады, файл атауын шаблонмен береді. Тегін нұсқасы айына 150 парақ.

**Жүктеу:** https://diroots.com/revit-plugins/dirootsone/ және https://diroots.com/revit-plugins/prosheets/ беттерінде форманы (аты, email, ел, компания) **өзіңіз** толтырасыз. Жүктелген `.exe` файлды осы `Установщики\` папкасына салыңыз, ары қарай мен тексеріп орнатамын.
Үнсіз орнату: `<installer>.exe /i // /qn accept_eula=1`.

1. Revit 2025-ті ашыңыз. «pyRevit» және «ModPlus» қойындылары, ал «Надстройки» ішінде RevitLookup көрінуі керек.

3. Бір қойынды болмаса, журналды қарау керек: `%LOCALAPPDATA%\Autodesk\Revit\Autodesk Revit 2025\Journals` (соңғы `journal.*.txt`).
