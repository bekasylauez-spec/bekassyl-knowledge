# Тапсырма

`<объект>` КМ узелдерін **бір-бірлеп** жаса: әр узел — жеке цикл (паспорт → модель → сурет → парақ → тексеріс). Келесі узелге тек алдыңғысы §8 «дайын» кестесінен толық өткенде көшесің. Жауап қазақша.

**Тыйым:** барлық узелді бір скриптпен жасау; паспортсыз узел салу; аналог парағын ашпай «өз шешіміммен» жасау; парақ суретін қарамай көрсету.

## 0. Кіріс және оқу
- Модель: `<.rvt>`; ЛИРА: `<.lir>`; узел тізімі (№, не неге, орны): `<жобалау паспорты / узелдер кестесі>`; аналог: `<альбом>`; нәтиже: `<жоба>\`.
- Оқы: BEKA-2 `КМ_стандарт\03_КМ_узел_ережелері.md` (толық), `ЕРЕЖЕЛЕР.md` №33–58; Obsidian «ПРОМПТ — КМ объектісінің түйіндерін толық оформление» §5–§9 (стиль сандары сонда, мұнда қайталанбайды); `База_КМ\02_Узлы\` ішінен осы узел түрінің каталогы.
- Үлгі парақты аш та қара: `D:\РАБОЧКА\Узлы_КМ\БК-КМ_Узел_40К2-30Б1_накладки (лист 1).png` және `… (3D).png`. Сенің әр парағың осыған ұқсауы керек: 1 узел, 3 разрез, толық размер, оң жақ төменде ірі 3D.

## 1. Узелді түсін (сызбай тұрып) — паспорт
`_авто\spec\uzel_NN.md` файлына сегіз сұрақтың жауабын жаз. Бір жауап жоқ болса — узел салынбайды.

1. **Не неге жалғанады:** элементтер, марка, профиль (h×b×s×t стандарттан), өзара орны, бұрыш/еңіс, отметка.
2. **Түрі:** шарнир / қатаң — ЛИРА-дағы шарнир мен М бойынша. Атында жазылады.
3. **Күштер:** N, Q, M (РСУ max). ЛИРА-дан алынбаса «жуық» деп анық жаз.
4. **Күш жолы.** Әр күшке бір жол: «Q: балка қабырғасы → 3 болт М24 → лист −10 → шов kf6 → колонна полкасы». М үшін: «үстіңгі полка → накладка −16 → шов → колонна; қарсысында колоннада қабырға −16». Тізбектің бір буыны жоқ болса (мыс. полка күшіне қарсы қабырға жоқ) — бұл қате, бөлшек қос.
5. **Аналог:** альбом, парақ, узел №. Парақты **өзің аш** (PNG/PDF, ұсақ жерін жақындат), паспорттағы сөзге сенбе. Аналог жоқ болса — серия; оны пайдаланушыға айт.
6. **Бөлшектер кестесі:** поз | атауы | −t × b × l | болат | саны | қай бетке, немен бекітілген. Аналогтағы әр бөлшек осында болуы керек; өзгергені «аналогта → менде → себебі» деп жазылады.
7. **Жинау реті:** зауытта не неге пісіріліп келеді, монтажда не қойылып, не бұралып, не пісіріледі. Осыдан шов түрі (заводской / монтажный) және монтаж саңылауы шығады. Кілт сыя ма, элемент орнына кіре ме — осында тексер.
8. **Видтер жоспары:** негізгі вид қай жақтан; қай разрездер (§5 ережесі); 3D қай бұрыштан.

## 2. Өз сечениеңе келтір
Аналог узелінің мәтінін ауыстыру жеткіліксіз. Кесте жаса: аналог профилі → өз профилің; әр өлшем қалай өзгереді (накладка ені = полка ені; қабырға биіктігі = h − 2t; болт саны қабырға биіктігіне сыя ма: шет ≥ 1,5d₀, қадам ≥ 2,5d₀; лист қалыңдығы аналогтағыдан жұқармайды).

## 3. Модель — бөлшек-бөлшек
Паспорттың 6-кестесінің әр жолы — бір дене. Салған соң кестеге «✓ ElementId» жаз. Түр бойынша **міндетті ең аз құрам** (біреуі жоқ болса узел толық емес):

| Узел түрі | Болуы міндетті |
|---|---|
| Балка → колонна полкасына, қатаң | үстіңгі және астыңғы накладка (не фланец); колоннада екі деңгейде көлденең қабырға; қабырға листі + болттар; балка ұшы тік кесілген, саңылау 20 |
| Балка → колонна, шарнир | тек қабырға листі / L + болттар (≥2); полкалар байланбаған; тірек столигі керек болса |
| Конёк / монтаж стыгы | фланец жұбы + болттар не накладкалар (полка + қабырға); ұштар тік; қабырға ребросы фланецке |
| Прогон тірегі | прогон артында тік лист + 2 болт; еңісте — тірек листі/қысқа столик; прогон стыгы тіректе |
| Связь / распорка ұшы (труба) | заглушка; вкладыш; фасонка (связь енінен әр жағына ≥30); 2 болт; фасонка тірекке толық ұзындықпен пісірілген; тірек элементте фасонка қарсысында қабырға |
| X / Λ / V түйіні | бір диагональ тұтас не ортақ фасонка; осьтер бір нүктеде қиылысады |
| Колонна басы | оголовок листі, астында қабырғалар |
| Кран жолы / консоль | тірек қабырғасы, тартпа, тоқтатқыш |

Жалпы: шов әр түйіскен жиекте; тесік Ø = d + 3; тірелетін ұш 0,3 мм ерте; қиылысу 0; ашық труба ұшы жоқ.

## 4. Модельді өз көзіңмен қара
Аудит (қиылысу 0, шов, тесік) өткен соң **үш сурет** шығар: алдынан, бүйірден, изометрия (≥2500 px). Өзің Read-пен аш. Аналог парағының қасына қойып, паспорттың 6-кестесін жол-жол тексер: бөлшек бар ма, орны сол ма, пішіні сол ма. Күмән болса — модельді түзет, парақты бастама.

## 5. Парақ
- **Бір узел — бір парақ** (А3; сыймаса А2). Масштаб 1:10; А3-ке сыймаса 1:15. Бір парақ — бір масштаб.
- **Видтер:** негізгі вид + разрездер. Ереже: **әр бөлшек кемінде екі видте көрінуі және оның үш өлшемі (қалыңдық, ен, ұзындық) парақтан оқылуы керек.** Әдетте: бүйірден 1-1, пластина деңгейлерінде 2-2 (3-3). Бір видпен шектелген узел қабылданбайды.
- **Размер (ең аз жиынтық):** элемент ені ось арқылы; әр болт тобына «шет – қадам – қадам – шет» екі бағытта; әр пластинаның габариті; саңылаулар (20, 10); пластинаның ось/қырдан привязкасы; жалпы габарит. Размерсіз пластина не болт — қате.
- **Отметка:** элемент үсті/асты, тірек деңгейі — кемінде біреу.
- **Выноска:** әр бөлшекке кемінде бір рет (маркалыға тек марка; бөлшекке «−t10 / С245»; «Болты М24»). Мәтіндер бір-біріне, размерге, разрез белгісіне түспейді — қойған соң суретпен тексер, тисе бос жерге жылжыт.
- **Шов белгісі** (заводской / монтажный, паспорттың 7-тармағынан), **обрыв** әр кесілген ұшта, узел шеңбері «N / схема парағы».
- Қалған стиль сандары — түйін промптының §6.

## 6. 3D сурет — әр узел парағында міндетті
- **Орны:** парақтың оң жақ төменгі бөлігі, штамптың үстінде (үлгі парақтағыдай). Тақырыпсыз (`БК_без_заголовка`).
- **Өлшемі:** негізгі видтен кіші емес — парақтағы ені мен биіктігі негізгі видтікінен ≥ (бос орынға сыйғанша ірі; масштаб 1:10-ға дейін, сыймаса 1:15 / 1:20).
- **Қарау бағыты:** жоғарыдан қиғаш (көз узелден жоғары, шамамен 30–35° төмен қарай, 40–50° бүйірден), барлық пластина мен болт көрінетін жақтан. Бір бағыттан бір бөлшек жасырын қалса — бағытты ауыстыр не екінші 3D қос.
- **Қима қорабы (section box):** узел бөлшектерінің габаритінен әр жаққа ~200 мм кең — айналадағы элементтердің кесіндісі көрінсін, бірақ бүкіл каркас емес.
- **Түрі:** «Заливка с ребрами», детализация жоғары, марка түстері (материал `КМ_<марка>`), шовтар көрінеді, шеттер жіңішке қара; осьтер, деңгейлер, section box рамкасы жасырын.
- **Жасалуы (Revit API):** `View3D.CreateIsometric` → аты «КМ 3D Узел N» → `SetOrientation(new ViewOrientation3D(eye, up, forward))` → `SetSectionBox(bbox)` (узел денелерінің BoundingBox бірігуі + 200 мм) → `Scale`, `DetailLevel = Fine`, `DisplayStyle = ShadingWithEdges` → section box пен аннотация категорияларын жасыр → `Viewport.Create(doc, sheetId, viewId, нүкте)` → `GetBoxOutline()` арқылы: рамка ішінде ме, басқа видке тимей ме, ені негізгі видтен кіші емес пе.
- **DWG альбомында:** сол узелдің Revit моделінен шығарылған 3D сурет (PNG ≥ 3000 px, ақ фон) парақтың сол орнына қойылады; сурет жоба папкасында `…\3D\Узел_NN.png` болып сақталады.

## 7. Парақты тексер
Парақты PNG-ге шығар (≥ 4000 px), **төрт ширекке бөліп жақындатып қара**. Үлгі парақты қасына қой. Сосын бөлек агентке (drawing-checker) «паспорт ↔ парақ» кестесін толтырт; сапа маңызды болса km-expert-reviewer.

## 9. Жұмыс реті және растау
1. Узелдер тізімін көрсет (№, не неге, түрі, аналог) — растау.
2. **Бірінші узелді** толық жаса, §8 кестесімен бірге көрсет. Пайдаланушы ескертуін күт.
3. Ескертуді қатенің бүкіл түрі ретінде жаз (`ЕРЕЖЕЛЕР.md`, `КМ_ҚАТЕЛЕР_ПРОМПТ.md`, `КМ_стандарт\03`, Obsidian, memory), §8-ге жаңа жол қос.
4. Қалған узелдерді **бір-бірлеп** жаса; әрқайсысына §8 кестесі. Екі-үш узел сайын нәтижені көрсет.
5. Соңында: схемалардағы узел белгілері ↔ узел парақтары, ведомость, спецификация (узел листтері кіреді) жаңартылады; үш тексеріс (drawing-checker → km-model-checker → km-expert-reviewer).
