## 2. Альбом құрамы және реті
1. Общие данные (начало / продолжение), Общие указания.
2. **Узлы стыковки вертикальной и горизонтальной арматуры** — екі нұсқа: `C20/25 (B25)` және `C25/30 (B30)` (S03 л. КЖ-9, S05 л. КЖ-10÷11). Барлық примечание осы параққа сілтейді.
3. **Фм-1:** опалубочный чертеж + разрезы 1-1, 2-2 → основная арматура «в 2 слоя верхней и нижней зоне» + сечения 1-1÷4-4 → нижняя доп. по цифровым осям / по буквенным осям → верхняя доп. по цифровым / по буквенным (әрқайсы бөлек схема) → поддерживающие каркасы (Кр) / «поперечная арматура сварными каркасами Ф1» → приямок: нижнее және верхнее армирование бөлек → фиксаторлар (РТм-1) → спецификация.
4. **Выпуски:** «Схема расположения фрагментов выпусков» + әр стенаға «Фрагмент N. Схема расположения выпусков СЖм-N» + «Сечение выпуска», өз кестелерімен `(Фундаменты)_Выпуски_2СА / 4ВД / 5ВРС СЖм-N`.
5. «Схема расположения элементов каркаса на отм. …» — әр деңгейге.
6. **Әр стена СЖм/СШм** (бір стена = 5–9 парақ): Опалубочный чертеж (+ сечения) → Схема вертикального и горизонтального армирования (кейде вертикаль мен горизонталь бөлек) → Схема дополнительного армирования → Сечения 1-1…N-N және горизонталь қималар а-а…с-с → Спецификация (начало / продолжение) → Ведомость деталей → Ведомость расхода стали.
7. **Әр плита Пм** (бірдей қабаттар бір топта: «Пм6 на отм. +19.100, +22.100, +25.100, +28.100»): опалубочный чертеж әр отметкаға жеке → основное армирование верх + низ → доп. **низ по буквенным** → доп. **верх по буквенным** → доп. **низ по цифровым** → доп. **верх по цифровым** → **поперечное армирование** → **пространственные каркасы** → Спецификация + Ведомость деталей + ВРС.
8. Обрамление отверстий (S03 КЖ-146, S05 КЖ-191) — «п.3.14.1 Руководство по конструированию б. и ж.б. конструкций из тяжелого бетона».
9. Лестницы, кладка (СКЦ, газоблок) усиление және спецификациясы.

## 3. Армирование — элемент бойынша
### Фундаментная плита
- Негізгі тор 2 қабат, асты және үсті; доп. арматура негізгілердің арасына, X пен Y бағыты, асты мен үсті — 4 бөлек схема.
- Жоғарғы торды ұстау: поддерживающие каркасы Кр-1/Кр-2/Кр-3 және сварной каркас Ф1 + фиксаторлар; приямок жеке армирленеді.
- Стык: скрутка (≥ 3 вязка), вразбежку ≤ 50 %; примечаниеде тек бір мән: **Ø16А500С Lнахл = 990 мм** (≈ 62d). «Защитный слой основной арматуры см. в сечениях» — санмен жалпы жазылмаған.

### Стена жесткости / шахты
- Тік (вертикальная) + көлденең (горизонтальная) арматура, шетінде **Ск-элемент (П-скоба)**, хомут, шпилька; бүйір/доп. арматура бөлек «Схема дополнительного армирования».
- «Размеры со знаком * даны до наружной грани вертикальной арматуры».
- Ø10…Ø22 полевой зонада нахлестпен, вразбежку, бір қимада ≤ 50 %; Ск-элементтер нахлестпен скруткада.
- Горизонталь арматура, Ск және хомут **шагы — «лист раскладки горизонтальной арматуры»** деген бөлек парақта.
- Тік стержень стыгы: «стык внахлест с изгибом 250 мм» (тік стерженьді 250 мм-де бүгіп жылжыту), «Смещенный стык внахлестку 60D» типі бар.
- Скоба өлшемдері (ведомость деталей жазуларынан):
  | Ø | A = C (аяғы) | B (ені) | dоп (оправка) |
  |---|---|---|---|
  | Ø16 | 820 (51d) және 980–990 (61d) | 170 / 220 / 250 / 270 / 290 | 115 |
  | Ø18 | 920 (51d) және 1100 (61d) | 220 / 270 | 130 |
  | Ø20 | 2000 | 270 | 140 |
  B = стена қалыңдығы − 80 (250→170, 300→220, 350→270) → **скобаның сыртқы қырына дейін 40 мм**.
  Болжам (тексерілмеген): аяқ 51d — B30 стенаға, 61d — B25-ке (екі «Узлы стыковки» парағына сай).
- Выпуски фундаменттен әр стенаға бөлек фрагментпен.

### Плита перекрытия / покрытия
- Негізгі тор асты мен үсті тұтас; доп. — 4 схема (`ДопНиз_X`, `ДопВерх_X`, `ДопНиз_Y`, `ДопВерх_Y` параметрімен бөлінеді).
- «Стержни доп. армирования устанавливать в промежутках между рабочей арматурой; совпадении — сдвинуть».
- Стык: жоғарғы арматура тіректен ≥ 1/3 пролет, төменгі ≤ 1/4 пролет, бір қимада ≤ 50 %, скрутка ≥ 3.
- Отверстие > 300 — обрамление узлымен; жақын отверстиелер бір ортақ обрамление; ойықта негізгі арматура қиылып, денеге отгиб не П-образная арматурамен анкерленеді.
- **Поперечное армирование** әр плитаға бөлек схема (продавливание аймақтары); **пространственные каркасы Кр-1…3** (+ «лягушка», фиксатор Ш1/Ш2 раскладкасы) жоғарғы торды ұстайды.

## 4. Revit техникасы
- 3D арматура + BI-дің **параметрлік арматура-семействолары** («BI_арматура_семейством», «BI_арматура_гнутая»). Семейство параметрлері:
  - қорғаныс: `Защитный слой` сверху / снизу / по краю / по краю_сверху / пересечение / по оси;
  - нахлест: `Нахлест`, `Множитель нахлеста` (k·d), `Округление нахлеста`, `Ручной_Нахлест`, `Без нахлеста`, `Отступ нахлеста`;
  - анкеровка: `Анкеровка_слева/справа_Вкл`, `Множитель анкеровки`, `Ручной_Анкеровка`;
  - тік: `Верт_Шаг`, `Верт_Количество`, `Верт_Длина анкеровки вниз/вверх`, `Верт_Сдвиг для нахлеста` (+ развернуть, длина);
  - отгиб: `BI_отгиб_в_начале/конце`, `Диаметр загиба`.
  Яғни нахлест пен анкеровка қолмен сызылмайды: d × коэффициент, дөңгелектеумен.
- Формалар: BI `Форма_11, 12, 14, 15, 21, 24, 26, 29, 31, 51 хомут`, шпилька, лягушка — ведомость деталей эскиздері осы суреттерден.
- Арматураның түрі (спецификацияны топтау): 1 — стержень, 2 — каркас ішіндегі стержень, 4 — закладной элементі, 8 — каркас, 16 — закладная.
- Кестелер: 2СА — спецификация, 4ВД — ведомость деталей, 5ВРС — ведомость расхода стали, әр элементке фильтрмен.
- Разрезде қорғаныс сызығы: «Линии защитного слоя арматуры» сызық типі.
- Арматура типтерінің саны (мәтін саны, жуық): S03 — Ø8 ~1650, Ø10 ~1530, Ø12 ~1660, Ø14 ~1480, Ø16 ~1170, Ø18 ~900, Ø20 ~490, Ø22 ~360, Ø25 ~50; S05 шамамен 60 %-ы.
