## 2. Қолданылған тізбектің ортақ сұлбасы

**0. Алдын ала оқу.** Obsidian ережелері + аналог + GitHub std-pull (CLAUDE.md; MEM github-standards-first). Әр жобада «аналог бойынша» шешім: Онкоцентр, Ресторан 6.1, АБК, Галакси (OBS барлық жобалар).

**1. ЛИРА-дан дерек алу.**
- Геометрия: `.lir` бинар парсинг (2013 формат: @94 версия, @98 узлы, @106 КЭ, КЭ 38 байт, жесткость массиві 0-based, жойылған КЭ n1=0 өткізу) (OBS Обезвоживание…; MEM lira-read-all-elements) немесе zip ішіндегі txt экспорт (OBS Маслоподготовка Блок 2/3).
- Арматура: ЛИРА GUI «Документация → Стандартные таблицы → Арматура в элементах → в стержнях / в пластинах» → CSV: пластина `…\.INV\tbl01.32_2.csv` (AS1 низ X, AS2 верх X, AS3 низ Y, AS4 верх Y), стержень `tbl01.31_1.csv` (низ = AU1+AU2+AS1, верх = AU3+AU4+AS2, ASW = max(ASW1,ASW2)) (OBS Галакси, БДМ 1/2/4). Жолы: `C:\Users\Public\Documents\LIRA SAPR\LIRA SAPR 2024\work\<модель>.DOCS\.INV\` (MEM lira-csv-export-ui).
- COM опциясы: `SetGenerateCsvTables(True,(31,))`+`StartAnalysis` → AUTORES\tbl01.31_1.csv (ArmaDA ~30 мин күту) (OBS Галакси (48); MEM bdm-block3-columns).
- Мозаика PNG (Резервуар): ұяшық түсі→легенда бин→0.5 м тор (OBS Резервуар).
- ТҰЗАҚТАР: computer-use «ЛИРА-САПР 2024» атын таппады → pyautogui (MEM bdm-block1-rigels); бірнеше сессия бір ЛИРА терезесінде қойындыларды ауыстырады (MEM bdm-block1-rigels); COM `AllTables` тек енгізу кестелері (OBS БДМ Блок 3 колонны); RSN көшіру мүмкін емес (OBS АБК); пайдаланушы CSV-ді өзі шығаруды білмейді («өзің жаса») (MEM lira-csv-export-ui).

**2. Марка унификациясы / армирование есебі.**
- Рм: `lira\design.py` (прогон→марка, ±300 немесе ±600 унификация, As по огибающей) + `rdesign.py` (армирование, As/Asw ≥ ЛИРА, Asw жетпесе хомут Ø үлкейту, Шп1 h>700) → `marks.json` (OBS Маслоподготовка Блок 2/3; БДМ Блок 1).
- Км: `b3types.py`/`b3group.py`, `col_as.py`/`col_tot.py` (Галакси), `types.py` (БДМ3) (OBS).
- Фм/плита: `arm/fm_as→fm_design→fm_fix→fm_pos` (Галакси); `design2.py/merge.py/post.py` (БДМ 1), DP-аймақ топтау, ≥4 ұяшық, ұзындық 300-ге еселі, анкеровка 40d/таблицадан (OBS).
- Стена: `wall_zones.py`, `wall_design.py`, `wall_vert.py` cfg_smN (Галакси; Ø төмен қарай ұлғаяды) (OBS (47)).

**3. Генератор → AutoCAD.** Негізгі тәсіл — «аналог/шаблон парағын импорт+клон+stretch/remap» (MEM cad-clone-analog-stretch, drawing-copy-not-create):
- (a) Өз `acad.exe` данасы + C# тыңдаушы (…LISTEN, JSON op-тар `rz.cs`/`ab.cs`, job.txt/done.txt, `%TEMP%\acadjob_<id>`), op: clone, stretch, pwmap, serfix/levelval, tformula/tnum, eraseregion, list, sp_set/mcset, vpset т.б. (MEM cad-dedicated-instance, reference-spds-api; OBS Галакси/Инструменты/rz.cs 92–104 КБ; DISK).
- (b) `accoreconsole.exe` + C# APPLYOPS (bk.cs, p4.cs): СПДС-сыз операциялар, DXFOUT+ezdxf оқу, AUDIT, layout/PDF (MEM cad-console-net-workflow; OBS БДМ 1/4).
- (c) MultiCAD .NET (McObjectManager) — СПДС объектілерін оқу/жасау (MEM reference-spds-api).
- Тұзақтар: eAtMaxReaders (McObject dispose/MGet; әр batch-тан кейін сақта) (MEM acad-eatmaxreaders); СПДС отметка — levelval бірдей ұзындықпен, 7 таңба үшін клон (OBS Обезвоживание/Цех/Маслоподготовка Км); кесте формулалары EvaluateFields-пен жоғалады → tformula бір op-та немесе tnum (MEM cad-clone-analog-stretch, OBS Галакси (18)); ескі eraseregion шекараны кесетін объектіні өшірмейді (MEM project-maslo-block2-rigels); layout CopyLayout/пакеттік mcrep тыңдаушыны қатырады → layout accoreconsole-да (OBS Маслоподготовка Блок 3 Км).

**4. Тұрақтылық (AutoCAD).** Жұмыс тек `D:\_claude_work\<объект>\` ішінде (C: толса DWG бүлінеді) (MEM acad-job-isolation); әр парақтан кейін integrity + `_good` көшірме; 60 с қатса kill+reopen (relaunch.ps1, batch.py әр 12 парақта reopen); AutoCAD-ты WMI арқылы іске қос (TaskStop-пен өлмеуі үшін); бір сессияға бір runner, бөлек job аттары (acadjob_<id>) (OBS БДМ 1, 4; MEM acad-job-isolation).

**5. Layout / PDF.** Layout-ты current ет → viewport қос (әйтпесе PDF бос); LAYFIX (бір layout = бір парақ, 1:1) → PLOTL (accoreconsole `-PLOT _N <layout>`), 4 параллель + merge+оглавление; «Без СПДС» = QAFLAGS 1 + EXPLODE SPDS*,MCS* (OBS Маслоподготовка Блок 2/3; MEM pdf-from-layouts). **6.
