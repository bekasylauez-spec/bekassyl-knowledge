# Приоритет системы Bekassyl и нормативная проверка

## Главный принцип
**Система армирования, которую Bekassyl последовательно утвердил в диалоге, является основной master-system проекта.**

Внешние нормы, справочники, интернет-источники, аналоги и типовые решения используются:
1. для заполнения пробелов, где правило Bekassyl ещё не задано;
2. для нормативной проверки уже принятого решения;
3. для поиска более полного объяснения механизма работы узла;
4. для проверки безопасности и применимости автоматизации.

## Приоритет решений
1. Последнее явное исправление Bekassyl имеет высший приоритет среди пользовательских правил.
2. Более ранняя версия того же правила считается устаревшей.
3. Внешний источник не должен молча заменять правило Bekassyl.
4. Если нормативный минимум строже — система обязана выявить конфликт.
5. При конфликте Dynamo выдаёт **CHECK_REQUIRED**, а не самовольно меняет конструктивное решение.
6. Если внешняя информация не противоречит системе, её можно использовать как дополнение.

## Принцип автоматизации
Последовательность: **правила Bekassyl → расчёт → оптимизация → нормативная проверка → Revit-модель → рабочие чертежи → спецификация → автопроверка**.

Программные решения, унификацию, раскрой, компоновку листов и техническую реализацию Dynamo система выбирает самостоятельно.
Bekassyl спрашивается прежде всего тогда, когда требуется новое конструктивное решение по армированию.
