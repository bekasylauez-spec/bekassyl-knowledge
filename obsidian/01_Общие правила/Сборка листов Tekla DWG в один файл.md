# Сборка листов Tekla DWG в один файл (метод, 03.11.2026)

Правило пользователя: «двг-ның барлығын 1 файлға жина. Жаңадан сызба копировать ет. Тек жоқ сызықты ғана сыз» — копировать существующие листы, рисовать только отсутствующее.

1. Сначала сверка: каждый исходный DWG печатается (Layout1, 1:1, DWG To PDF) и сравнивается с PDF тома пикселями (200 dpi, допуск 9 px). Кластеры «есть в PDF, нет в DWG» смотреть глазами.
2. Типичные пропуски Tekla-экспорта:
   - тексты/примечания в модели без видового экрана (общие данные) → перенести в лист по совмещению с PDF;
   - текст обрезан краем узкого видового экрана → полный текст в пространстве листа поверх;
   - растровый логотип с потерянным путём → извлечь из PDF.
3. Сборка (accoreconsole + C# KMMERGE): модель листа N со сдвигом Y −100 000·N; Layout создаётся, затем клонируются ВСЕ объекты листа **вместе с общим видовым экраном** (первый VIEWPORT), потом лист активируется и экраны включаются. Если общий экран не клонировать — видовые экраны остаются пустыми.
4. Имена листов без запятых (AutoCAD не принимает «,»). IMAGEFRAME 0, WIPEOUTFRAME 0.
5. Проверка: печать всех листов собранного файла и повторное сравнение с PDF; остаток — только шрифты.

## Перенос листов в модель («барлығын моделде сызып шықшы», 03.11.2026)
- Каждый лист → рамка в модели: бумажные объекты ×S (S = масштаб главного видового экрана, без видов — 100), содержимое каждого видового экрана: модель→бумага→×S, линии обрезаются по экрану, остальное — если центр внутри, тексты на границе пропускаются (их полные копии уже на листе).
- Сначала содержимое экранов, потом бумажные объекты (маскировки wipeout должны быть сверху).
- Объекты Tekla, «припаркованные» за листом, не переносить — иначе попадают в соседнюю рамку.
- Тип линий: LinetypeScale ×S (PSLTSCALE=1 в исходниках).
- Новые марки-выноски на другой стороне оси: полка под текстом, выноска переносится, текст не зеркалить.

## Знак двутавра в марках (правило 04.11.2026)
- Марка двутавра пишется знаком двутавра, не буквой «I». Если источник даёт «I20Ш1» (Tekla), заменить «I» на начерченный знак: стойка + верхняя и нижняя полки, высота = высоте текста, ширина полки ≈0,6h, наклон как у шрифта (ГОСТ type A italic — 15°).
