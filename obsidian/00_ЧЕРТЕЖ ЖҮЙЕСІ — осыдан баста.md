# ЧЕРТЕЖ ЖҮЙЕСІ — кез келген сессия осыдан бастайды

Жазылған: 11.11.2026. Источник: пайдаланушы — «Клаудта кез келген сессияда чертеж жасайтын болса бірден GitHub-тан оқып, қалай жасалуы керек системасын тауып оқитын ереже жаса».
Бұл файл екі жерде бірдей тұрады: GitHub `bekasylauez-spec/bekasyl-kzh-km` → `_Стандарт_КЖ\00_ЧЕРТЕЖ_ЖҮЙЕСІ.md` және Obsidian `Bekassyl\00_ЧЕРТЕЖ ЖҮЙЕСІ — осыдан баста.md`. Біреуін өзгертсең — екіншісін де өзгерт.

## 0. Әр чертеж жұмысының алдында (міндетті)

1. Стандартты жаңарт: `powershell -NoProfile -ExecutionPolicy Bypass -File "D:\РАБОЧКА\.claude\std-pull.ps1"` (BEKA-2-де `R:\.claude\std-pull.ps1` не `\\BEKA-1\РАБОЧКА\.claude\std-pull.ps1`). Ол `STD_ROOT=` (стандарт папкасы), `INDEX=` (осы файл), `STATE=`, `COMMIT=` жолдарын шығарады.
2. `STATE` OK болмаса — жергілікті/кэштегі нұсқамен жұмыс істе, бірақ пайдаланушыға «стандарт жаңартылмады» деп айт.
3. Төмендегі 1-кестеден жұмыс түрін тап, көрсетілген файлдарды **сол ретпен** оқы. Не оқығаныңды қысқа айт.
4. Жұмыс біткенде жаңа ереже шықса — 3-бөлім бойынша жаз да GitHub-қа жібер.

`STD` = `STD_ROOT` (GitHub, пайдаланушы бекіткен ережелер — басым). `OBS` = `D:\РАБОЧКА\Bekassyl` (Obsidian). `БАЗА` = `D:\РАБОЧКА\База_КМ`. `УЗЛЫ` = `D:\РАБОЧКА\Узлы_КМ`.

## 2. Басымдық (қайшылық болса)

1. Пайдаланушының осы чаттағы сөзі.
2. `STD` (GitHub): `ЕРЕЖЕЛЕР.md`, `КМ_ҚАТЕЛЕР_ПРОМПТ.md`, `КМ_стандарт\`.
3. Obsidian `Bekassyl` + `~/.claude/CLAUDE.md` + memory.
4. Пайдаланушы шаблоны мен жоба аналогы (стиль, парақ реті).
5. `БАЗА` аналогтары (тек конструктив, стиль емес).
Екі ереже қайшы келіп, қайсысы кейінгі екені анық болмаса — пайдаланушыдан сұра.

## 3. Жаңа ереже шыққанда (пайдаланушы түзетсе)

1. Қатенің бір нүктесін емес, бүкіл түрін түзет.
2. Жаз: `STD\ЕРЕЖЕЛЕР.md` (келесі № нөмірмен, пайдаланушы сөзімен), КМ болса `STD\КМ_ҚАТЕЛЕР_ПРОМПТ.md` және `STD\КМ_стандарт\` тиісті файлы, чек-листке (`06`) жаңа тармақ; Obsidian тақырып жазбасы; memory.
3. Revit-те түзетілген узел ережесі DWG-ға да қолданылады (№62), 3D-ден басқасы.
4. GitHub-қа жібер: BEKA-2-де `D:\Бекасыл КЖ КМ` ішінен commit + push; басқа компта кэштен (`%LOCALAPPDATA%\bekassyl-std`) тек `_Стандарт_КЖ` файлдарын өзгертіп commit + push. Push алдында `git pull`.
5. Осы индекске жаңа файл/бөлім қосылса — 1-кестені жаңарт (екі көшірмесін де).

## 4. Желі не GitHub жоқ болса

Кэш (`%LOCALAPPDATA%\bekassyl-std\_Стандарт_КЖ`) не BEKA-2-дегі жергілікті папка оқылады; ол да жоқ болса — Obsidian `Bekassyl` (`16_КМ чертежи`, `01_Общие правила`, `14_Мои правила`) және memory. Бұл жағдайды есепте айт.
