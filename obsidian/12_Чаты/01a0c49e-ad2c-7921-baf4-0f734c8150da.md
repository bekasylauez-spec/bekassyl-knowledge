# CAD reconstruction apartment plan

Тема: CAD
Дата импорта: 30.09.2026
Источник: codex, ID `01a0c49e-ad2c-7921-baf4-0f734c8150da`.

## Резюме и обучение

Пользователь задаёт метод CAD reconstruction: изображение → измерения → координаты → геометрия → SVG/DXF; сначала единая система координат и коррекция перспективы, затем геометрия. Нельзя рисовать стены приблизительно; итог не делается до измерений.

## Требования пользователя — фрагменты источника

> Сенің міндетің — берілген техпаспорттағы пәтер жоспарын "суретке ұқсатып"
> қайта салу ЕМЕС.
> 
> Сен CAD reconstruction жасауың керек:
> IMAGE → MEASUREMENTS → COORDINATES → GEOMETRY → SVG/DXF.
> 
> Соңғы сызбаны бірден жасама.
> 
> ━━━━━━━━━━━━━━━━━━━━━━
> 1. REFERENCE COORDINATE SYSTEM
> ━━━━━━━━━━━━━━━━━━━━━━
> 
> Алдымен планның өзін суреттен анықта.
> 
> План орналасқан bounding box-ты тап:
> 
> LEFT   = x0
> TOP    = y0
> RIGHT  = x1
> BOTTOM = y1
> 
> Сол жақ жоғарғы нүктені:
> 
> P0 = (0,0)
> 
> деп қабылда.
> 
> X → оңға
> Y → төмен
> 
> бағытталсын.
> 
> Планның барлық элементінің позициясын осы бір координаталық жүйеде анықта.
> 
> ЕШБІР қабырғаны "шамамен осы жерде" деп салуға болмайды.
> 
> ━━━━━━━━━━━━━━━━━━━━━━
> 2. PERSPECTIVE / PHOTO CORRECTION
> ━━━━━━━━━━━━━━━━━━━━━━
> 
> Егер reference фотосуреттен алынған болса, қағаздың перспективасын план геометриясы деп қабылдама.
> 
> Алдымен:
> - page perspective;
> - rotation;
> - skew;
> - camera distortion
> 
> әсерін есепке алып, планды front-facing orthographic view ретінде қарастыр.
> 
> Егер PDF-тен алынған таза бет берілсе, PDF нұсқасын негізгі reference ретінде пайдалан.
> 
> ━━━━━━━━━━━━━━━━━━━━━━
> 3. EXTRACT ALL VERTICES
> ━━━━━━━━━━━━━━━━━━━━━━
> 
> Сыртқы контурдан баста.
> 
> Контурдағы БАРЛЫҚ бұрылыс нүктелерін ретімен анықта:
> 
> P1 = (x,y)
> P2 = (x,y)
> P3 = (x,y)
> ...
> Pn = (x,y)
> 
> Контурды:
> 
> P1 → P2 → P3 → ... → Pn → P1
> 
> ретімен жап.
> 
> Тіпті кішкентай:
> - выступ;
> - ниша;
> - шахта;
> - балкон;
> - қабырға ығысуы
> 
> болса да жеке vertex ретінде енгіз.
> 
> Контурды қарапайым төртбұрышқа айналдыруға БОЛМАЙДЫ.
> 
> ━━━━━━━━━━━━━━━━━━━━━━
> 4. CREATE GEOMETRY TABLE FIRST
> ━━━━━━━━━━━━━━━━━━━━━━
> 
> СЫЗУДАН БҰРЫН маған осындай кесте жаса:
> 
> ID | TYPE | START X | START Y | END X | END Y | THICKNESS | SOURCE
> 
> Мысалы:
> 
> W01 | exterior wall | 0 | 0 | 124 | 0 | 8 | image
> W02 | exterior wall | 124 | 0 | 124 | 37 | 8 | image
> W03 | interior wall | 48 | 0 | 48 | 82 | 5 | image
> 
> Барлық сыртқы және ішкі қабырға осы кестеде болуы керек.
> 
> ━━━━━━━━━━━━━━━━━━━━━━
> 5. USE DIMENSIONS AS CONSTRAINTS
> ━━━━━━━━━━━━━━━━━━━━━━
> 
> Пландағы жазылған өлшемдер — PRIMARY CONSTRAINTS.
> 
> Мысалы, қабырға жанында:
> 
> 4.23
> 3.97
> 1.20
> 1.34
> 
> сияқты өлшем тұрса, графикалық пиксель өлшемінен бұрын сол санға сен.
> 
> Яғни:
> 
> printed dimension > inferred image measurement.
>

> [Фрагмент сокращён]
