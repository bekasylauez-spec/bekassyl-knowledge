# Тассай АР — стены по Схеме каркаса, пересчёт площадей (20.10.2026)

## Запрос
«Мынаның стеналарын өзгертеміз… одан алатының стеналардың орналасуы, сосын площадын ретте» — в АР `Tassay B Blok_2021.03.22.dwg` заменить стены по `2.Схема каркаса.dwg` (стены 370/250/120) и пересчитать площади помещений.
Уточнения пользователя: менять АР; 4.KAT — по схеме «4 этаж»; оба ряда планов (нижний с названиями и верхний с турецкими названиями).

## Правила / решения
- Схема каркаса = эталон расположения стен; железобетон (колонны) берётся из АР.
- Наружная стена 370, наружный контур не меняется — помещения уменьшаются внутрь.
- Площадь по граням стен; дверной проём — граница по линии стены.
- Размеры `размеры общие` не перестраивались.

## Метод
- accoreconsole DXFOUT → ezdxf/shapely; растр 0,5 см: старое помещение − новые стены + освобождённые полосы старых стен (заполнение по оси, раздел посередине); дверные проёмы закрываются в габарите блока двери; объединение — только если ≥60 % общей стены снесено.
- C# APPLYWALLS (WblockClone из схемы + TransformBy, правка вершин m2, клон подписи + Field `AcObjProp…Area`), `db.EvaluateFields()`. Скрипты: scratchpad сессии 5eb15a46 (`rooms.py`, `genops.py`, `net\walls.cs`).
