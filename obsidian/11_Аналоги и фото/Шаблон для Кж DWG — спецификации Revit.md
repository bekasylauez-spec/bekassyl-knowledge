# Шаблон для Кж.dwg — спецификации и решения для Revit

Дата разбора: 2026-10-02.
Источник: `C:\Users\Admin\OneDrive\Осноыной работа\Шаблон для Кж.dwg`.
DWG открыт через AutoCAD Core Console 2021 и выгружен в DXF для машинного анализа.

## Статус источника

Это **аналог оформления КЖ**, а не универсальная норма.
Подтверждённые пользователем правила Bekassyl имеют приоритет.
Числа и узлы из этого DWG использовать как шаблон/пример до отдельного подтверждения.

## Формат спецификации

В нескольких таблицах DWG повторяется один заголовок:

**Поз. | Обозначение | Наименование | Кол. | Масса ед.кг | Примечание**

Для Revit Schedule этот порядок принять базовым шаблоном данного аналога.
Поле **Масса ед.кг** — масса одной единицы позиции в килограммах.

## Проверка массы по реальным строкам

В блоке строки `vcBlockST1-6-1` есть атрибуты:
`ПОЗИЦИЯ, ОБОЗНАЧЕНИЕ, СЕТКА, НАИМЕНОВАНИЕ1, НАИМЕНОВАНИЕ2, РАЗМЕРЫ, КОЛИЧЕСТВО, МАССА, ПРИМЕЧАНИЕ`.
Примеры из DWG:
- С1: Кол. 14; Масса ед. 3.01 кг; Примечание 42.1.
- С1: Кол. 13; Масса ед. 3.01 кг; Примечание 39.1.
- С1: Кол. 9; Масса ед. 3.01 кг; Примечание 27.1.
- С1: Кол. 7; Масса ед. 3.01 кг; Примечание 21.1.

Во всех примерах значение в последнем поле равно **Кол. × Масса ед.** с округлением до 0.1 кг.
То есть шаблон хранит индивидуальную массу отдельно, а общий вес позиции вычисляется.
При воспроизведении внешнего вида аналога общий вес можно выводить в последней колонке; внутренне в Revit лучше держать отдельный параметр **Масса позиции, кг**.

## Состав поля «Наименование»

Для сетки С1 в строке используются отдельные данные:
- обозначение: `ГОСТ 23279-2012(214-403-01010)`;
- тип сетки: `4С`;
- наименование 1: `5Bp-I-100`;
- наименование 2: `5Bp-I-100(50)`;
- размеры: `75x130`.

В Revit эти составляющие хранить отдельными параметрами, а отображаемое поле «Наименование» собирать формулой/общим параметром.

## Связь с ведомостью деталей

В DWG повторяется примечание: **«Позиции со "*" см. "Ведомость деталей" на данном листе.»**
Для автоматизации: позиция со звёздочкой должна иметь ссылку на геометрию/эскиз в ведомости деталей.
## Дополнительные решения из аналога

- Для части листов расход арматуры в погонных метрах указан **с учётом нахлёста**.
- Для лестницы Л1 спецификация элементов и ведомость расхода стали вынесены на КЖ-9.3.
- В примечании лестницы указано: масса металла в спецификации приведена **без 1% трудноустранимых потерь** при укладке арматуры.
- Для плиты перекрытия спецификация вынесена на КЖ-7.14.
- Стержни из «Ведомости деталей» в данном аналоге гнут механически в холодном состоянии; на отдельных листах указан радиус 3d–5d. Не превращать это число в глобальное правило без сверки с правилами Bekassyl/нормами.
- Для стен в аналоге: шпильки периферийной зоны — шаг 100 мм; в поле — 400×400 мм в шахматном порядке. Использовать как подтверждающий аналог, не как автоматическое универсальное правило.

## Параметры Revit для спецификации

Минимальный набор shared/project parameters:
- Позиция;
- Обозначение;
- Наименование;
- Количество;
- Масса единицы, кг;
- Масса позиции, кг = Количество × Масса единицы;
- Примечание;
- Признак «Есть ведомость деталей»;
- Марка/тип сетки;
- Размеры;
- ГОСТ/норматив;
- Источник/лист.

## Правило для Dynamo

Dynamo должен считать массу позиции автоматически и не доверять ручному вводу итоговой массы. Округление отображения — до 0.1 кг там, где это требуется шаблоном. Полную точность сохранять в параметре модели.
