# Windows видеокарта құлау диагностикасы

- Дата: 2026-11-08
- Сессия: `1fcb0ef9-40bc-476a-adb8-414dec55583c`

## Пайдаланушы

<pasted_content id="6d63">
Менің Windows компьютерімде видеокарта немесе драйвер құлап жатыр: жұмыс кезінде екі монитор қарайып кетеді, сосын экранда көлденең сызықты бұзылған сурет пен күлгін жолақтар шығады. Мәселенің себебін тауып, жөндеуге көмектес.

Тәртібі:
1. Алдымен тек диагностика жаса, ештеңе өзгертпе:
   - Видеокартаның моделін, драйвер нұсқасын және оның күнін анықта (PowerShell: Get-CimInstance Win32_VideoController).
   - Соңғы 7 күндегі System журналынан мына оқиғаларды тап: Display/nvlddmkm/amdkmdag 4101, WHEA-Logger, Kernel-Power 41, LiveKernelEvent 141/117. Олардың уақыты мен мәтінін кесте түрінде көрсет.
   - C:\Windows\LiveKernelReports және Minidump папкаларында файлдар бар-жоғын тексер.
   - Мүмкін болса, GPU температурасын тексер (nvidia-smi немесе басқа қолжетімді құрал арқылы).
   - Windows нұсқасын және жедел жад (RAM) көлемін анықта.
2. Нәтижелерді қысқаша қорытып, ең ықтимал себепті және ұсынатын әрекеттеріңді тізім түрінде айт.
3. Кез келген өзгеріс жасамас бұрын менен рұқсат сұра. Рұқсат берсем:
   - Алдымен жүйені қалпына келтіру нүктесін (restore point) жаса.
   - Драйверді тек өндірушінің ресми сайтынан (NVIDIA/AMD/Intel) жаңарт.
   - Chrome мен Claude Desktop-та аппараттық үдетуді (hardware acceleration) өшір.
   - Қажет болса, Windows Memory Diagnostic-ті жоспарла.
4. BIOS-ты өзгертпе, тізілімді (registry) өзгертпе, файлдарды өшірме, оверклок не андервольт баптауларын қозғама.
5. Соңында не өзгергенін және оны қалай кері қайтаруға болатынын жаз.

Жауапты қазақ тілінде, қысқа әрі нақты бер.
</pasted_content id="6d63">

## 3. Қорытынды
**Ең ықтимал себеп — видеокарта немесе оның драйвері.** Сізде екі монитор бірге қарайды, сосын көлденең сызықтар мен күлгін жолақтар шығады. Журналда да nvlddmkm қатесі және 141/193 оқиғалары бар. Мұндай белгілер GPU-дың өзі (видеожады), кабель немесе қуат ақаулығы кезінде көп кездеседі. Драйвер қатесі де мұндай сурет беруі мүмкін.

Екінші ықтимал себеп — жүйенің жалпы тұрақсыздығы. BSOD кодтары әртүрлі (0xEF, 0x18), ал Kernel-Power 41 BSOD-сыз шыққан. Мұндай жағдай RAM 6400 XMP режимінде немесе i7-14xxx процессорында болатын белгілі тұрақсыздықта кездеседі.

## 4. Ұсынылатын әрекеттер
1. Жүйені қалпына келтіру нүктесін (restore point) жасау.
2. NVIDIA драйверін тек nvidia.com сайтынан қайта орнату: таза орнату («Clean install» белгісімен), тұрақты нұсқа немесе Studio Driver.
3. Chrome мен Claude Desktop-та аппараттық үдетуді өшіру.
4. Windows Memory Diagnostic-ті келесі қайта қосылуға жоспарлау.
5. **Өзіңіз жасайсыз (мен тимеймін):**
   - видеокартаның қуат кабелін және монитор кабельдерін қайта тығыз қосып шығу;
   - сызықтар қайталанса, BIOS-та XMP-ді уақытша өшіріп көру;
   - BIOS-ты Colorful сайтынан жаңарту.
6. Драйвер ауыстырылғаннан кейін де сызықтар мен жолақтар шықса, видеокарта жаңа, сондықтан кепілдікпен (RMA) ауыстыру керек.

BIOS-қа, тізілімге (registry), файлдарға және оверклок баптауларына тиіспеймін. Рұқсат берсеңіз, 1–4 қадамдарды жасаймын, соңында не өзгергенін және оны қалай кері қайтаруға болатынын жазамын.
