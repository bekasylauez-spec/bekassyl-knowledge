BEKA-1-дегі оптимизацияны осы компқа (BEKA-2) орнат. Қазақша жауап бер, соңында «Бәрі бітті» + тексеріс нәтижесі.

Дереккөз — ортақ папка D:\РАБОЧКА\.claude (BEKA-2-де ол желі сілтемесі арқылы ашылады; жолын memory main-pc-central.md / shared-memory-two-pcs.md бойынша тап, мысалы R:\.claude немесе \\BEKA-1\...). Ішінде: agents\ (5 файл), statusline.py, usage_report.py, CLAUDE.global.md.

Істе:
1. agents\*.md (obsidian-reader, file-scout, script-worker, drawing-checker, spec-calculator) → %USERPROFILE%\.claude\agents\ көшір. Ішіндегі жолдар D:\РАБОЧКА\... болса — BEKA-2-дегі нақты жолға ауыстыр (memory, Obsidian, D:\Бекасыл КЖ КМ\_Стандарт_КЖ).
2. statusline.py → %USERPROFILE%\.claude\statusline.py.
3. %USERPROFILE%\.claude\settings.json — алдымен бэкап (backups\settings.json.bak-<күн>), содан кейін бар кілттерді (hooks т.б.) сақтап, тек мыналарды қос:
   - "model": "opus"
   - "env": { "CLAUDE_CODE_SUBAGENT_MODEL": "sonnet" }
   - "statusLine": { "type": "command", "command": "python C:/Users/<user>/.claude/statusline.py", "padding": 0 } (python жолын тексер, Python 3.13 бар)
   JSON-ды Python-мен өзгерт, қолмен емес; соңында json.load-пен тексер.
4. %USERPROFILE%\.claude\CLAUDE.md ішіндегі bekassyl-global блогында «## Модельдер және субагенттер (оптимизация, 04.11)» бөлімі бар ма — жоқ болса claude-shared.ps1-ді іске қос (ол CLAUDE.global.md-ден блокты жаңартады), блоктан тыс мәтінге тиіспе.
5. Тексеріс:
   - echo '{"model":{"display_name":"Opus"},"cost":{"total_cost_usd":0.5}}' | python %USERPROFILE%\.claude\statusline.py — жол шығуы керек.
   - python <ортақ>\.claude\usage_report.py 30 — BEKA-2 үшін есеп; нәтиже HTML-ді D:\Бекасыл КЖ КМ\_Стандарт_КЖ\usage_report_BEKA-2.html-ге сақта (скрипттің OUT жолын аргумент/көшірмемен өзгерт, BEKA-1 файлын бұзба).
   - %USERPROFILE%\.claude\agents ішінде 5 файл бар екенін тексер.
6. Memory model-delegation-setup.md ішіне «BEKA-2-де орнатылды <күн>» жолын қос; Obsidian 12_Чаты-ға қысқа жазба.

Ескерту: жаңа модель/агенттер келесі жаңа чатта ғана іске қосылады. Пайдаланушының AutoCAD/Revit-іне тиіспе.

3. **settings.json.** Алдымен бэкап жасалды: `backups\settings.json.bak-2026-11-05`. Содан кейін Python-мен `model: opus`, `env.CLAUDE_CODE_SUBAGENT_MODEL: sonnet` және `statusLine` қосылды. Бұрынғы кілттер (hooks Stop/SessionEnd, theme т.б.) орнында. Python 3.13.17 бар.
