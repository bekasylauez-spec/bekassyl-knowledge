## Пайдаланушы

<pasted_content id="35eb">
BEKA-2-де Claude сессиясы R:\ папкасында ашылады (R: = \\192.168.0.107\рабочка).
Claude memory папкаға байланып сақталады, сондықтан BEKA-2-де мынадай болып тұр:
  C:\Users\beka\.claude\projects\R--\memory           → бос (0 жазба)
  C:\Users\beka\.claude\projects\D---------\memory    → 84 жазба (D:\РАБОЧКА)
  C:\Users\beka\.claude\projects\D---------------\memory → 27 жазба

Не істеу керек:
1. link-git.ps1 / tools\setup.ps1 скриптіне мынаны қос: BEKA-2-де memory тек
   D--------- папкасына ғана емес, R-- папкасына да түсетін болсын. Ең жақсысы —
   R--\memory папкасын D---------\memory папкасына junction ету
   (New-Item -ItemType Junction). Сонда memory бір жерде болады да,
   қай папкада ашсам да бірдей жүктеледі.
2. Маңызды жазбалар әр папкада өздігінен көрінуі үшін оларды MEMORY.md
   индексіне қос. Ал барлық жобаға ортақ ережелерді (оформление, КМ қателері)
   C:\Users\beka\.claude\CLAUDE.md файлына жаз — ол memory емес, кез келген
   папкада жүктеледі.
3. Скриптті қайта іске қосып, BEKA-2-де тексер: R--\memory ішінде 84 жазба
   көрінуі керек.
