# Бека 1 рабочкасына кіру мәселесі

- Дата: 2026-11-09
- Сессия: `8a9e94dd-7c75-4d64-9c3b-d8981dedefe4`

## Пайдаланушы

Неге мен Бека 1 дің рабочкасына кіре алмадым

## Claude

**Себебі:** BEKA-1 компьютерінің IP мекенжайы өзгерген. Бұрын **192.168.0.107** болатын, қазір **192.168.0.104**. Роутер оған жаңа адрес берген (DHCP). Ал BEKA-2-дегі `D:\РАБОЧКА` сілтемесі әлі ескі мекенжайға қарап тұр: `\\192.168.0.107\РАБОЧКА`. Ол адрес енді жауап бермейді, сондықтан папка ашылмады.

Тексеріс нәтижесі:
- `192.168.0.107`: ping жоқ, папка ашылмайды.
- `192.168.0.104` пен `\\BEKA-1\РАБОЧКА`: екеуі де жұмыс істейді.
- `R:` дискі: қазір .104-ке қосулы, ішіндегі файлдар көрініп тұр.

**Түзету:** сілтемені IP-ге емес, компьютер атына бағыттау керек. Сонда IP қайта ауысса да ашыла береді. Мен бұл папканы өшіре алмадым, қорғау ережесі тыйым салды. Сондықтан BEKA-2-де **cmd-ні әкімші ретінде** (Run as administrator) ашып, мына командаларды кезекпен орындаңыз:

```bash
rmdir D:\РАБОЧКА
```

```bash
mklink /D D:\РАБОЧКА \\BEKA-1\РАБОЧКА
```

`rmdir` тек сілтемені өшіреді, BEKA-1-дегі файлдарға тимейді.

Мұндай жағдай қайталанбауы үшін роутерде BEKA-1-ге тұрақты IP бекітіп қоюға да болады (DHCP reservation).

Бәрі бітті: себебі анықталды (IP .107 → .104), `\\BEKA-1\РАБОЧКА` пен R: жұмыс істейтіні тексерілді. Сілтемені жоғарыдағы командамен сізге ауыстыру қалды.
