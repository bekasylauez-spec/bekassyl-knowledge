## Пайдаланушы

Телефоннан осы компты басқар алуым керек. Оны қалай жасаймыз. Мысалы жаңа сессия ашып жұмыс жасауы керек. Бұлтта емес

## Claude

Бұл компта Remote Control қосулы тұр. «Жаңа сессияларды Remote Control-ға қосу» баптауы — **On**, яғни осы компта ашылған әр сессия телефоннан көрінеді. Бұлт керек емес: жұмыс осы компта, D:\РАБОЧКА-да жүреді, телефон тек экран мен пернетақтаның орнын басады.

## Телефоннан қалай басқарасыз

1. Телефонға **Claude** қосымшасын орнатыңыз да, осы аккаунтпен ([email жасырылды]) кіріңіз.
2. **Code** бөліміне өтіңіз. Онда осы компта ашылған сессиялар тұрады: оларды ашып, хат жазып, жұмысты жалғастыра бересіз.
3. **Жаңа сессия ашу.** Ең сенімді жолы — «басқарушы» сессия:
   - Компте бір сессияны ашық қалдырасыз (мысалы, осы сессияны).
   - Телефоннан соған жазасыз: *«Жаңа сессия аш: Аэротенк Рм парағын түзет»*.
   - Мен осы компта, D:\РАБОЧКА папкасында бөлек жергілікті сессия ашамын, ол да телефонда бірден көрінеді. Сол сессияға тікелей жазып, жұмысты сонда жалғастырасыз.

   Телефондағы Code бөлімінде компті таңдап, жаңа сессияны тікелей ашатын батырма болуы мүмкін. Бірақ ол сіздің нұсқаңызда бар-жоғын тексере алмадым. Бар болса, сол батырманы қолдана беріңіз.

## Компке қойылатын шарттар
- **Claude desktop қосымшасы ашық тұруы керек.** Терезесін кішірейтуге болады, бірақ жаппаңыз.
- **Комп ұйықтамауы керек.** Claude жұмыс істеп жатқанда компті өзі ояу ұстайды, бірақ бос тұрғанда Windows ұйықтатып тастауы мүмкін. Онда телефоннан жаңа тапсырма жібере алмайсыз. Бұл жүйелік баптау болғандықтан, оны өзім өзгертпеймін. Әкімші құқығымен ашылған PowerShell-де мына екі команданы орындасаңыз, комп токқа қосулы тұрғанда ұйықтамайды:
```bash
powercfg /change standby-timeout-ac 0
```
```bash
powercfg /change hibernate-timeout-ac 0
```
- **Интернет қосулы тұруы керек.** Телефон мен комп Anthropic сервері арқылы байланысады, сондықтан екеуі бір желіде болуы шарт емес.

## Ескерту
- Рұқсат сұрайтын әрекеттер телефонға хабарлама болып келеді, оларды телефоннан растайсыз.
- AutoCAD/Revit жұмысы бұрынғыдай осы компта жүреді. Дайын PDF не скриншотты телефонға файл етіп жібере аламын.

Бәрі бітті: Remote Control қосулы екенін тексердім, оны қалай қолдану керегін жоғарыда жаздым. Компті ұйықтатпау үшін жоғарыдағы екі команданы орындау ғана қалды.
