## Семейство жасау (Autodesk ұсынатын тәртіп)

1. Алдымен жоспарлау: өлшемдері, видтерде қалай көрінетіні, хост керек пе, енгізу нүктесі қайда.
2. Дұрыс шаблон таңдау: балка үшін Structural Framing, колонна үшін 2-Level Based, арматура формасы үшін Rebar, түйін үшін Detail Item, пластина үшін Face-based.
3. **Қаңқа жасау:** бастапқы нүктені (origin) бекіту, reference plane салу, размер қойып құлыптау, label арқылы параметр жасау, геометрия салмай тұрып flex жасап тексеру.
4. Типтерді жасау, геометрияны бөліктеп қосып, әр бетін plane-ге құлыптау, әр қадамнан кейін flex жасау.
5. Көрінісін баптау: подкатегория, Coarse/Medium/Fine деңгейлері.
6. Сынақ жобаға жүктеп тексеру. Тип 6-дан көп болса, type catalog (.txt) жасау.

Файлда бұдан бөлек:
- формулалар: `if`, `not(a>b)`, бірліктер;
- shared және shared емес ішкі (nested) семействолар (КМ-де болт пен пластинаны бөлек спецификацияға шығару үшін керек);
- құрылымдық параметр түрлері;
- осының бәрінің біздің C# API тәжірибемізбен байланысы.
