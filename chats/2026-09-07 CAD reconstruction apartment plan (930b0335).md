━━━━━━━━━━━━━━━━━━━━━━
1. REFERENCE COORDINATE SYSTEM
━━━━━━━━━━━━━━━━━━━━━━

Алдымен планның өзін суреттен анықта.

План орналасқан bounding box-ты тап:

LEFT   = x0
TOP    = y0
RIGHT  = x1
BOTTOM = y1

Сол жақ жоғарғы нүктені:

P0 = (0,0)

деп қабылда.

X → оңға
Y → төмен

бағытталсын.

Планның барлық элементінің позициясын осы бір координаталық жүйеде анықта.

ЕШБІР қабырғаны "шамамен осы жерде" деп салуға болмайды.

━━━━━━━━━━━━━━━━━━━━━━
2. PERSPECTIVE / PHOTO CORRECTION
━━━━━━━━━━━━━━━━━━━━━━

Егер reference фотосуреттен алынған болса, қағаздың перспективасын план геометриясы деп қабылдама.

Алдымен:
- page perspective;
- rotation;
- skew;
- camera distortion

әсерін есепке алып, планды front-facing orthographic view ретінде қарастыр.

Егер PDF-тен алынған таза бет берілсе, PDF нұсқасын негізгі reference ретінде пайдалан.

━━━━━━━━━━━━━━━━━━━━━━
3. EXTRACT ALL VERTICES
━━━━━━━━━━━━━━━━━━━━━━

Сыртқы контурдан баста.

Контурдағы БАРЛЫҚ бұрылыс нүктелерін ретімен анықта:

P1 = (x,y)
P2 = (x,y)
P3 = (x,y)
...
Pn = (x,y)

Контурды:

P1 → P2 → P3 → ... → Pn → P1

ретімен жап.

Тіпті кішкентай:
- выступ;
- ниша;
- шахта;
- балкон;
- қабырға ығысуы

болса да жеке vertex ретінде енгіз.

Контурды қарапайым төртбұрышқа айналдыруға БОЛМАЙДЫ.

━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━

Пландағы жазылған өлшемдер — PRIMARY CONSTRAINTS.
