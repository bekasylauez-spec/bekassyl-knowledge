3602 Портал Блок 1 альбомын Revit-те жасағанда (15.11.2026, BEKA-2, скрипттер `D:\_claude_work\km3602\v3\km_lib.cs` → KM/KMS) табылған тәсілдер:

- **Кестенің «бос жолы» мен итог сызығы.** API «Пустая строка перед данными / Сетка в колонтитулах / Рамка» опцияларын өзгерте алмайды. Бір рет өз Revit данамда диалогпен: PostCommand(ScheduleOrQuantities) → «Новая спецификация» OK → «Свойства спецификации» PSM_SETCURSEL(4) «Вид» беті; BM_CLICK: 2260 «Отделять данные пустой строкой» өшір, 2337 «Сетка в колонтитулах» қос, 2259 «Рамка» + combo 2229 = «БК_спецификация_толстая» (CB_SELECTSTRING + CBN_SELCHANGE); «Поля»-ға бір өріс (2092 «Добавить»), OK. Одан `CreateViewTemplate()` → «БК_кесте_вид» (тек SCHEDULE_SHEET_APPEARANCE_PARAM басқарылады) → әр кестеге `ApplyViewTemplateParameters` (KMS.Appear). Шаблон кез келген санатқа жарамды (каркас, листы, multi). Скрипт: `ui_appear1..5.ps1`, `w32.ps1`.
- **Кесте тақырыбы** header бөлімінде тор ретінде (ShowHeaders = false, ShowTitle = true; InsertColumn/InsertRow, MergeCells, SetCellStyle; тік мәтін TextOrientation = 900 — градус×10). Бір бағанды GroupHeaders жасалмайды («Headers could not be grouped»). Мәтін «БК_текст_2,5» (Body/Header/TitleTextTypeId). Бағандар: field style шекарасы қалың/жіңішке.
- **Итог жолы «Всего профиля»** = топтау өрісінің мәні. Екі топтың аты бірдей көрінуі үшін жасырын КМ_Итог мәнінде латын «o» (Всегo) — бос орын қосу Revit-те кесіліп, топтар бірігеді.
- **Қосындылар дәл шығуы үшін** әр профиль жолы бүтін килограмға келтіріледі (айырма жолдың ең ауыр элементіне) — пайдаланушы қосындыны тексереді.
- **Парақ тізімі басқа файлдардағы парақтармен**: `ViewSheet.CreatePlaceholder` (нөмір, атау); CreateSheetList оларды өзі қосады, сұрыптау 1…13 табиғи. Тұрақты кесте (ссылочные документы) — денесі бос (сүзгі), тек header торы бар кесте.
- **0,000 «+»-сыз** (ГОСТ 21.101): spot типінің көшірмесі «…_0», `GetUnitsFormatOptions().UsePlusPrefix = false` (KM.SpotType).
- **Штамп:** жаңа парақта Revit-тің «Разработал/Проверил/Руководитель» үлгі мәндері шығады — SHEET_DESIGNED_BY/CHECKED_BY/DRAWN_BY/APPROVED_BY бос. «Листов» белгісі штампта жоқ → 1-парақта мәтін.
- **Разрез белгісінде viewport-тың detail number көрінеді** → разрез көрінісінің нөмірін разрез атымен бірдей қой (2-2 → «2»).
- **Узел парағы 1:5** (1:10-да қабырға/пластина ұсақ, мәтін сызбаға түседі); annotation crop өшірулі, выноска шынтағы стрелканың оң жағында (полка оңға созылады).
- Ведомость «штамп → ведомость (185 мм) → примечание» төменнен жоғары; ведомость тақырыбы парақ мәтіні ретінде кестенің үстінде.
