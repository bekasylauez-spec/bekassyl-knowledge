Пайдаланушы 13.11.2026 (РМЦ КМ Revit, бірнеше сағаттық фондық субагент тізбегінен кейін): «не болды неге тоқтап қала бердің», «Фонда емес, не жасап жатқаныңды мен көріп отырайын».

**Why:** фондық агент жұмыс істеп жатқанда менің хабарламам бітіп қалады да, оған «тоқтап қалды» болып көрінеді; ол үш рет «не болып жатыр», «неге жасамай отырсың» деп сұрады. Нәтижені күтіп отырғаннан процесті көргенді қалайды.

**How to apply:** ұзақ қадамдарды мүмкіндігінше өзім, көрінетін командалармен (скрипт іске қосу, лог оқу, сурет көрсету) орындаймын; әр қадамнан кейін қысқа жол жазып, нәтиже суретін жіберемін. Субагент шынымен керек болса (параллель оқу, тәуелсіз тексеріс) — алдын ала айтып, фонда емес, алдыңғы планда іске қосамын және аралық нәтижені көрсетемін. Менің түсіндірмем: бұл [[model-delegation-setup]] ережесін жоймайды, бірақ «фонда үнсіз жұмыс» тәсілін шектейді. Байланысты: [[feedback-full-autonomy]], [[feedback-finish-album-then-review]].

**16–17.11.2026 (КМ Чертеж БЦ → PDF, қысқа тапсырманың өзінде):** мен ережелерді оқып, листтерді тізіп, скрипт жазып, бірнеше tool шақыруын үнсіз жасадым. Пайдаланушы соңында: «не болып жатыр ескертіп отыр». Ереже: **кез келген тапсырмада** (қысқасында да) чатқа қысқа күй жолын жазып отырамын: бастағанда не істейтінімді (1 жол), әр қадамды бастағанда және ұзақ команда алдында (не істеп жатырмын, неге), аралық нәтиже шыққанда (не табылды, не шықты). Үнсіз қатарынан 3–4 tool шақыруынан артық жасамаймын. Тек соңғы есеппен шектелмеймін. Тапсырма тізімі (update_plan) чаттағы жолдың орнын баспайды.

**15.11.2026 (РМЦ КЖ пилот):** шаблон кестелерін көшіру қатесін бір сағатқа жуық үнсіз тексергенімде пайдаланушы: «неге созып кеттің?», «Не болды. Көрсетші жасағаныңды ашшы». Қорытынды: инфрақұрылымдық кедергіге (көшіру, API қатесі) 2–3 сынақтан көп кетпе — шешімі табылмаса баламаға көш, ал бірінші көрінетін нәтижені (парақты өз Revit-імде ашып, PNG-ні жоба папкасынан жіберу) ерте көрсет; тәуелсіз тексерісті іске қосқанда да аралық нәтиже көрсетіледі.

**17.11.2026 (Касымова BI, ұзақ Revit сериялары):** пайдаланушы «неге тоқтадың», «неге қатып тұр», «қанша қалды не жасағанын айтып отыр» деді. Ереже: ұзақ фондық серия кезінде кезекті бітіп, үнсіз кетпе — (1) серия басталғанда кесте: қалған кезеңдер + әр кезеңнің шамамен уақыты + аяқталу уақыты; (2) әр кезең біткенде 1–2 жол: не дайын, қанша қалды; (3) Revit терезесі API жұмыс кезінде қатып тұрады — алдын ала айт, «жаппа, өзгертпе» де; көрсету керек болса өз данамды алдыңғы планға шығарып (OpenAndActivateDocument + ShowWindow), түсті 3D фрагментті аш.
