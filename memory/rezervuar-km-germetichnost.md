Первый вариант листа схемы каркаса резервуара заказчик вернул одной фразой:
**«гидроизоляцию не сделал, внутри же вода стоит»** (2026-09-01, резервуар
3000×1700×2900, объект от Андрея).

**Почему:** резервуар водонаполненный. Схема каркаса с ведомостью отвечает только
на вопрос «что варить», но не на вопрос «как варить, чтобы не текло». Без указаний
бригада вправе поставить прерывистый шов — и резервуар потечёт.

**Как применять:** в КМ любого водонаполненного резервуара блок «Общие указания» —
обязательная часть листа, наравне с ведомостью. Минимум: сплошные герметичные швы
обшивки; примыкание рёбер завариваются с обеих сторон; вырезы для полного слива в
нижних узлах рёбер; контроль герметичности до покрытия; гидроиспытание наливом;
покрытие по всей внутренней поверхности вместе с рёбрами. Числа (система покрытий,
толщины, сроки выдержки) — из нормы объекта, не из головы.

**На этом объекте лист 6 мм стоит с ВНУТРЕННЕЙ стороны каркаса, рёбра снаружи**
(уточнено заказчиком 2026-09-02; более ранняя запись «рёбра внутри» была
предположением). Воды касается только гладкий лист: на смачиваемой поверхности
нет примыканий, вырезы для слива за рёбрами не нужны, площадь внутренней окраски
равна площади обшивки. Из `.lir` сторону листа не видно — модель срединная,
поэтому её надо спрашивать, а не додумывать.

`src/km_rezervuar.py`. См. [[rezervuary-apt-nahimova]], [[shema-karkasa-pravila]].
