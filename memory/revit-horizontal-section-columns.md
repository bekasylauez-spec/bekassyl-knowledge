15.11.2026 (РМЦ КМ, узел 12 «Разрез 1-1»): көлденең (жоғарыдан қараған) ViewSection-да К1 колоннасы сызылмады, «К1» выноскасы бос жерді көрсетті. Зерттеу: элемент көріністе бар, жасырылмаған, сүзгі/override кінәлі емес, семейство көрінуі толық. Бірақ `get_Geometry(new Options{View=v})` колоннаны базадан ~1 м-де (z 900…1900) береді, қима +6,000-де (5900…6000). База жоспарында (қима ~1050) колонна сызылады, жоғарыда сызылмайды. Revit-тің өз ерекшелігі (база деңгейі + ~1000 мм). РМЦ-да 32 көлденең қиманың 6-уы зардап шекті (У1 4-4, У5 2-2/3-3, У8 1-1, У11 2-2, У12 1-1).

**Тексеріс:** `D:\_claude_work\RMC\kzh\kz22_colcut_scan.cs` — кроп ішінде бар, бірақ көрініс геометриясы кроппен қиылыспайтын колонналар тізімі.
**Шешім:** rmc_n_lib `ColCuts(c)` (Dress-тен кейін): колонна ∩ кроп призмасы → `BooleanOperationsUtils.CutWithHalfSpace` (қалыпты = −ViewDirection) → көрерменге қараған жазық беттің контуры → `FilledRegion` «БК_кесінді_колонна» + override (колонна түсі: бояу c+(255−c)·0.78, контур c·0.72). Фрейм пішінінің Hull-ы нақты I-контурмен ауыстырылады, сонда выноска полкаға түседі (дөңес қабықтың полка ұштары арасындағы бос жеріне емес).
Ескі PDF-тегі «К1» сызығы басқа элемент болған (бөтен узел денесі, қазір дұрыс жасырылады), яғни ақау бұрыннан бар еді. Байланысты: [[project-rmc-make]], [[km-callout-style]].
