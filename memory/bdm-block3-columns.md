06.11.2026 пайдаланушы БДМ Блок 3 колонналарын (Км) тапсырды. Нәтиже: `R:\От Шерхан\БДМ Блок 3\Б3.колонны.dwg` + PDF.

- Шешімдер (пайдаланушы 06.11): 22 және 33 осьтердегі колонналар (деформациялық тігіс) — көрші блоктардікі, кірмейді; В–Д арасындағы 1200×800/1500×800/1000×800 тіктөртбұрыштар — жабдық тіректері, Км емес. Блок 3-те 60 колонна (800×1200 — 30, 700×700 — 20, 600×600 — 10), бәрі −1.200…+7.000.

Генератор `gen3.py` (шаблоннан импорт, b×h, nb/nh, түйін деңгейлері, splice тізімі), `gen_sch.py` (Онкоцентр «Км» выноскасы C681D клоны), `gen_tab.py` (Онкоцентр кестесі 3D44EA → Ведомость колонн), `w/types.py`.
