Аналог берілгенде дереккөз реті қатаң: (1) берілген аналог — парақ құрамы, узел құрылымы, стиль дәл содан; (2) жетпесе GitHub стандарты (`00_ЧЕРТЕЖ_ЖҮЙЕСІ.md` 5-бөлім, ЕРЕЖЕЛЕР №66); (3) табылмаса пайдаланушыдан сұра. Интернеттен, басқа жобадан, серияның жалпы шешімінен, өз ойымнан алмаймын. Осьтер, отметка, уклон — АР-дан; сечение өз жобадан (ЛИРА/ведомость, АР-мен салыстыр); узел мен парақ геометриясымен келтіріледі, тек мәтін емес.

**Why:** пайдаланушы 11.11.2026: «бір аналог бергенде дәл сол аналогпен өз чертежін корректировка жасап, уклон, сечениені архитектурадан алып, узелді өзіне келтірсін. Басқа жақтан болмайтын бір затты алып, қуып қате жасайды. Чат бірінші берілген аналог бойынша; жетпесе GitHub-тан қарауы міндетті; ол жақтан таппаса менен сұрауға міндетті».

**How to apply:** әр парақ/узелге «аналогта → менде → көзі» кестесі; көзі жоқ жол — сұрақ (бір хабарламада жинап, қалған жұмысты тоқтатпай). Көрсетпес бұрын аналог парағымен қатар салыстыр, аналогтың саны/маркасы/отметкасы қалмағанын мәтінмен іздеп тексер. «Сечение архитектурадан» дегенді мен «өз жобаның сечениесі (ЛИРА/ведомость), АР-да болса АР-мен салыстыру» деп жаздым — пайдаланушы нақтыласа түзет.
