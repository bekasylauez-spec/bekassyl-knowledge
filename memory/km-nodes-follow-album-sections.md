09.11.2026 (В109): ЛИРА бойынша пролет ортасында түйісетін СВ узелдерін сыздым — пайдаланушы: «Өшіріп қайта жаса, ешқандай жері сәйкес емес». Оның разрездерінде (3-3, 4-4, 5-5) СВ1 ярус ішінде айқасқан X, колоннаға +5.020-да бекітіледі (узел «4» белгісі).

**Why:** узел — альбомдағы сызбаның бөлшегі; разрез/схемада көрсетілген түйінге сәйкес келмесе, ол пайдасыз. ЛИРА тек сечение/күш үшін.
**How to apply:** узел сызбас бұрын сол элемент тұрған барлық схема/разрезді ашып, узел белгісі (knot) қойылған нүктелерді тізім ет; әр узел сол нүктенің геометриясы (бұрыш, ярус биіктігі, қай элементтер келеді) бойынша. Пайдаланушы «мақсаты дұрыс» деген ескі узелдердің тізімін сақта, тек стилін пайдаланушы узелдерінен ал. Сәйкессіздік (ЛИРА ↔ разрез) болса — айт, бірақ сызбаны разрез бойынша жаса. Related: [[km-copy-user-nodes]], [[km-analog-nodes-own-sections]].

09.11 (кейін): «Сен өзің сызып жатырсың — переделка жасап жаса» — узелді жаңадан сызба. Аналог КМ альбомдарынан (Надстройка 2, Спорткомплекс Блок 1/2) ұқсас узелді import (side DB, WblockClone) → plset/sp_set/mcset/erase арқылы біздің элементке келтір. Тұзақтар: stretchwin маңайдағы объектілерді де созады (колоннаны бөліктермен кой); □ таңбасы жазудан бөлек LWPOLYLINE болуы мүмкін (масштабтағанда қалып қояды); қайта жинағанда import map префиксін (B:old) қолдан.

09.11: кран — БМ1 КН консолінің ҮСТІНДЕ (пайдаланушы). Аналог: «H:\От Дастанкотелный\100гкал\…\КМ Чертеж Блок 1.dwg» 13.1-парақ «Узел крепление ПБ1…ПБ3 к колонне» (консоль + ПБ + рельс + -t14 тартпа). Цех Блок 1 кран узелдері — ілулі монорельс, бізге сәйкес емес. SPDSFORMAT clone 's' масштабына көнбейді → mcset Scale.

09.11: узелді айнадан көшіргенде (mirror) элементтің уклонын тексер — ферма мен балка бір бағытта (жотаға қарай) көтеріледі; айна уклонды кері бұрады (пайдаланушы ескертті, Узел 8). Айналған LWPOLYLINE-да normal −Z болады — оған plset қолданба (нүктелер −x-ке кетеді); клондап тікелей нүкте қой.
