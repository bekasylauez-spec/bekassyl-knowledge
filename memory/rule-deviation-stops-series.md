17.11.2026, Гостиница Касымова: «Неге сен ережеге мойын сұнбадың. Бірінші мәрте емес. Қате қай жерде нені дұрыс сақтамадың».

Не болды: стена маркаларын 15.11-де (t, L) бойынша бір қабат кесінділерінен автоматты бердім (46 марка, См-1 = 218 дана). Ереже — «әр ось/сызық бойындағы тұтас стена — бөлек марка, бірдейі бір марка» (Obsidian 14_Мои правила 06.11; 18_КЖ жүйесі Ережелер кітабы Ст21; Онкоцентр 5.2–5.6 «…по оси 1с стена См-1»). Мен ауытқуды `күй.md`-ге «пайдаланушымен келісілмеген» деп жазып, «ашық сұрақтар» тізіміне қостым да, 17.11-де бүкіл 5.x сериясын соның үстіне құрдым; парақ үлгісін аналогтан емес, GitHub-тағы ерекше жағдайдан (`doc_67`, бір парақтық стена) алдым. Көрсетер алдындағы тексеріс тек оформлениені қарады.

Ереже қай жерде сақталмаған еді: тек Obsidian-да (14_Мои правила, Ережелер кітабы). GitHub `ЕРЕЖЕЛЕР.md`-де де, memory-де де жоқ еді → контекст қысылғаннан кейін әр сессияда жүктелетін ережелерде болмады; дайджест файлымда болса да, стена алдында қайта оқымадым.

Бұрынғы ұқсас ескертулер (бір түрі): 20.10 «неге видео уроктан жасағандай жасамадың стенаны» (3в-14); 05.11 Галакси «аналогты оқымай көшірдім» ([[wall-sheets-rules]]); 11.11 аналог ережесі ([[analog-first-then-github-then-ask]]); КМ «аналог парағы қатаң клондалады» ([[km-strict-analog-sheets]]). Ортақ себебі: автоматтандыруға ыңғайсыз ережені өз жеңілдетуіммен алмастырып, ауытқуды «сұрақ» деп кейінге қалдырамын.

**How to apply:**
- Ережеге/аналогқа қайшы немесе «келісілмеген» шешім — серияны бастамаймын: ережемен түзетемін, ереже анық болмаса пайдаланушыдан сұраймын. «Белгілі ауытқу / ашық сұрақ» тізіміне жазу — рұқсат емес.
- Әр элемент (Фм, Км, См, Рм, Пм) бөлімі алдында «қақпа»: (1) маркалау ережесі (Obsidian тақырып папкасы + 14_Мои правила + Ережелер кітабы) — менің маркаларыммен жолма-жол; (2) аналогтың сол бөлімінің парақ тізімі (құрамы, атауы, реті) — менің жоспарыммен; (3) екеуінің нәтижесі пайдаланушыға бір пилотпен көрсетіледі. «Альбомды бітіріп бір рет көрсет» ([[feedback-finish-album-then-review]]) — узел/парақ сайын растау сұрамау деген, мазмұн ережесін аттап өтуге рұқсат емес.
- Тәуелсіз тексерушіге (drawing-checker) тек оформление емес, мазмұн ережелері де беріледі (марка қалай бөлінеді, парақ құрамы аналогпен).
- Пайдаланушы ережесі тек Obsidian-да тұрса — GitHub `ЕРЕЖЕЛЕР.md` пен memory-ге де көшіремін (әр сессияда жүктелетін жерге).

**17.11.2026 (Касымова стеналары) — пайдаланушы:** «1:100, типтік үзіп» (стена қасбеті 1:100, типтік қабаттар бір рет, үзу сызығымен); «жеке жеке жасайық. ревитте тексерем сосын келесісіне өтеміз». **How to apply:** элемент маркалары бір-бірлеп жасалады: бір марканың барлық парағы → файлды сақтаймын → пайдаланушы Revit-те тексереді → келесі марка. Серияны скриптпен бір рет жүргізу жоқ (бұл объектіде, стеналар үшін).
