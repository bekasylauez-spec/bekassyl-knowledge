2026-10-26 (Рампа spec): I sent the sheet PDF straight from the session scratchpad (Temp). The user said «АЙДАЛАҒА САҚТАМА», pointed at «…\ЖК Қарасу село Абай\КМ Чертеж», and «маған көрсеткен жерге сақтап атын өзгерт».

**Why:** the user cannot find or reuse files left in Temp, and odd names such as «копия до правок 19-10 v2» or «(пересчет 26-10)» get in their way.
**How to apply:** save every deliverable (PDF, DWG) in the project's own folder, named like the other files there (e.g. «КМ Чертеж <объект>.dwg / … - лист N <название>.pdf»). Scratchpad is only for working files. Before renaming a DWG, check for a .dwl: if it is open in AutoCAD, ask the user to close it first.
