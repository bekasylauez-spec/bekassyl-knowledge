17.11.2026, Касымова, стена См-1 опалубкасы: «Стенаның шеттерін яғни контурын 0,30 мм қалың сызықпен сызу керек» (мен 0,50 мм қойған едім); «Біз сызып жатқан стенадан басқасының барлығы 0,05 мм-де сызылуы міндетті. Негізгі ережеге кіргіз».

**Why:** парақта өз элементі ғана ерекшеленуі керек; мен қалың перо қойып, қалғанын шаблон салмағымен қалдырған едім. Пайдаланушы PDF-те қалай көрінетінін тексереді.

**How to apply:** әр парақ генераторында — өз элементінің санатына 0,30-ға сай перо (Касымова BI шаблонында 3-перо → PDF-те 0,30), қалған санаттарға ең жіңішке перо; аннотация семействолары (отметка, қима белгісі, ось көпіршігі) салмағын «Стили объектов» анықтайды — вид override-ы оларға әсер етпейді. Көрсетпес бұрын PDF сызық енін өлшеймін (PyMuPDF `get_drawings()` → ені бойынша санау). Шаблонның «Веса линий» кестесінде 1-перо 0,05 мм болмаса (Касымова: модель 1-перо 1:100-де 0,10, аннотация 1-перо 0,20 мм шығады) — кестені өзгерту керек, API жоқ, UI арқылы, пайдаланушыдан рұқсат сұраймын. Негізгі ереже CLAUDE.md «Сызық қалыңдығы» жолында да.

Ерекшелік (17.11.2026, пайдаланушы «Қала берсін»): размер засечкалары (BI шаблонының `BI_диагональ_2мм` типі, «Толщина пера для утолщенной засечки» = 6 → PDF-те 0,18 мм) өзгертілмейді — шаблон салмағымен қалады. Штамп/рамка да шаблоннан (0,2/0,5). PDF-тегі 0,085 мм = Revit PDF экспортының ең жіңішке шегі (0,05 перо).
