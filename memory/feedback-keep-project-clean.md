05.11.2026 АБК: «артық файлдарды өшіріп таста». Менің ui*.png скриндерім, drag2.ps1, ЛИРА бэкаптары (*.~lir), қабылданбаған нұсқалар (кол400) `Расчет` ішінде жиналып қалды.
**Why:** жоба папкасы тек нәтижелік файлдар үшін (тапсырыс берушіге кетеді).
**How to apply:** GUI скриптерін (ui.ps1 көшірмесі) scratchpad\tools-тан іске қос, скрин сонда түссін; жұмыс соңында жоба папкасынан менің уақытша файлдарымды, ЛИРА *.~lir/*.~~lir бэкаптарын корзинаға жібер (тек корзина, D-ге қатаң өшіру жоқ).
