10.11.2026 пайдаланушы «40К2 колоннаға 30Б1 балканың қатаң жалғануы» түйінін сұрады (аналог [[project-node-20k1-25b1]]), сосын В109 «Узел 4» суретін жіберіп: «мына стилде де жасап көрші, сосын Ревитте оформленесін де».

**Файлдар** (BEKA-1, `D:\РАБОЧКА\Узлы_КМ\`):
- `БК-КМ_Узел_40К2-30Б1.rvt` — торцевой фланец ПЛ1 −20×200×500, 8 М20×75 (Ø23), 4 қабырға −14×190×358, оголовок ПЛ3 −10×420×440.
- `БК-КМ_Узел_40К2-30Б1_накладки.rvt` — Узел 4 стилі: ПЛ1 үстіңгі накладка −16 (әрі оголовок), ПЛ2 астыңғы −16, колоннада 2 қабырға −16, стенкада −8×100×250 + L100×7, 3 М24×55 (Ø27), кронштейн −8.
- Жұмыс папкасы `D:\_claude_work\uzel40\`: `uz_12…uz_18` скрипттері, `runner.cs`, `run.ps1`, `dlg.ps1`, `uz4\node4.json` (Узел 4 DXF геометриясы).

**Сечениелер ГОСТ Р 57837-2017:** 40К2 400×400×13×21 r22 171,7 кг/м; 30Б1 298×149×5,5×8 r13 32,0 кг/м. Стандарт семействосындағы «30Б1» типі — ескі ГОСТ 26020 (296×140×5,8×8,5), В109 альбомы үшін; түйін файлдарында тип жоба ішінде ғана өзгертілді, .rfa-ға тиген жоқпын.

**BEKA-1-де Revit жүргізу тәсілі** ([[revit-build-via-addin]] жалғасы):
- `D:\Бекасыл КЖ КМ` BEKA-1-де жоқ. Стандарт скрипттер/семейство/шаблон жабық репода: `git clone --filter=blob:none --no-checkout https://[email жасырылды]/bekasylauez-spec/bekasyl-kzh-km.git` + sparse-checkout (`_Стандарт_КЖ/скрипттер|семейства|шаблоны`), көшірмесі `D:\_claude_work\kzhkm_repo`. Тек оқу, push жоқ.
- RBLive shim + `runner.dll` (Framework csc, C# 5) Revit ішінде скриптті pyRevit-тегі Roslyn-мен (`%APPDATA%\pyRevit-Master\bin\netcore`) компиляциялайды — BEKA-2-дегі `send_code_to_revit` сияқты, соңғы C#.
- Іске қосқанда: pyRevit диалогы «Не загружать» (тұрақты сенім бермеу), RBLive «Загрузить один раз».

**API сабақтары:**
- «Соединения несущих конструкций» семействосын жобада void данасымен кесуге болмайды; стандарт семейство ішінде API void денені кеспейді, SolidSolidCutUtils қабылданбайды → тесігі бар пластинаны эскизінде шеңберлері бар бір экструзиямен немесе DirectShape-пен жаса.
- Face-based шаблонда өз хост экструзиясы бар — `First(IsSolid)` соны алады.
- Тік жазықтыққа қойылған пластинаның local Y = −Z (өлшеп тексер).
- Қабаттасатын шов призмаларын Union-мен бір денеге біріктір; Union-нан кейін «ауадағы» шыңдар пайда болуы мүмкін — жақсысы қабаттастырмау.

**Ашық сұрақтар (пайдаланушы шешеді):** фланецті нұсқада оголовок фланец үстін жауып, оған пісірілген (аналогтағыдай) — монтажда балканы үстінен түсіру мүмкін емес; накладкалы нұсқада тік шет 40 мм (сызбадағыдай) < 2·d0 = 54; П1 прогоны мен ГС1 алынбаған; оформление парағы жасалған жоқ.
