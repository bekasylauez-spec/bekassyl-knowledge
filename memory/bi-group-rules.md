**How to apply:** жоба BI-дікі болса (пайдаланушы айтады, не модельде `BI_версия_шаблона` / `BI_марка_конструкции` бар) — жұмыс алдында `19_BI Group\00_ОҚЫ_АЛДЫМЕН`, содан кейін жұмысқа сай файл. Басқа объектіге қолданбаймын. Негізі:

- негізгі тор тұтас стержень, типі `… пм`; нахлёстты кесте қосады (стык × k·d);
- стена тігі: L = қабат + нахлёст, 50 % вразбежку, «Узлы стыковки» кестесі (B25 ≈ 61d, B30 ≈ 51d);
- доп. бөлек `BI_фильтр`: плитада `ДопНиз/Верх_X/Y` (төрт парақ), стенада `Доп`;

- стена парақтары: опалубка → тік+көлденең схема → доп → қималар 1:25 → спецификация поэтажно → ВД → ВРС.
