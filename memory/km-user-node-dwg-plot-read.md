09.11.2026 кеш (В109): «КМ Чертеж узелдер.dwg ішіндегі узелдерді жақсылап қарап жаса. Қателерің өте көп». Мен узел 1–4-ті бір қарап, қалғанын өз «стандартыммен» жасаған едім: фланец 300 + М20, БП қатаң түйіні фланецпен, СВ1 Λ/V, ГС1 қабырғаға ортасынан, БМ1 тартпасы көлденең −12, СФ үстінде оголовок, прогон −10. Дұрысы: [[km-node-rules-purlin-brace-base]] және ЕРЕЖЕЛЕР.md «Узелдер пайдаланушы DWG-сы бойынша» блогы.

**Why:** пайдаланушы өз узелдерін сызып қойған. Олардан ауытқу = қате. ЛИРА топологиясы да (Λ/V связь) альбомдағы «Разрез 6-6» (X) алдында жеңіледі ([[km-nodes-follow-album-sections]]).

**How to apply:**
- DWG-ны accoreconsole арқылы оқы. Layout бос болуы мүмкін, сондықтан модельден `-PLOT` Model Window (DWG To PDF, «ISO без полей A3 (420.00 x 297.00 мм)») қолдан. .scr файлы **cp1251**-де болуы керек. Содан pdf2png.ps1 → 5000 px → әр узелді кесіп, жақындатып қара.
- Парақтарды Штамп_В109 блогының insert нүктесімен тап (масштаб 0.1 → кадр 4200×2970). Royal BIK штампы бар парақтар — аналог.
- Әр узел үшін тізім жаса: пластина (қалыңдығы, өлшемі, материалы), болт (саны, Ø, қадамы), қай бетке пісірілгені. Модельде дәл солай жаса. Көрсетпес бұрын q20 C15 тексерісінен өтсін.
- Shell heredoc ішінде `'''` немесе `\t` бар Python скрипті бұзылады. Оны Write арқылы файлға жазып, сосын іске қос.
- Кейін (№44): «профилдердің басындағы листтер» — құбыр ұшындағы заглушканы да сызбадан оқы: −t8, құбырдан кең, вкладыш сыртынан пісірілген. Ұсақ бөлшекті (заглушка, қабырға, шайба) да тізімге қос.
