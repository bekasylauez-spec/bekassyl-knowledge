Пайдаланушы (05.11.2026, АБК v3 кезінде): «Чертеж жасағанда жаңадан жасама тек бар затты өзгертіп көшіріп қойып жаса. Копировать ет».

**Why:** өз стилі мен шешімдері сақталсын; жаңадан салынған объект стильден ауытқиды (выноска, размер, штрих, кесте).
**How to apply:** кез келген жаңа элемент/лист/кесте/узел/свая схемасы — алдымен аналогтағы немесе сол DWG-дағы дайын объектіні табу, clone (WblockCloneObjects / copy), содан кейін stretch/мәтін ауыстыру. Сызба жоқ болса ғана сұрау. Раскатные сваи сияқты жаңа түйіндер — «Кж-склад рулонов» аналогынан көшіру.
