06.11.2026 Маслоподготовка Блок 3: CSV сұрағанымда пайдаланушы «өзің жаса мен білмим» деді.

**Why:** пайдаланушы ЛИРА кестесін CSV-ге шығаруды білмейді; күтіп отыру уақыт жоғалтады.

**How to apply:** ЛИРА ашық тұрса (BEKA-1, процесс LiraSapr), computer-use: request_access атауы « ЛИРА-САПР 2024» (алдында бос орын!) + Яндекс. Железобетон → Документация → «Таблицы результатов для ЖБ» → CSV, «Арматура в элементах», «в стержнях», вариант → ✓. Файл: `C:\Users\Public\Documents\LIRA SAPR\LIRA SAPR 2024\work\<модель>.DOCS\.INV\tbl01.31_1.csv`. Есепке жіберме, модельге тиме. «Расчетқа жіберме» = zip-ті «Расчет» папкасына ашпа, .txt-ті scratchpad-қа ғана ал.
